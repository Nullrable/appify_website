**오디오 에디터**(«**당사**»)는 사용자의 오디오와 비디오를 기기에 머무르게 한다는 것을 설계 원칙으로 하는 iPhone의 오디오 및 비디오 처리 앱입니다. 본 개인정보 처리방침은 앱이 어떤 데이터를 처리하는지, 왜 처리하는지, 그리고 사용자가 갖는 선택권을 설명합니다.

앱을 사용함으로써 본 정책에 설명된 처리에 동의합니다.

**최종 업데이트:2026년 10월 17일**

## 1. 개요

- **기기 내 처리.** 모든 오디오 및 비디오 처리(편집, 엔환스, 변환, 음성 추출, 압축, 병합)는 사용자의 기기에서 로컬로 실행됩니다. 오디오 파일, 비디오 파일 및 중간 결과는 당사가 운영하는 어떤 서버에도 **업로드되지 않습니다**.
- **계정 불필요.** 앱은 가입을 요구하지 않습니다. 당사는 사용자의 이름, 이메일, 전화번호 또는 어떤 연락처 정보도 수집하지 않습니다.
- **콘텐츠 분석 없음.** 앱은 사용자의 오디오 또는 비디오 콘텐츠를 분석하지 않으며 AI 분류, 음성 인식, 화자 식별을 수행하지 않습니다.
- **광고(무료 버전, 비개인화).** 무료 버전은 홈, 기록, 설정 세 화면에 배너 광고를 표시합니다. 앱은 App Tracking Transparency 권한을 **요청하지 않으며** Apple의 광고 식별자도 **읽지 않습니다**. 모든 광고는 실시간 맥락을 기반으로 게재됩니다.
- **유료 버전.** Pro를 구독하면 구매는 App Store에서 처리되며, RevenueCat은 익명 식별자와 스토어 영수증을 사용하여 구독을 검증합니다.

## 2. 수집하지 않는 데이터

당사는 다음 데이터를 **수집, 전송 또는 판매하지 않습니다**:

- 사용자의 오디오 또는 비디오 파일, 또는 그것들의 섬네일
- 오디오/비디오 메타데이터(녹음 시간, 길이, 위치) 또는 처리 과정의 중간 결과
- 사용자의 이름, 이메일, 전화번호, 우편 주소 또는 기타 연락처 정보
- 사용자의 오디오/비디오와 관련된 정밀하거나 대략적인 위치
- 사용자의 연락처, 캘린더, 사진 라이브러리 인덱스 또는 기타 개인 콘텐츠

## 3. 기기에서 처리되는 데이터

### 3.1 멀티트랙 에디터

오디오 클립이 타임라인에 배치되며, 사용자가 지정한 진입점, 종료점, 순서, 재생 배속, 스케일, 이펙트 체인(노이즈 제거, 보컬 엔환스, 라우드니스 정규화, 스테레오 확장, 채널 분할/병합)을 거쳐 새 오디오로 변환됩니다. 원본 파일은 절대 수정되지 않으며, 결과는 새 파일로 앱 샌드박스 디렉터리에 기록됩니다.

### 3.2 오디오 포맷 변환

지원 입력 포맷(MP3, WAV, M4A, AAC, FLAC, OGG, Opus, AIFF, AMR, CAF) 중 하나를 읽고 MP3, WAV, FLAC, OGG 중 하나로 내보냅니다. 오디오 스트림 자체는 대상 포맷의 요구 사항에 맞게 재인코딩되고, 컨테이너 래퍼는 교체됩니다.

### 3.3 비디오에서 오디오 추출

MP4, MOV, M4V, AVI, MKV, WebM, FLV, WMV 비디오 파일에서 오디오 트랙을 분리하고 사용자가 선택한 포맷(MP3, WAV, FLAC, OGG 중 하나)으로 재인코딩합니다. 비디오 파일 자체는 유지되지 않으며 오디오 트랙의 소스로만 사용됩니다.

### 3.4 기록 및 초안

각 작업의 파라미터(도구 유형, 시간, 파일 경로, 파라미터 구성)는 로컬 데이터베이스에 기록되며, 멀티트랙 에디터의 초안은 사용자가 드래그할 때 자동 저장됩니다. 이 데이터는 모두 사용자의 기기에 저장되며 앱을 삭제하면 완전히 삭제됩니다.

## 4. 제3자 서비스가 수집하는 데이터

다음 제3자는 사용자에게 서비스를 제공할 때 데이터를 수집합니다. 데이터 사용은 각자의 개인정보 처리방침에 따릅니다.

### 4.1 광고 SDK(무료 버전 전용)

무료 버전은 홈, 기록, 설정 세 화면에 배너 광고를 표시합니다. 광고는 비개인화입니다:

**광고는 비개인화입니다.** 앱은 App Tracking Transparency API를 호출하지 않으며 Apple의 광고 식별자도 읽지 않습니다. 모든 광고는 사용자의 기기 사용 행위와 무관한 실시간 맥락을 기반으로 게재됩니다. 광고 SDK는 다음을 수신할 수 있습니다:

- **기기 정보**(기기 모델, 시스템 버전, 화면 크기, 언어, 지역 등)
- **광고 게재 메타데이터**(광고 단위 ID, 광고 유형, 광고 조회/탭 여부 등)
- **IP 주소**(대략적 위치(보통 국가 또는 도시) 추정 및 사기 방지에 사용)

Pro를 구독하면 광고가 제거되며 광고 SDK는 더 이상 앱에서 데이터를 받지 않습니다.

### 4.2 RevenueCat(구독 관리)

Pro를 구독하면 앱은 **RevenueCat**을 사용하여 구독을 검증하고 권한을 관리합니다. RevenueCat은 다음을 수신합니다:

- **무작위로 생성된 익명 식별자**(RevenueCat «App User ID»)
- 구매 검증을 위한 App Store 영수증
- 제품 식별자, 가격, 통화, 구매일
- 사용자의 기기 로케일 및 앱 버전

[RevenueCat 개인정보 처리방침](https://revenuecat.com/privacy)을 참조하십시오.

### 4.3 Apple App Store

구매는 Apple App Store에서 처리됩니다. 구매 데이터 처리는 [Apple 개인정보 처리방침](https://www.apple.com/legal/privacy/)을 따릅니다.

## 5. 앱이 요청하는 권한

| 권한 | 요청 사유 | 필수 여부 |
|---|---|---|
| **사진 라이브러리 접근** | 처리할 오디오 또는 비디오 읽기, 처리된 오디오 쓰기 | 예, 처리에 필수 |
| **파일 접근(Files App)** | Files App 내 파일 읽기 또는 저장 | 아니오 — 사용자가 소스로 Files를 명시적으로 선택할 때만 사용 |

앱은 카메라, 마이크(사용자가 명시적으로 녹음을 시작하는 경우 제외), 연락처, 위치, 추적(ATT) 권한을 **요청하지 않습니다**.

## 6. 아동 개인정보

앱은 일반 청중을 대상으로 하며 13세 미만(또는 사용자의 관할권에서 최소 디지털 동의 연령 미만)의 아동을 대상으로 하지 않습니다. 당사는 아동의 개인 데이터를 고의로 수집하지 않습니다. 앱이 어떤 사용자의 개인 데이터도 수집하지 않기 때문에 이 약속은 모든 연령대에 적용됩니다.

## 7. 국제 데이터 전송

- **광고 SDK**는 사용자의 국가 외 지역에서 데이터를 처리할 수 있습니다. 구체적 공급업체와 해당 데이터 전송 정책은 공식 문서를 따릅니다.
- **RevenueCat**은 구매 검증 데이터를 미국과 유럽 연합에 위치한 인프라에 저장합니다. [RevenueCat 개인정보 처리방침](https://revenuecat.com/privacy)을 참조하십시오.
- **Apple**은 표준 글로벌 인프라를 통해 App Store 구매를 처리합니다.

제3절에서 설명한 기기 내 처리는 기기를 **벗어나지 않으므로** 국제 데이터 전송 규칙의 적용을 받지 않습니다.

## 8. 사용자의 권리

### 8.1 GDPR(유럽 경제 지역 및 영국)

유럽 경제 지역 또는 영국에 있는 경우, 사용자는 자신의 개인 데이터에 대한 접근, 정정, 삭제, 제한 또는 처리에 반대할 권리, 데이터 이동권, 언제든지 동의를 철회할 권리, 그리고 현지 데이터 보호 기관에 불만을 제기할 권리를 가집니다.

앱이 서버 측 사용자 프로필을 유지하지 않기 때문에, 이러한 권리의 대부분은 이미 앱의 설계로 충족됩니다:

- 사용자의 오디오와 비디오는 기기를 절대 떠나지 않으며, 앱을 삭제하면 모든 것이 제거됩니다
- 광고는 항상 비개인화입니다(제4.1절 참조), 추가 제어가 필요하지 않습니다
- 구매 관련을 삭제하려면, 영수증과 관련된 RevenueCat 기록 삭제를 당사에 요청해 주십시오

### 8.2 CCPA / CPRA(캘리포니아)

캘리포니아 거주자는 수집된 개인정보를 알 권리, 해당 정보를 삭제할 권리, 그 판매 또는 공유를 거부할 권리, 그리고 이러한 권리行使에 대해 차별을 받지 않을 권리를 가집니다. 앱은 개인정보를 **판매하지 않으며** 크로스 컨텍스트 행동 광고를 위해 개인정보를 **공유하지 않습니다** — 모든 광고는 비개인화입니다.

### 8.3 기타 관할권

다른 관할권(예: 브라질의 LGPD, 한국의 PIPA, 캐나다의 PIPEDA) 거주자에게도 유사한 권리가 있을 수 있습니다. 관련 법률이 허용하는 범위에서, 당사는 위 보호를 거주지와 관계없이 모든 사용자에게 확대합니다.

## 9. 데이터 보존

- **오디오 및 비디오 파일:** 사용자의 기기에만 보존됩니다. 당사로 전송되는 데이터가 없으므로, 당사는 어떤 보존도 수행하지 않습니다.
- **기록 및 초안:** 사용자 기기의 로컬 데이터베이스에 저장되며, 앱을 삭제하면 완전히 삭제됩니다.
- **구매:** RevenueCat 및 App Store가 각자의 보존 정책에 따라 보존합니다.
- **광고 데이터:** 광고 SDK 공급업체의 보존 정책에 따릅니다.

## 10. 보안

앱은 기기의 기본 파일 보호 기능에 의존합니다. 모든 처리는 시스템 사진 라이브러리와 로컬 파일 시스템의 보호된 인터페이스를 통해 로컬에서 수행됩니다. 제3자와의 네트워크 통신은 HTTPS를 사용합니다. 그러나 어떤 전송 또는 저장 방법도 100% 안전하다고 보장할 수 없으며, 당사는 절대적인 보안을 보장할 수 없습니다.
