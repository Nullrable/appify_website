## Полный список форматов

Эта страница — шпаргалка: все аудио- и видеоформаты, которые поддерживает аудиоредактор, и когда какой выбирать.

Вход и выход — это два разных набора форматов: приложение может читать 10 аудиоформатов, но записывать только 4. Видео только читаются и не открываются непосредственно редактором.

## Аудиоформаты на вход (10)

Редактор открывает эти 10 аудиофайлов — многодорожечное редактирование, улучшение и конвертация (compress / merge) принимают их в качестве входа:

| Формат | Когда использовать |
|---|---|
| **MP3** | Универсальные плееры, автомобильные системы, вложения в почту. Стандартный выбор. |
| **WAV** | Без потерь, идеален для сведения, архивации или повторного монтажа. |
| **M4A** | Контейнерная версия AAC, распространён в экосистеме Apple. |
| **AAC** | Стандарт экосистемы Apple, хорошая детализация при малом размере. |
| **FLAC** | Без потерь, но со сжатием — примерно вдвое меньше, чем WAV. |
| **OGG** | Открытый контейнер, предпочитается некоторыми профессиональными плеерами. |
| **Opus** | Современный низколатентный кодек, распространён в голосовых встречах, подкастах и стриминге. |
| **AIFF** | Стандарт экосистемы macOS / Logic, без потерь. |
| **AMR** | Ранний формат записи мобильных вызовов, стандарт 3GPP. |
| **CAF** | Контейнер Apple Core Audio, идеален для последующей обработки на iOS. |

## Аудиоформаты на выход (4)

Редактор, многодорожечное улучшение и конвертация при экспорте могут записать только один из этих 4 форматов:

| Формат | Когда использовать |
|---|---|
| **MP3** | Универсальный стандарт, распознаётся практически любым устройством и плеером. |
| **WAV** | Без потерь, идеален для повторного монтажа или архивации. |
| **FLAC** | Без потерь, но со сжатием, примерно вдвое меньше, чем WAV. |
| **OGG** | Открытый контейнер, предпочитается некоторым профессиональным оборудованием. |

## Видеоформаты (8)

Видеофайлы **не** открываются непосредственно редактором. Они используются только как «источник аудиодорожек»:

| Формат | Когда использовать |
|---|---|
| **MP4** | Универсальный, распознаётся практически любым устройством и плеером. |
| **MOV** | Стандарт экосистемы Apple — iMovie, Final Cut, Logic принимают его. |
| **M4V** | Видеоконтейнер эпохи iTunes, на устройствах Apple ведёт себя как MP4. |
| **AVI** | Классический контейнер, лучшая совместимость со старыми приложениями Windows. |
| **MKV** | Открытый контейнер, может содержать несколько аудиодорожек и субтитров. Подходит для HD-архивации. |
| **WebM** | Распространённый веб-формат видео, открытый. |
| **FLV** | Старый стриминговый формат эпохи Flash, полезен для архивного материала. |
| **WMV** | Windows Media Video, экосистема Windows. |

## Как выбрать

- **Универсальный обмен** -> аудио MP3, видео MP4
- **Второй проход в экосистеме Apple** -> видео MOV
- **Архивация без потерь** -> аудио WAV или FLAC
- **Веб- или открытые рабочие процессы** -> аудио OGG, видео WebM

## Видео не редактируются

Таймлайн редактора принимает только аудиоклипы. Видеофайлы могут быть только «источником дорожек» — сам редактор их не режет.

## Полностью локально

Будь то аудио или видео, всё декодирование, кодирование и перезапись выполняются на iPhone. Файлы не покидают устройство.
