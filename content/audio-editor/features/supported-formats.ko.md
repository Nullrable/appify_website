## 지원 포맷 전체 목록

이 페이지는 치트 시트입니다 — Audio Editor가 지원하는 모든 오디오 및 비디오 포맷과 어떤 상황에서 어떤 것을 골라야 할지를 정리했습니다.

입력과 출력은 서로 다른 포맷 집합입니다: 앱은 오디오 10종을 읽을 수 있지만, 쓸 수 있는 것은 4종뿐입니다. 비디오는 읽기만 가능하며 에디터 본체에서는 열리지 않습니다.

## 오디오 입력 포맷(10종)

에디터는 다음 10종 오디오 파일을 열 수 있습니다 — 멀티트랙 편집, 엔환스, 변환(compress / merge) 모두 이들을 입력으로 받습니다:

| 포맷 | 적합한 상황 |
|---|---|
| **MP3** | 범용 플레이어, 차량 시스템, 이메일 첨부. 기본 선택. |
| **WAV** | 무손실 마스터, 믹싱·보관·재작업에 적합. |
| **M4A** | AAC의 컨테이너 버전, Apple 생태계에서 흔함. |
| **AAC** | Apple 생태계 기본, 작은 크기에 디테일이 좋음. |
| **FLAC** | 무손실 압축, WAV의 절반 정도 크기. |
| **OGG** | 오픈소스 컨테이너, 일부 프로 플레이어가 선호. |
| **Opus** | 현대적인 저지연 코덱, 음성 회의·팟캐스트·스트리밍에서 흔함. |
| **AIFF** | macOS / Logic 생태계 기본, 무손실. |
| **AMR** | 초기 휴대폰 통화 녹음 포맷, 3GPP 표준. |
| **CAF** | Apple Core Audio 컨테이너, iOS 후처리에 적합. |

## 오디오 출력 포맷(4종)

에디터, 멀티트랙 엔환스, 변환은 최종적으로 다음 4종 중 하나로만 기록할 수 있습니다:

| 포맷 | 적합한 상황 |
|---|---|
| **MP3** | 범용 기본, 거의 모든 기기와 플레이어가 인식. |
| **WAV** | 무손실 마스터, 재작업이나 보관에 적합. |
| **FLAC** | 무손실 압축, WAV의 절반 정도 크기. |
| **OGG** | 오픈소스 컨테이너, 일부 프로 장비가 선호. |

## 비디오 포맷(8종)

비디오 파일은 에디터 본체에서 열리지 않습니다. "오디오 트랙의 출처" 역할만 합니다:

| 포맷 | 적합한 상황 |
|---|---|
| **MP4** | 범용, 거의 모든 기기와 플레이어가 인식. |
| **MOV** | Apple 생태계 기본, iMovie, Final Cut, Logic 모두 수용. |
| **M4V** | iTunes 시대의 비디오 컨테이너, Apple 기기에서 MP4와 유사하게 동작. |
| **AVI** | 오래된 컨테이너, 레거시 Windows 앱 호환성이 가장 좋음. |
| **MKV** | 오픈소스 컨테이너, 다중 오디오 트랙과 자막 저장 가능. HD 수집에 적합. |
| **WebM** | 웹 비디오에서 흔함, 오픈소스. |
| **FLV** | 구 Flash 시대 스트리밍 포맷, 레거시 영상 변환용. |
| **WMV** | Windows Media Video, Windows 생태계. |

## 선택 가이드

- **범용 공유** → MP3 오디오, MP4 비디오
- **Apple 생태계 후처리** → MOV 비디오
- **무손실 보관** → WAV 또는 FLAC 오디오
- **웹·오픈소스 워크플로우** → OGG 오디오, WebM 비디오

## 비디오는 편집되지 않습니다

에디터 타임라인은 오디오 클립만 받습니다. 비디오 파일은 "트랙 출처" 역할만 할 뿐, 에디터가 직접 자르지는 않습니다.

## 완전 로컬 처리

오디오와 비디오를 막론하고 모든 디코딩·인코딩·재작성은 iPhone에서 이루어지며 파일은 기기를 떠나지 않습니다.
