## قائمة التنسيقات الكاملة

هذه الصفحة ورقة مرجعية سريعة — جميع تنسيقات الصوت والفيديو التي يدعمها محرر الصوت، ومتى تختار كلًا منها.

الإدخال والإخراج مجموعتان مختلفتان من التنسيقات: يمكن للتطبيق قراءة 10 تنسيقات صوت، لكنه لا يكتب سوى 4. الفيديو للقراءة فقط ولا يفتحه المحرر مباشرةً.

## تنسيقات إدخال الصوت (10)

يفتح المحرر ملفات الصوت العشر التالية — التحرير متعدد المسارات، والتحسين، والتحويل (compress / merge) جميعها تقبلها كإدخال:

| التنسيق | متى يُستخدم |
|---|---|
| **MP3** | مشغلات عامة، أنظمة السيارات، مرفقات البريد. الاختيار الافتراضي. |
| **WAV** | ملف رئيسي بدون فقدان، مثالي للمزج والأرشفة وإعادة التحرير. |
| **M4A** | نسخة الحاوية من AAC، شائعة في منظومة Apple. |
| **AAC** | معيار منظومة Apple، تفاصيل جيدة بحجم صغير. |
| **FLAC** | بدون فقدان لكنه مضغوط — نحو نصف حجم WAV. |
| **OGG** | حاوية مفتوحة المصدر، يفضلها بعض المشغلات الاحترافية. |
| **Opus** | ترميز حديث بزمن انتقال منخفض، شائع في اجتماعات الصوت والبودكاست والبث. |
| **AIFF** | معيار منظومة macOS / Logic، بدون فقدان. |
| **AMR** | تنسيق قديم لتسجيلات المكالمات على الهواتف، معيار 3GPP. |
| **CAF** | حاوية Apple Core Audio، مثالية للمعالجة اللاحقة على iOS. |

## تنسيقات إخراج الصوت (4)

لا يمكن للمحرر وتحسين المسارات المتعددة والتحويل عند التصدير سوى كتابة أحد هذه التنسيقات الأربعة:

| التنسيق | متى يُستخدم |
|---|---|
| **MP3** | المعيار العام، تعتمده تقريبًا كل الأجهزة والمشغلات. |
| **WAV** | ملف رئيسي بدون فقدان، مثالي لإعادة التحرير أو الأرشفة. |
| **FLAC** | بدون فقدان لكنه مضغوط، نحو نصف حجم WAV. |
| **OGG** | حاوية مفتوحة المصدر، يفضلها بعض الأجهزة الاحترافية. |

## تنسيقات الفيديو (8)

ملفات الفيديو **لا** يفتحها المحرر مباشرةً. إنها تعمل فقط بوصفها «مصدرًا لمسارات الصوت»:

| التنسيق | متى يُستخدم |
|---|---|
| **MP4** | عام، تعتمده تقريبًا كل الأجهزة والمشغلات. |
| **MOV** | معيار منظومة Apple — iMovie و Final Cut و Logic تقبله. |
| **M4V** | حاوية فيديو من عصر iTunes، تتصرف مثل MP4 على أجهزة Apple. |
| **AVI** | حاوية قديمة، أفضل توافق مع تطبيقات Windows القديمة. |
| **MKV** | حاوية مفتوحة المصدر، يمكنها حمل مسارات صوت وترجمة متعددة. جيد لأرشفة HD. |
| **WebM** | تنسيق فيديو ويب شائع، مفتوح المصدر. |
| **FLV** | تنسيق بث قديم من عصر Flash، مفيد للمواد القديمة. |
| **WMV** | Windows Media Video، منظومة Windows. |

## كيف تختار

- **مشاركة عامة** -> صوت MP3، فيديو MP4
- **تمريرة ثانية في منظومة Apple** -> فيديو MOV
- **أرشفة بدون فقدان** -> صوت WAV أو FLAC
- **سير عمل ويب أو مفتوح المصدر** -> صوت OGG، فيديو WebM

## الفيديو لا يُحرَّر

لا يقبل الخط الزمني للمحرر سوى مقاطع الصوت. لا يمكن لملفات الفيديو أن تعمل إلا بوصفها «مصدرًا للمسارات» — المحرر نفسه لا يقصها.

## محلي بالكامل

سواء أكان الصوت أم الفيديو، فإن جميع عمليات فك التشفير والترميز وإعادة الكتابة تتم على iPhone. لا تغادر الملفات الجهاز.
