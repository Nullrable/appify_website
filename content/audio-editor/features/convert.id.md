## Konversi Format Audio

Rekaman datang dengan format yang salah — butuh MP3 malah dapat FLAC, butuh master WAV ternyata hanya ada M4A. Konverter menulis ulang file ke container dan bitrate yang Anda pilih, tanpa menyentuh yang asli.

## Format input (10)

Konverter menerima 10 format audio input. Apapun sumbernya — lossless, lossy, atau hasil ekstrak video — alurnya sama:

| Format | Kapan dipakai |
|---|---|
| **MP3** | Pemutar universal, sistem mobil, lampiran email. Pilihan bawaan. |
| **WAV** | Master lossless, ideal untuk mixing, arsip, atau penyuntingan ulang. |
| **M4A** | Versi container AAC, lazim di ekosistem Apple. |
| **AAC** | Bawaan ekosistem Apple, detail baik di ukuran kecil. |
| **FLAC** | Lossless terkompresi, kira-kira separuh ukuran WAV. |
| **OGG** | Container sumber terbuka, disukai sebagian pemutar profesional. |
| **Opus** | Codec latensi-rendah modern, lazim di rapat suara dan podcast. |
| **AIFF** | Bawaan ekosistem macOS / Logic, lossless. |
| **AMR** | Format rekaman panggilan ponsel awal, standar 3GPP. |
| **CAF** | Container Apple Core Audio, ideal untuk pascaproduksi iOS. |

## Format output (4)

Hasil ekspor hanya bisa jatuh di satu dari 4 container ini:

| Format | Kapan dipakai |
|---|---|
| **MP3** | Bawaan universal, dikenali hampir semua perangkat dan pemutar. |
| **WAV** | Master lossless, ideal untuk penyuntingan ulang atau arsip. |
| **FLAC** | Lossless terkompresi, kira-kira separuh ukuran WAV. |
| **OGG** | Container sumber terbuka, disukai sebagian perangkat profesional. |

## Memilih bitrate

Untuk MP3 dan OGG, pilih bitrate sebelum mengekspor. Patokan yang sering dipakai:

- **128 kbps** - suara, podcast, saat ukuran lebih penting daripada detail
- **192 kbps** - titik tengah harian untuk musik
- **256 kbps** - nyaris tak bisa dibedakan dari lossless bagi kebanyakan pendengar
- **320 kbps** - langit-langit MP3, saat setiap kilobit berharga

WAV dan FLAC bersifat bit-perfect — output sama dengan input sampai level byte.

## Pemrosesan batch

Masukkan file sebanyak yang Anda butuhkan. Antrean berjalan berurutan, dan satu pilihan bitrate/format berlaku untuk seluruh batch. Antrean panjang tetap jalan di latar; tutup aplikasi dan kembali lagi untuk memantau progres.

## Asli tetap aman

Sumber tidak pernah ditimpa. File baru pertama-tama ditulis ke sandbox aplikasi, dengan nama mengikuti sumber dan ekstensi baru. Baru setelah Anda mengonfirmasi hasil ekspor, aplikasi menawarkan "Simpan ke File" — sementara itu, file asli tetap di tempat semula.
