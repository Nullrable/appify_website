## 音频格式转换

一份录音的格式不对路 - 需要 MP3 时拿到 FLAC,需要 WAV 母带时只有 M4A。转换器按你选的容器、码率重写文件,原文件全程不动。

## 输入格式(10 种)

转换器接受以下 10 种音频输入。无损、有损、从视频里抽出来的,流程都一样:

| 格式 | 适合场景 |
|---|---|
| **MP3** | 通用播放器、车载系统、邮件附件。默认首选。 |
| **WAV** | 无损母带,适合混音、存档、二次剪辑。 |
| **M4A** | AAC 的容器版本,Apple 生态常用。 |
| **AAC** | Apple 生态首选,细节好、体积小。 |
| **FLAC** | 压缩后的无损,体积约为 WAV 的一半。 |
| **OGG** | 开源容器,部分专业播放器偏好。 |
| **Opus** | 现代低延迟编码,语音会议、播客常见。 |
| **AIFF** | macOS / Logic 生态首选,无损。 |
| **AMR** | 早期手机通话录音格式,3GPP 标准。 |
| **CAF** | Apple Core Audio 容器,适合 iOS 二次处理。 |

## 输出格式(4 种)

最终落盘只能是以下 4 种之一:

| 格式 | 适合场景 |
|---|---|
| **MP3** | 通用首选,几乎所有设备和播放器都认。 |
| **WAV** | 无损母带,适合二次剪辑或存档。 |
| **FLAC** | 压缩后的无损,体积约为 WAV 的一半。 |
| **OGG** | 开源容器,部分专业设备偏好。 |

## 怎么选码率

MP3 和 OGG 可以在导出前挑码率。常见档位:

- **128 kbps** - 语音、播客,体积比细节重要时
- **192 kbps** - 日常听音乐的中庸选择
- **256 kbps** - 大部分听众听不出与无损的差别
- **320 kbps** - MP3 的天花板,每一 bit 都要珍惜时

WAV 和 FLAC 是 bit-perfect,出啥进啥,字节级一致。

## 批量处理

想塞多少文件都行。队列按顺序处理,整批共用一个码率 / 格式。队列很长时后台继续跑,关掉 app 稍后回来看进度就行。

## 原文件安全

源文件从不会被覆盖。新文件先落到 app 沙盒里,文件名沿用源名加新扩展名。等你确认导出没问题了,app 才会提示"存储到文件" — 原文件仍在你原来的位置。

## 完全在本地

解码、重编码、写入全部在 iPhone 上完成,不上传、不经过服务器、不等网络往返 — 飞行模式也照常工作。
