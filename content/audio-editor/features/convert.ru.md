## Конвертер форматов аудио

Запись приходит не в том формате - нужен MP3, а прислали FLAC, или нужен мастер WAV, а есть только M4A. Конвертер переписывает файл в выбранный контейнер с выбранным битрейтом, не трогая оригинал.

## Входные форматы (10)

Конвертер принимает любой из этих 10 аудиоформатов. Что бы ни было на входе - без потерь, с потерями или извлечённое из видео, - порядок действий один и тот же:

| Формат | Когда подходит |
|---|---|
| **MP3** | Универсальные плееры, автомобильные системы, вложения в почту. Выбор по умолчанию. |
| **WAV** | Мастер без потерь, идеален для сведения, архива или повторного монтажа. |
| **M4A** | Контейнерная версия AAC, обычная в экосистеме Apple. |
| **AAC** | Стандарт экосистемы Apple, хорошая детализация при малом размере. |
| **FLAC** | Без потерь, но сжатый - примерно вдвое меньше WAV. |
| **OGG** | Открытый контейнер, предпочитаемый частью профессиональных плееров. |
| **Opus** | Современный кодек с низкой задержкой, обычен в голосовых встречах и подкастах. |
| **AIFF** | Стандарт экосистемы macOS / Logic, без потерь. |
| **AMR** | Ранний формат записи мобильных звонков, стандарт 3GPP. |
| **CAF** | Контейнер Apple Core Audio, идеален для пост-обработки на iOS. |

## Выходные форматы (4)

Результат может оказаться только в одном из этих 4 контейнеров:

| Формат | Когда подходит |
|---|---|
| **MP3** | Универсальный стандарт, распознаётся практически любым устройством и плеером. |
| **WAV** | Мастер без потерь, идеален для повторного монтажа или архива. |
| **FLAC** | Без потерь, но сжатый, примерно вдвое меньше WAV. |
| **OGG** | Открытый контейнер, предпочитаемый частью профессиональных устройств. |

## Выбор битрейта

Для MP3 и OGG битрейт выбирается до экспорта. Распространённые значения:

- **128 кбит/с** - речь, подкасты, когда размер важнее деталей
- **192 кбит/с** - повседневная середина для музыки
- **256 кбит/с** - почти неотличимо от lossless для большинства слушателей
- **320 кбит/с** - потолок MP3, когда важен каждый килобит

WAV и FLAC побитово точные: выход совпадает со входом до байта.

## Пакетная обработка

Добавляйте сколько угодно файлов. Очередь идёт по порядку, и один выбор битрейта/формата применяется ко всей партии. Длинные очереди продолжают работать в фоне; закройте приложение и вернитесь позже посмотреть прогресс.

## Оригиналы в безопасности

Источник никогда не перезаписывается. Новый файл сначала попадает в песочницу приложения с именем на основе источника и новым расширением. Предложение «Сохранить в Файлы» появляется только после того, как вы подтвердите результат экспорта, - а оригинал всё это время остаётся на своём месте.

## Полностью локально

Декодирование, перекодирование и запись идут на iPhone. Без выгрузки, без серверов, без ожидания сетевого обмена - даже в авиарежиме всё работает.
