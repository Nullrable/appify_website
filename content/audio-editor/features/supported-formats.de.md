## Vollständige Formatliste

Diese Seite ist eine Übersicht - jedes Audio- und Videoformat, das der Audio-Editor unterstützt, und wann Sie welches wählen.

Eingabe und Ausgabe sind zwei unterschiedliche Formate: Die App kann 10 Audioformate lesen, aber nur 4 schreiben. Videos werden nur gelesen und nicht direkt im Editor geöffnet.

## Audio-Eingabeformate (10)

Der Editor öffnet diese 10 Audiodateien - Mehrspur-Bearbeitung, Verbesserung und Konvertierung (compress / merge) akzeptieren sie alle als Eingabe:

| Format | Eignung |
|---|---|
| **MP3** | Universelle Player, Autoanlagen, E-Mail-Anhänge. Standardwahl. |
| **WAV** | Verlustfreies Master, ideal zum Mischen, Archivieren oder Nachbearbeiten. |
| **M4A** | Die Container-Variante von AAC, verbreitet im Apple-Ökosystem. |
| **AAC** | Standard im Apple-Ökosystem, gute Details bei kleiner Größe. |
| **FLAC** | Verlustfrei, aber komprimiert - etwa halb so groß wie WAV. |
| **OGG** | Open-Source-Container, bevorzugt von einigen professionellen Playern. |
| **Opus** | Moderner Codec mit niedriger Latenz, verbreitet bei Sprachmeetings, Podcasts und Streaming. |
| **AIFF** | Standard im macOS / Logic-Ökosystem, verlustfrei. |
| **AMR** | Frühes Mobiltelefon-Aufzeichnungsformat, 3GPP-Standard. |
| **CAF** | Apple-Core-Audio-Container, ideal für iOS-Weiterverarbeitung. |

## Audio-Ausgabeformate (4)

Editor, Mehrspur-Verbesserung und Konvertierung können beim Export nur eines dieser 4 Formate schreiben:

| Format | Eignung |
|---|---|
| **MP3** | Universeller Standard, wird von praktisch jedem Gerät und Player erkannt. |
| **WAV** | Verlustfreies Master, ideal zum Nachbearbeiten oder Archivieren. |
| **FLAC** | Verlustfrei, aber komprimiert, etwa halb so groß wie WAV. |
| **OGG** | Open-Source-Container, bevorzugt von einigen professionellen Geräten. |

## Videoformate (8)

Videodateien werden **nicht** direkt im Editor geöffnet. Sie dienen ausschließlich als „Quelle für Audiospuren":

| Format | Eignung |
|---|---|
| **MP4** | Universell, wird von praktisch jedem Gerät und Player erkannt. |
| **MOV** | Standard im Apple-Ökosystem - iMovie, Final Cut, Logic akzeptieren es. |
| **M4V** | Video-Container aus der iTunes-Ära, verhält sich auf Apple-Geräten wie MP4. |
| **AVI** | Klassischer Container, beste Kompatibilität mit älteren Windows-Apps. |
| **MKV** | Open-Source-Container, kann mehrere Audiospuren und Untertitel enthalten. Gut für HD-Archivierung. |
| **WebM** | Verbreitetes Webvideo-Format, Open Source. |
| **FLV** | Altes Streaming-Format aus der Flash-Ära, nützlich für älteres Material. |
| **WMV** | Windows Media Video, Windows-Ökosystem. |

## Wie wählen

- **Universelles Teilen** -> MP3-Audio, MP4-Video
- **Zweiter Durchgang im Apple-Ökosystem** -> MOV-Video
- **Verlustfreie Archivierung** -> WAV- oder FLAC-Audio
- **Web- oder Open-Source-Workflows** -> OGG-Audio, WebM-Video

## Videos werden nicht bearbeitet

Die Zeitleiste des Editors nimmt nur Audioclips an. Videodateien können nur als „Spurquelle" dienen - der Editor selbst schneidet sie nicht.

## Komplett lokal

Ob Audio oder Video - Decodierung, Codierung und Umschreiben laufen auf dem iPhone. Dateien verlassen das Gerät nicht.
