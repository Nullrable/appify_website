## 오디오 포맷 변환

들어온 음원의 포맷이 맞지 않습니다 — MP3가 필요한데 FLAC이거나, WAV 마스터가 필요한데 M4A뿐일 때. 변환기는 선택한 컨테이너와 비트레이트로 파일을 다시 쓰고, 원본은 끝까지 건드리지 않습니다.

## 입력 포맷(10종)

변환기는 다음 10종 오디오 입력을 받습니다. 무손실이든 손실이든, 영상에서 추출한 것이든 흐름은 동일합니다:

| 포맷 | 적합한 상황 |
|---|---|
| **MP3** | 범용 플레이어, 차량 시스템, 이메일 첨부. 기본 선택. |
| **WAV** | 무손실 마스터, 믹싱·보관·재작업에 적합. |
| **M4A** | AAC의 컨테이너 버전, Apple 생태계에서 흔함. |
| **AAC** | Apple 생태계 기본, 작은 크기에 디테일이 좋음. |
| **FLAC** | 무손실 압축, WAV의 절반 정도 크기. |
| **OGG** | 오픈소스 컨테이너, 일부 프로 플레이어가 선호. |
| **Opus** | 현대적인 저지연 코덱, 음성 회의·팟캐스트에서 흔함. |
| **AIFF** | macOS / Logic 생태계 기본, 무손실. |
| **AMR** | 초기 휴대폰 통화 녹음 포맷, 3GPP 표준. |
| **CAF** | Apple Core Audio 컨테이너, iOS 후처리에 적합. |

## 출력 포맷(4종)

내보내기 결과는 다음 4종 중 하나로만 떨어집니다:

| 포맷 | 적합한 상황 |
|---|---|
| **MP3** | 범용 기본, 거의 모든 기기와 플레이어가 인식. |
| **WAV** | 무손실 마스터, 재작업이나 보관에 적합. |
| **FLAC** | 무손실 압축, WAV의 절반 정도 크기. |
| **OGG** | 오픈소스 컨테이너, 일부 프로 장비가 선호. |

## 비트레이트 고르기

MP3와 OGG는 내보내기 전에 비트레이트를 고를 수 있습니다. 흔한 선택지:

- **128 kbps** - 음성·팟캐스트, 크기가 디테일보다 중요할 때
- **192 kbps** - 일상적인 음악 감상의 중간 지점
- **256 kbps** - 대부분의 청자에겐 무손실과 구별이 어려움
- **320 kbps** - MP3의 천장, 비트 하나까지 아까울 때

WAV와 FLAC은 비트 퍼펙트로, 입출력이 바이트 단위로 일치합니다.

## 배치 처리

파일은 필요한 만큼 한꺼번에 넣을 수 있습니다. 큐는 순서대로 진행되며 비트레이트와 포맷 선택은 배치 전체에 적용됩니다. 긴 큐는 백그라운드에서 계속 도므로, 앱을 닫고 나중에 진행 상황을 확인하러 돌아와도 됩니다.

## 원본은 안전합니다

원본 파일이 덮어써지지는 않습니다. 새 파일은 먼저 앱 샌드박스에 쓰여지고, 파일명은 원본 이름에 새 확장자가 붙은 형태입니다. 내보내기 결과를 확인한 뒤에야 "파일에 저장" 안내가 나오며, 그 순간에도 원본은 본래 자리에 그대로 있습니다.

## 완전 로컬 처리

디코딩·재인코딩·쓰기까지 모두 iPhone에서 이루어집니다. 업로드도, 서버 경유도, 네트워크 왕복 대기도 없어 — 비행기 모드에서도 그대로 동작합니다.
