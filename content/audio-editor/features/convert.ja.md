## 音声フォーマット変換

録音のフォーマットが合わない - MP3 がほしいのに FLAC、WAV マスターがほしいのに M4A しかない。変換器は指定したコンテナとビットレートでファイルを書き直し、元ファイルには一切手を付けません。

## 入力フォーマット(10 種)

変換器が受け付ける入力は以下の 10 種です。無損、圧縮可逆、動画から取り出したもの、いずれも流れは同じ:

| フォーマット | 使う場面 |
|---|---|
| **MP3** | 汎用プレーヤー、車載システム、メール添付。デフォルトの選択肢。 |
| **WAV** | 可逆のマスター、ミックス・アーカイブ・再編集向け。 |
| **M4A** | AAC のコンテナ版、Apple エコシステムで一般的。 |
| **AAC** | Apple エコシステムのデフォルト、軽量でディテール良好。 |
| **FLAC** | 圧縮可逆、WAV のおよそ半分のサイズ。 |
| **OGG** | オープンソースのコンテナ、一部のプロ向けプレーヤーが好む。 |
| **Opus** | 最新の低遅延コーデック、音声会議やポッドキャストで一般的。 |
| **AIFF** | macOS / Logic エコシステムのデフォルト、可逆。 |
| **AMR** | 初期の携帯通話録音フォーマット、3GPP 規格。 |
| **CAF** | Apple Core Audio コンテナ、iOS の後処理に適する。 |

## 出力フォーマット(4 種)

書き出し先は次の 4 種のいずれかに限られます:

| フォーマット | 使う場面 |
|---|---|
| **MP3** | 汎用のデフォルト、ほぼすべての端末とプレーヤーが対応。 |
| **WAV** | 可逆のマスター、再編集やアーカイブ向け。 |
| **FLAC** | 圧縮可逆、WAV のおよそ半分のサイズ。 |
| **OGG** | オープンソースのコンテナ、一部のプロ向け機器が好む。 |

## ビットレートの選び方

MP3 と OGG は書き出し前にビットレートを選べます。一般的な目安:

- **128 kbps** - 音声・ポッドキャスト、サイズ重視のとき
- **192 kbps** - 日常的に音楽を聴くときの真ん中
- **256 kbps** - 多くのリスナーには無損失と聞き分けがつかない
- **320 kbps** - MP3 の天井、1 bit たりとも無駄にできないとき

WAV と FLAC はビットパーフェクトで、出力は入力とバイト単位で一致します。

## バッチ処理

ファイルは何個でも投入できます。キューは順番に処理され、ビットレートと形式の選択はバッチ全体に適用されます。長いキューはバックグラウンドで動き続けるので、アプリを閉じて後で進捗を見に戻れます。

## 元ファイルは守られる

元ファイルが上書きされることはありません。新しいファイルはまずアプリのサンドボックスに書き出され、ファイル名は元ファイル名に新しい拡張子を付けたものになります。書き出し内容を確認したあとにだけ「ファイルに保存」が促され、その時点でも元ファイルは元の場所にあります。

## 完全ローカル

デコード・再エンコード・書き込みはすべて iPhone 上で完結します。アップロードもサーバー経由もなく、ネットワークの往復待ちも発生しないため、機内モードでも問題なく動作します。
