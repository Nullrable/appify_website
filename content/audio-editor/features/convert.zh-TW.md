## 音訊格式轉換

一份錄音的格式不對路 - 需要 MP3 時拿到 FLAC,需要 WAV 母帶時只有 M4A。轉換器依你選的容器、位元率重寫檔案,原檔全程不動。

## 輸入格式(10 種)

轉換器接受以下 10 種音訊輸入。無損、有損、從影片抽出的,流程都一樣:

| 格式 | 適合場景 |
|---|---|
| **MP3** | 通用播放器、車載系統、郵件附件。預設首選。 |
| **WAV** | 無損母帶,適合混音、封存、二次剪輯。 |
| **M4A** | AAC 的容器版本,Apple 生態常用。 |
| **AAC** | Apple 生態預設,細節好、體積小。 |
| **FLAC** | 壓縮後的無損,體積約為 WAV 的一半。 |
| **OGG** | 開放原始碼容器,部分專業播放器偏好。 |
| **Opus** | 現代低延遲編碼,語音會議、播客常見。 |
| **AIFF** | macOS / Logic 生態預設,無損。 |
| **AMR** | 早期手機通話錄音格式,3GPP 標準。 |
| **CAF** | Apple Core Audio 容器,適合 iOS 後續處理。 |

## 輸出格式(4 種)

最終落盤只能是以下 4 種之一:

| 格式 | 適合場景 |
|---|---|
| **MP3** | 通用預設,幾乎所有裝置與播放器都認得。 |
| **WAV** | 無損母帶,適合二次剪輯或封存。 |
| **FLAC** | 壓縮後的無損,體積約為 WAV 的一半。 |
| **OGG** | 開放原始碼容器,部分專業設備偏好。 |

## 怎麼選位元率

MP3 和 OGG 可以在匯出前挑位元率。常見檔位:

- **128 kbps** - 語音、播客,體積比細節重要時
- **192 kbps** - 日常聽音樂的中庸選擇
- **256 kbps** - 大部分聽眾聽不出與無損的差別
- **320 kbps** - MP3 的天花板,每一 bit 都要珍惜時

WAV 與 FLAC 是 bit-perfect,出什麼進什麼,位元組級一致。

## 批次處理

想塞多少檔案都行。佇列按順序處理,整批共用一個位元率 / 格式。佇列很長時背景繼續跑,關掉 app 稍後回來看進度即可。

## 原檔安全

來源檔案從不會被覆寫。新檔先落到 app 沙盒裡,檔名沿用來源檔名加新副檔名。等你確認匯出沒問題了,app 才會提示「儲存到檔案」 — 原檔仍在你原來的位置。
