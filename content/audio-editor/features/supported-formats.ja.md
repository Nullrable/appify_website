## 対応フォーマット一覧

このページはチートシートです — Audio Editor に対応する音声と動画のフォーマットすべてと、どの場面でどれを選ぶかを一覧します。

入力と出力は別々のフォーマット集合です:アプリは 10 種類の音声を読めますが、書けるのは 4 種類だけ。動画は読み込みのみで、エディタ本体では開けません。

## 音声入力フォーマット(10 種)

エディタは以下の 10 種類の音声ファイルを開けます — マルチトラック編集、エンハンス、変換(compress / merge)はいずれもこれらを入力として受け付けます:

| フォーマット | 向いている場面 |
|---|---|
| **MP3** | 汎用プレーヤー、車載システム、メール添付。デフォルトの第一選択。 |
| **WAV** | 非圧縮マスター、ミキシング・アーカイブ・再編集向き。 |
| **M4A** | AAC のコンテナ版、Apple エコシステムで一般的。 |
| **AAC** | Apple エコシステムの定番、サイズが小さくディテールが良い。 |
| **FLAC** | 非可逆圧縮ロスレス、WAV の半分ほどのサイズ。 |
| **OGG** | オープンソースコンテナ、一部のプロプレーヤーが好む。 |
| **Opus** | モダンな低遅延コーデック、音声会議・ポッドキャスト・ストリーミングで一般的。 |
| **AIFF** | macOS / Logic エコシステムの定番、非圧縮。 |
| **AMR** | 初期の携帯電話通話録音フォーマット、3GPP 標準。 |
| **CAF** | Apple Core Audio コンテナ、iOS での二次処理向き。 |

## 音声出力フォーマット(4 種)

エディタ、マルチトラックエンハンス、変換は最終的に書き出す際に以下の 4 種類のいずれかにしか落とせません:

| フォーマット | 向いている場面 |
|---|---|
| **MP3** | 汎用デフォルト、ほぼすべての端末とプレーヤーが認識。 |
| **WAV** | 非圧縮マスター、再編集やアーカイブ向き。 |
| **FLAC** | 非可逆圧縮ロスレス、WAV の半分ほどのサイズ。 |
| **OGG** | オープンソースコンテナ、一部のプロ機器が好む。 |

## 動画フォーマット(8 種)

動画ファイルはエディタ本体では開かれません、「音声トラックの出所」としてだけ使われます:

| フォーマット | 向いている場面 |
|---|---|
| **MP4** | 汎用、ほぼすべての端末とプレーヤーが認識。 |
| **MOV** | Apple エコシステムの定番、iMovie、Final Cut、Logic がそのまま受け付ける。 |
| **M4V** | iTunes 世代の動画コンテナ、Apple 端末では MP4 と似た挙動。 |
| **AVI** | 老舗コンテナ、レガシー Windows アプリの互換性が一番。 |
| **MKV** | オープンソースコンテナ、複数音声・複数字幕を格納可能。HD コレクション向き。 |
| **WebM** | ウェブ動画で一般的、オープンソース。 |
| **FLV** | 旧 Flash 世代のストリーミング形式、レガシー素材の変換用。 |
| **WMV** | Windows Media Video、Windows エコシステム。 |

## 選び方の指針

- **汎用共有** → MP3 音声、MP4 動画
- **Apple エコシステムでの二次処理** → MOV 動画
- **ロスレスアーカイブ** → WAV または FLAC 音声
- **ウェブ・オープンソース系ワークフロー** → OGG 音声、WebM 動画

## 動画は編集されません

エディタのタイムラインが受け付けるのは音声クリップだけです。動画ファイルは「音声の出所」としてだけ機能し、エディタ側でカットはできません。

## 完全ローカル

音声・動画を問わず、すべてのデコード・エンコード・書き換えは iPhone 上で行われ、ファイルは端末から一切出ません。
