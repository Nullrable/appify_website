## Audio format converter

A recording lands in the wrong format - FLAC when you need MP3, M4A when a WAV master would do. The converter rewrites the file into the container you pick, at the bitrate you pick, without touching the original.

## Input formats (10)

The converter accepts any of these 10 audio formats. Whether the source is lossless, lossy, or pulled from a video, the workflow is the same:

| Format | When to use |
|---|---|
| **MP3** | Universal players, car systems, email attachments. Default pick. |
| **WAV** | Lossless master, ideal for mixing, archival, or re-editing. |
| **M4A** | The container version of AAC, common in the Apple ecosystem. |
| **AAC** | Apple ecosystem default, great detail at small size. |
| **FLAC** | Lossless but compressed - roughly half the size of WAV. |
| **OGG** | Open-source container, preferred by some professional players. |
| **Opus** | Modern low-latency codec, common in voice meetings and podcasts. |
| **AIFF** | macOS / Logic ecosystem default, lossless. |
| **AMR** | Early mobile call-recording format, 3GPP standard. |
| **CAF** | Apple Core Audio container, ideal for iOS post-processing. |

## Output formats (4)

Export can only land in one of these 4 containers:

| Format | When to use |
|---|---|
| **MP3** | Universal default, recognized by virtually every device and player. |
| **WAV** | Lossless master, ideal for re-editing or archival. |
| **FLAC** | Lossless but compressed, roughly half the size of WAV. |
| **OGG** | Open-source container, preferred by some professional devices. |

## Choosing a bitrate

For MP3 and OGG, pick the bitrate before exporting. Common picks:

- **128 kbps** - speech, podcasts, anything where small file size matters more than detail
- **192 kbps** - the everyday middle ground for music
- **256 kbps** - close-to-transparent for most listeners
- **320 kbps** - the MP3 ceiling, for the moments where every kilobit counts

WAV and FLAC are bit-perfect - what comes out matches what goes in, byte for byte.

## Batch processing

Drop in as many files as you need. The queue runs in order, and a single bitrate/format choice applies to the whole batch. Large queues keep working in the background; close the app and come back when they're done.

## Originals are safe

Nothing overwrites the source. The new file lands in the app sandbox first, named after the source with the new extension. Only after you confirm the export does the app offer to "Save to Files" - the original is still where you left it.

## Fully local

Decoding, re-encoding, and writing all run on the iPhone. No upload, no server pass, no waiting for a network round-trip - even airplane mode is fine.
