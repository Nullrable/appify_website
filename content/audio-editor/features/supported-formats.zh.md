## 完整格式清单

这篇文章是一份速查表 — 音频编辑器支持的音频和视频格式都列在这里,以及什么场景该选哪个。

输入和导出是两套不同的格式集合:app 能读 10 种音频,但只能写 4 种。视频只读、不被编辑器直接打开。

## 音频输入格式(10 种)

编辑器可以打开这 10 种音频文件 — 多轨编辑、增强、转换(compress / merge)都接受它们作为输入:

| 格式 | 适合场景 |
|---|---|
| **MP3** | 通用播放器、车载系统、邮件附件。默认首选。 |
| **WAV** | 无损母带,适合混音、存档、二次剪辑。 |
| **M4A** | AAC 的容器版本,Apple 生态常用。 |
| **AAC** | Apple 生态首选,细节好、体积小。 |
| **FLAC** | 压缩后的无损,体积约为 WAV 的一半。 |
| **OGG** | 开源容器,部分专业播放器偏好。 |
| **Opus** | 现代低延迟编码,语音会议、播客、流媒体常见。 |
| **AIFF** | macOS / Logic 生态首选,无损。 |
| **AMR** | 早期手机通话录音格式,3GPP 标准。 |
| **CAF** | Apple Core Audio 容器,适合 iOS 二次处理。 |

## 音频导出格式(4 种)

编辑器、多轨增强、转换最终落盘时只能写这 4 种之一:

| 格式 | 适合场景 |
|---|---|
| **MP3** | 通用首选,几乎所有设备和播放器都认。 |
| **WAV** | 无损母带,适合二次剪辑或存档。 |
| **FLAC** | 压缩后的无损,体积约为 WAV 一半。 |
| **OGG** | 开源容器,部分专业设备偏好。 |

## 视频格式(8 种)

视频文件**不会**被编辑器直接打开,只作为"音轨来源"使用:

| 格式 | 适合场景 |
|---|---|
| **MP4** | 通用,几乎所有设备和播放器都认。 |
| **MOV** | Apple 生态首选,iMovie、Final Cut、Logic 都吃。 |
| **M4V** | iTunes 时代的视频容器,Apple 设备上跟 MP4 类似。 |
| **AVI** | 老牌容器,Windows 老应用兼容性最好。 |
| **MKV** | 开源容器,能装多音轨、多字幕,适合高清收藏。 |
| **WebM** | 网页视频常用,开源。 |
| **FLV** | 老 Flash 时代的流媒体格式,转给老素材用。 |
| **WMV** | Windows Media Video,Windows 生态。 |

## 怎么选

- **通用分享** → MP3 音频、MP4 视频
- **Apple 生态二次处理** → MOV 视频
- **无损存档** → WAV 或 FLAC 音频
- **网页或开源工作流** → OGG 音频、WebM 视频

## 视频不会被编辑

编辑器时间线只接受音频片段。视频文件只能作为"提供音轨"的来源,不能被编辑器剪辑。

## 完全在本地

无论是音频还是视频,所有解码、编码、重写都在 iPhone 上完成,文件不离开设备。
