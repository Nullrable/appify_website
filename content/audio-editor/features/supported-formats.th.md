## รายการรูปแบบไฟล์ทั้งหมด

หน้านี้เป็นชีตช่วยจำ — รูปแบบเสียงและวิดีโอทั้งหมดที่ตัวแก้ไขเสียงรองรับ พร้อมคำแนะนำว่าเมื่อใดควรเลือกแบบใด

อินพุตและเอาต์พุตเป็นสองชุดที่แตกต่างกัน: แอปอ่านเสียงได้ 10 รูปแบบ แต่เขียนได้เพียง 4 รูปแบบ ส่วนวิดีโอนั้นอ่านได้อย่างเดียวและไม่ได้ถูกเปิดโดยตรงในตัวแก้ไข

## รูปแบบอินพุตเสียง (10 ชนิด)

ตัวแก้ไขสามารถเปิดไฟล์เสียง 10 ชนิดนี้ — การตัดต่อหลายแทร็ก การปรับแต่งเสียง และการแปลง (compress / merge) ต่างรับไฟล์เหล่านี้เป็นอินพุต:

| รูปแบบ | เมื่อใดควรใช้ |
|---|---|
| **MP3** | เครื่องเล่นทั่วไป ระบบในรถยนต์ ไฟล์แนบอีเมล ตัวเลือกเริ่มต้น |
| **WAV** | ต้นฉบับไม่สูญเสียคุณภาพ เหมาะกับการมิกซ์ การเก็บถาวร หรือการตัดต่อซ้ำ |
| **M4A** | เวอร์ชันคอนเทนเนอร์ของ AAC พบบ่อยในระบบนิเวศของ Apple |
| **AAC** | ค่าเริ่มต้นของระบบนิเวศ Apple รายละเอียดดีเมื่อขนาดเล็ก |
| **FLAC** | ไม่สูญเสียคุณภาพแต่มีการบีบอัด ขนาดประมาณครึ่งหนึ่งของ WAV |
| **OGG** | คอนเทนเนอร์โอเพนซอร์ส เครื่องเล่นระดับมืออาชีพบางตัวเลือกใช้ |
| **Opus** | โคเดกสมัยใหม่ที่มีเวลาแฝงต่ำ พบได้ทั่วไปในการประชุมเสียง พอดแคสต์ และการสตรีม |
| **AIFF** | ค่าเริ่มต้นของระบบนิเวศ macOS / Logic ไม่สูญเสียคุณภาพ |
| **AMR** | รูปแบบการบันทึกเสียงสนทนาในโทรศัพท์มือถือยุคแรก มาตรฐาน 3GPP |
| **CAF** | คอนเทนเนอร์ Apple Core Audio เหมาะกับการประมวลผลต่อบน iOS |

## รูปแบบเอาต์พุตเสียง (4 ชนิด)

ตัวแก้ไข การปรับแต่งหลายแทร็ก และการแปลงสามารถเขียนได้เพียงหนึ่งใน 4 รูปแบบนี้เมื่อส่งออก:

| รูปแบบ | เมื่อใดควรใช้ |
|---|---|
| **MP3** | ค่าเริ่มต้นสากล อุปกรณ์และเครื่องเล่นเกือบทุกชนิดรู้จัก |
| **WAV** | ต้นฉบับไม่สูญเสียคุณภาพ เหมาะกับการตัดต่อซ้ำหรือการเก็บถาวร |
| **FLAC** | ไม่สูญเสียคุณภาพแต่มีการบีบอัด ขนาดประมาณครึ่งหนึ่งของ WAV |
| **OGG** | คอนเทนเนอร์โอเพนซอร์ส อุปกรณ์ระดับมืออาชีพบางตัวเลือกใช้ |

## รูปแบบวิดีโอ (8 ชนิด)

ไฟล์วิดีโอ **ไม่** ถูกเปิดโดยตรงในตัวแก้ไข ทำหน้าที่เป็นเพียง «แหล่งที่มาของแทร็กเสียง»:

| รูปแบบ | เมื่อใดควรใช้ |
|---|---|
| **MP4** | สากล อุปกรณ์และเครื่องเล่นเกือบทุกชนิดรู้จัก |
| **MOV** | ค่าเริ่มต้นของระบบนิเวศ Apple — iMovie, Final Cut, Logic รองรับ |
| **M4V** | คอนเทนเนอร์วิดีโอยุค iTunes ทำงานคล้าย MP4 บนอุปกรณ์ Apple |
| **AVI** | คอนเทนเนอร์เก่าแก่ เข้ากันได้ดีที่สุดกับแอป Windows รุ่นเก่า |
| **MKV** | คอนเทนเนอร์โอเพนซอร์ส เก็บแทร็กเสียงและคำบรรยายได้หลายชุด เหมาะกับการเก็บถาวร HD |
| **WebM** | รูปแบบวิดีโอบนเว็บที่ใช้กันทั่วไป โอเพนซอร์ส |
| **FLV** | รูปแบบสตรีมยุค Flash เก่า เหมาะกับการแปลงไฟล์เก่า |
| **WMV** | Windows Media Video ระบบนิเวศของ Windows |

## วิธีเลือก

- **แชร์แบบสากล** -> เสียง MP3 วิดีโอ MP4
- **ประมวลผลซ้ำในระบบนิเวศ Apple** -> วิดีโอ MOV
- **เก็บถาวรแบบไม่สูญเสียคุณภาพ** -> เสียง WAV หรือ FLAC
- **เวิร์กโฟลว์บนเว็บหรือโอเพนซอร์ส** -> เสียง OGG วิดีโอ WebM

## วิดีโอไม่ถูกตัดต่อ

ไทม์ไลน์ของตัวแก้ไขรับเฉพาะคลิปเสียง ไฟล์วิดีโอทำหน้าที่เป็นเพียง «แหล่งที่มาของแทร็ก» เท่านั้น ตัวแก้ไขเองไม่ได้ตัดวิดีโอ

## ทำงานในเครื่องทั้งหมด

ไม่ว่าจะเป็นเสียงหรือวิดีโอ การถอดรหัส การเข้ารหัส และการเขียนไฟล์ใหม่ทั้งหมดเกิดขึ้นบน iPhone ไฟล์จะไม่ออกจากเครื่อง
