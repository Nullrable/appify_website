## 完整格式清單

這篇文章是一份速查表 — 音訊編輯器支援的音訊和影片格式都列在這裡,以及什麼場景該選哪個。

輸入和匯出是兩套不同的格式集合:app 能讀 10 種音訊,但只能寫 4 種。影片只讀、不被編輯器直接開啟。

## 音訊輸入格式(10 種)

編輯器可以開啟這 10 種音訊檔 — 多軌編輯、增強、轉換(compress / merge)都接受它們作為輸入:

| 格式 | 適合場景 |
|---|---|
| **MP3** | 通用播放器、車載系統、郵件附件。預設首選。 |
| **WAV** | 無損母帶,適合混音、封存、二次剪輯。 |
| **M4A** | AAC 的容器版本,Apple 生態常見。 |
| **AAC** | Apple 生態首選,細節好、體積小。 |
| **FLAC** | 壓縮後的無損,體積約為 WAV 的一半。 |
| **OGG** | 開放原始碼容器,部分專業播放器偏好。 |
| **Opus** | 現代低延遲編碼,語音會議、播客、串流媒體常見。 |
| **AIFF** | macOS / Logic 生態首選,無損。 |
| **AMR** | 早期手機通話錄音格式,3GPP 標準。 |
| **CAF** | Apple Core Audio 容器,適合 iOS 二次處理。 |

## 音訊匯出格式(4 種)

編輯器、多軌增強、轉換最終落盤時只能寫這 4 種之一:

| 格式 | 適合場景 |
|---|---|
| **MP3** | 通用首選,幾乎所有裝置和播放器都認。 |
| **WAV** | 無損母帶,適合二次剪輯或封存。 |
| **FLAC** | 壓縮後的無損,體積約為 WAV 一半。 |
| **OGG** | 開放原始碼容器,部分專業設備偏好。 |

## 影片格式(8 種)

影片檔**不會**被編輯器直接開啟,只作為「音軌來源」使用:

| 格式 | 適合場景 |
|---|---|
| **MP4** | 通用,幾乎所有裝置和播放器都認。 |
| **MOV** | Apple 生態首選,iMovie、Final Cut、Logic 都吃。 |
| **M4V** | iTunes 時代的影片容器,Apple 裝置上跟 MP4 類似。 |
| **AVI** | 老牌容器,Windows 老應用相容性最好。 |
| **MKV** | 開放原始碼容器,能裝多音軌、多字幕,適合高畫質收藏。 |
| **WebM** | 網頁影片常用,開放原始碼。 |
| **FLV** | 老 Flash 時代的串流格式,轉給老素材用。 |
| **WMV** | Windows Media Video,Windows 生態。 |

## 怎麼選

- **通用分享** → MP3 音訊、MP4 影片
- **Apple 生態二次處理** → MOV 影片
- **無損封存** → WAV 或 FLAC 音訊
- **網頁或開放原始碼工作流程** → OGG 音訊、WebM 影片

## 影片不會被編輯

編輯器時間軸只接受音訊片段。影片檔只能作為「提供音軌」的來源,不能被編輯器剪輯。

## 完全在本機

無論是音訊還是影片,所有解碼、編碼、重寫都在 iPhone 上完成,檔案不離開裝置。
