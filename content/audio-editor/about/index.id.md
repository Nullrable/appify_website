Audio Editor adalah alat audio yang sepenuhnya lokal untuk iPhone, diatur围绕 tiga kategori: pengeditan, peningkatan, dan konversi. File video dapat dimasukkan untuk mengekstrak trek audionya, tetapi editor sendiri hanya menerima klip audio - semua pemrosesan berjalan lokal di perangkat Anda, dan tidak ada file yang diunggah.

## Tiga kategori

**Pengeditan** - Taruh beberapa klip audio di garis waktu dan potong, bagi, susun ulang, ubah kecepatan, atau balikkan masing-masing secara independen. Setiap klip dapat disimpan sebagai bagian baru; file sumber tetap utuh sampai Anda mengekspor.

**Peningkatan** - Pemisahan kanal, penggabungan kanal, pengurangan noise, peningkatan vokal, normalisasi, pelebaran stereo. Efek-efek ini dapat ditumpuk pada klip yang sama dalam urutan apa pun.

**Konversi** - Membaca 10 format input audio dan mengekspor ke MP3, WAV, FLAC, atau OGG. Juga dapat menarik trek audio dari video MP4, MOV, M4V, AVI, MKV, WebM, FLV, atau WMV. Video tidak pernah dibuka langsung oleh editor - hanya digunakan sebagai "sumber audio."

## Format yang didukung

10 input audio: MP3, WAV, M4A, AAC, FLAC, OGG, Opus, AIFF, AMR, CAF. 4 output audio: MP3, WAV, FLAC, OGG.

8 format video, hanya dibaca sebagai "sumber audio": MP4, MOV, M4V, AVI, MKV, WebM, FLV, WMV. Editor sendiri tidak menerima klip video.

## Sepenuhnya di perangkat

Pengeditan, peningkatan, konversi, ekstraksi, kompresi, penggabungan - setiap operasi berjalan di iPhone Anda. File video, file audio, dan hasil antara tidak pernah meninggalkan perangkat. Satu-satunya panggilan jaringan adalah iklan banner yang ditampilkan di versi gratis pada tiga layar: Beranda, Riwayat, dan Pengaturan, serta validasi langganan melalui RevenueCat.

## Versi gratis dan Pro

Semua fitur dapat digunakan secara gratis. Versi gratis menampilkan iklan banner di tiga layar: Beranda, Riwayat, dan Pengaturan. Pro menghilangkan iklan banner dan memperpanjang otomatis melalui App Store.

## Riwayat dan draf

Setiap tugas dicatat di riwayat, sehingga Anda dapat meninjau parameter atau menjalankannya lagi. Draf di editor multi-track disimpan otomatis saat Anda menyeret - pindah layar dan kembali, pengaturan Anda masih ada.
