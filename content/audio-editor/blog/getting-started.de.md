## Schnellstart

Sie haben den Audio-Editor gerade geöffnet und sehen Mehrspur-Bearbeitung, Verbesserung, Konvertierung und Audio-Extraktion. Wo fangen Sie an? Dieser Leitfaden führt Sie durch den häufigsten Weg - aus vorhandenem Material eine neue Version exportieren.

## Schritt 1: Quelle öffnen

Nach dem App-Start sehen Sie den Werkzeugbereich (Bearbeiten / Verbessern / Konvertieren / Audio extrahieren) und einen Quell-Einstieg. Wählen Sie eine Audiodatei aus dem Album oder Files - beliebige aus MP3, WAV, M4A, AAC, FLAC, OGG, Opus, AIFF, AMR, CAF.

Wenn das Audio aus einem Video stammt, gehen Sie zuerst zu „Audio extrahieren" - ziehen Sie die Tonspur aus dem Video (MOV, MP4, M4V, AVI, MKV, WebM, FLV, WMV) heraus und exportieren Sie sie als Audiodatei. Kehren Sie anschließend zum Bearbeitungs-Flow zurück.

## Schritt 2: Auf die Zeitleiste legen

Öffnen Sie den Mehrspur-Editor. Das gewählte Material landet automatisch auf der Zeitleiste - haben Sie mehrere gewählt, bekommt jede Spur einen eigenen Track. Mit einem einzelnen Clip erhalten Sie einen Track, aber Sie können weiteres Material hinzufügen und zu einem Stück stapeln.

## Schritt 3: Schneiden und neu anordnen

Jeder Clip hat an beiden Enden einen Griff. Ziehen Sie am Anfang, ziehen Sie am Ende, werfen Sie die ungewünschten Teile weg. Sie können einen Clip auch an einem beliebigen Zeitpunkt in zwei Teile teilen und beide Hälften unabhängig bearbeiten. Durch Ziehen eines Clips können Sie die Reihenfolge neu anordnen.

## Schritt 4: Effekte hinzufügen

Jeder Clip kann eine eigene Verbesserungs-Pipeline bekommen:

- **Rauschunterdrückung** - bei Außenaufnahmen zuerst anwenden
- **Stimmenverbesserung** - häufig bei Podcasts und Interviews
- **Lautstärken-Normalisierung** - bei Mehrspur-Arbeiten mit unterschiedlichen Pegeln angleichen
- **Kanaltrennung / -zusammenführung / Stereo-Erweiterung** - je nach Bedarf auswählen

Jeder Effekt lässt sich in Echtzeit vorhören - spielen Sie so lange, bis Sie zufrieden sind.

## Schritt 5: Geschwindigkeit ändern / umkehren (optional)

Brauchen Sie eine andere Geschwindigkeit oder Umkehrung? Steuern Sie das direkt auf der Spur. Ein stufenloser Schieberegler von 0,25× bis 4×; Umkehrung mit einem Tipp.

## Schritt 6: Vorschau und Export

Hören Sie vor dem Export das Ganze in der App an - das, was Sie hören, sollte mit dem Endergebnis übereinstimmen. Klingt es richtig, starten Sie den Export.

## Schritt 7: Speichern

Nach dem Export wird die neue Datei zunächst in den Sandbox-Ordner der App geschrieben. Ein Dialog fragt Sie, „Save to Files" zu wählen. Wählen Sie einen Ordner in der iOS-Files-App, und die neue Datei wird dort abgelegt.

Die Originalquelle wird nie verändert - behalten Sie das Master bei, wenn Sie möchten.
