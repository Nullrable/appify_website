Kebijakan Privasi ini menjelaskan bagaimana **Work Hours Tracker** ("**Aplikasi**") menangani informasi tentang Anda. Singkatnya: data jam kerja Anda hanya tersimpan di perangkat Anda — kami tidak menjualnya, tidak mengumpulkannya, dan tidak dapat melihatnya.

Kami menghargai privasi Anda dan membangun Aplikasi dengan desain "lokal-dahulu" untuk menepati komitmen itu.

## 1. Kami Tidak Mengumpulkan Data Pribadi

Aplikasi tidak memerlukan registrasi akun dan tidak meminta nama, email, atau nomor telepon. Seluruh data Anda — catatan absensi, tarif per jam, aturan lembur — tersimpan di basis data lokal aplikasi pada perangkat Anda dan **tidak pernah diunggah ke server kami atau pihak ketiga mana pun**.

Kami tidak menjual data Anda; kami tidak punya data untuk dijual.

## 2. Data yang Tersimpan Secara Lokal

Data berikut hanya ada di perangkat Anda:

- Catatan absen dan jam kerja
- Informasi pekerjaan dan pengaturan tarif per jam
- Aturan lembur dan pilihan preset
- Pengaturan aplikasi (mata uang, awal minggu, dll.)

Karena data ini hanya ada di perangkat Anda, kami tidak dapat mengakses, melihat, atau memulihkannya. Anda dapat melihat, mengubah, atau menghapus data ini di aplikasi kapan saja, atau menghapus semuanya kapan pun Anda mau.

## 3. Kunci Aplikasi Biometrik

Jika Anda mengaktifkan fitur kunci aplikasi, verifikasi sidik jari atau wajah dilakukan oleh antarmuka biometrik sistem perangkat Anda (seperti Touch ID / Face ID). Aplikasi **tidak menyimpan atau mengambil data sidik jari atau wajah Anda** — verifikasi sepenuhnya ditangani sistem.

## 4. Penggunaan Jaringan

Fitur inti Aplikasi (absen, perhitungan, statistik, ekspor) **berfungsi sepenuhnya offline**. Satu-satunya fitur yang melibatkan jaringan adalah sinkronisasi hari libur resmi:

- Saat menyinkronkan, aplikasi mengquery API data hari libur publik (**Nager.Date**) untuk wilayah yang Anda pilih
- Permintaan tersebut **tidak memuat** data pribadi atau catatan kerja Anda — hanya kode negara/wilayah yang dipilih
- Jika tidak memerlukan fitur ini, cukup lewati sinkronisasi hari libur; fitur lain tidak terpengaruh

## 5. Langganan Pro

Pembayaran langganan Pro ditangani oleh **Apple App Store**, dan verifikasi langganan serta pengelolaan hak berjalan melalui **RevenueCat**. Kami tidak pernah melihat detail pembayaran Anda (nomor kartu, alamat penagihan, dll.) dan tidak menyimpan kredensial pembayaran apa pun. Data transaksi terkait tunduk pada [Kebijakan Privasi Apple](https://www.apple.com/legal/privacy/) dan [Kebijakan Privasi RevenueCat](https://revenuecat.com/privacy/).

## 6. Cadangan dan Berbagi

File cadangan dan ekspor yang Anda buat melalui aplikasi sepenuhnya dikendalikan oleh Anda: ke mana file dikirim melalui panel berbagi sistem (penyimpanan awan, email, komputer) sepenuhnya terserah Anda. Kami tidak dapat memperoleh file tersebut dan tidak menerima notifikasi apa pun tentangnya.

## 7. Penghapusan Data

Karena semuanya lokal, penghapusan sangat menyeluruh:

- Anda dapat menghapus catatan individual atau menghapus semua data di aplikasi
- Menghapus instalasi aplikasi akan menghapus semua data lokal dari perangkat

Tindakan ini tidak dapat dibatalkan — cadangkan dulu.

## 8. Privasi Anak

Aplikasi tidak ditujukan bagi anak di bawah usia minimal kontrak menurut hukum yang berlaku, dan kami tidak dengan sengaja mengumpulkan data anak.

## 9. Perubahan Kebijakan

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Penggunaan Aplikasi secara berkelanjutan setelah pembaruan berlaku merupakan penerimaan atas kebijakan yang diperbarui. Untuk perubahan material, kami akan memberi pemberitahuan yang wajar di dalam Aplikasi atau di halaman App Store.
