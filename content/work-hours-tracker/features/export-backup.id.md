## Ekspor dan Cadangkan Data Jam Kerja Anda

Catatan kerja tidak seharusnya terkunci di dalam ponsel. Entah untuk mencocokkan jam kerja dengan pemberi kerja, arsip pribadi, atau diimpor ke alat lain untuk analisis lanjutan — ekspor dan cadangan menanganinya.

## Tiga Format Ekspor

- **CSV**: format spreadsheet universal yang bisa diimpor ke Excel, Numbers, dan alat analisis lain.
- **PDF**: laporan tetap yang cocok untuk dicetak atau langsung dikirim ke seseorang.
- **Excel**: menyertakan lembar rincian lembur, dengan lembur berjenjang dan item shift malam terpisah jelas.

Setelah diekspor, file bisa langsung dibagikan lewat menu berbagi sistem. Ekspor adalah fitur Pro.

## Cadangkan dan Pulihkan

Aplikasi dapat mengemas seluruh data menjadi satu cadangan yang bisa Anda simpan ke penyimpanan awan atau komputer melalui berbagi. Saat ganti ponsel atau instal ulang, pulihkan semuanya dari file cadangan — atau hapus semua data untuk mulai dari awal.

Secara bawaan data hanya tersimpan di perangkat Anda; file cadangan dipegang sendiri dan tidak pernah diunggah ke server mana pun.
