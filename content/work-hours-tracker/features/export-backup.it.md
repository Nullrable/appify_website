## Esporta e salva i dati delle tue ore di lavoro

I registri di lavoro non dovrebbero restare chiusi nel telefono. Che sia per verificare le ore con il datore di lavoro, tenere un archivio personale o importare in altri strumenti, esportazione e backup ci pensano.

## Tre formati di esportazione

- **CSV**: formato foglio di calcolo universale, importabile in Excel, Numbers e altri strumenti di analisi.
- **PDF**: report a impaginazione fissa, ideale per la stampa o l'invio diretto.
- **Excel**: include un foglio con il dettaglio degli straordinari, con scaglioni e voci notturne ben separate.

Dopo l'esportazione, il file si condivide direttamente dal menu di condivisione di sistema. L'esportazione è una funzione Pro.

## Backup e ripristino

L'app può raccogliere tutti i dati in un backup che salvate su cloud o computer tramite la condivisione. Cambiando telefono o reinstallando, tutto si ripristina dal file di backup — e all'occorrenza potete cancellare tutto per ripartire da zero.

Di default i dati restano sul tuo dispositivo; il file di backup resta in mano tua e non viene mai caricato su alcun server.
