## Export and Back Up Your Work Hours Data

Work records should not be locked inside your phone. Whether you need to verify hours with an employer, keep your own archive, or import into other tools, export and backup handle it.

## Three Export Formats

- **CSV**: a universal spreadsheet format that imports into Excel, Numbers, and other analysis tools.
- **PDF**: a fixed-layout report, suitable for printing or sending directly to someone.
- **Excel**: includes an overtime breakdown worksheet, with tiered overtime and night-shift items clearly separated.

After exporting, you can share the file directly via the system share sheet. Exporting is a Pro feature.

## Backup and Restore

The app can package all your data into a backup, which you can save to cloud storage or a computer via sharing. When switching phones or reinstalling, restore everything from the backup file — or clear all data to start fresh.

Data stays on your device by default. Backup files are kept by you and never uploaded to any server.
