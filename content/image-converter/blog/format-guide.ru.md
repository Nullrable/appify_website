## Зачем менять формат

На телефоне хранятся самые разные форматы: JPG — компактный, PNG — с прозрачностью, WebP — баланс качества и размера. Под разные задачи нужен свой формат. Image Converter поддерживает свободное переключение между JPG, JPEG, PNG, WebP, BMP и TIFF, обработка выполняется локально, качество не страдает.

## Особенности шести форматов

### JPG / JPEG: сжатие с потерями, минимальный размер

Самый распространённый формат фото, почти все камеры и телефоны сохраняют JPG по умолчанию. Используется сжатие с потерями: отбрасываются детали, малочувствительные для глаза, ради меньшего размера. **Плюсы**: минимальный размер, лучшая совместимость. **Минусы**: каждое пересохранение теряет детали, прозрачность не поддерживается.

Типичное применение: публикация фото, соцсети, веб-изображения.

### PNG: сжатие без потерь, поддержка прозрачности

Используется алгоритм сжатия без потерь, качество совпадает с оригиналом. Поддерживается альфа-канал (прозрачность) — формат первого выбора для иконок, UI-макетов и скриншотов. **Плюсы**: без потерь, поддержка прозрачности. **Минусы**: размер в 3–5 раз больше, чем у JPG.

Типичное применение: иконки, логотипы, UI-макеты, изображения с прозрачным фоном.

### WebP: современный веб-формат

Современный формат от Google, сочетает качество и размер: на 25–35% меньше JPG и лучшее сжатие, чем PNG. **Плюсы**: маленький размер, поддержка сжатия с потерями, без потерь и прозрачности. **Минусы**: хуже поддерживается на старых устройствах (нативная поддержка в iOS 16+ / Android 5+).

Типичное применение: веб-изображения, ресурсы приложений, сценарии, требующие минимального размера.

### BMP: растровый формат без сжатия

Исторический формат Windows, без сжатия, сохраняет все исходные пиксели. **Плюсы**: без потерь, хорошая совместимость. **Минусы**: огромный размер — в 5–10 раз больше JPG.

Типичное применение: встроенные инструменты Windows, временные файлы профессионального ПО.

### TIFF: архив и печать

Профессиональный формат, без потерь, поддержка слоёв и цветовых пространств печати (CMYK). **Плюсы**: максимальное качество, богатые метаданные. **Минусы**: огромный размер, совместимость хуже, чем у JPG.

Типичное применение: печать, профессиональное архивирование фото, сканирование.

## Как сохранить качество при конвертации

- **Между одним и тем же / близким форматом**: JPG ↔ WebP оба с потерями, дополнительных потерь нет
- **JPG → PNG**: пиксели копируются, размер растёт, но качество не меняется (конвертация без потерь)
- **PNG → JPG**: прозрачный канал отбрасывается (заполняется белым), размер резко уменьшается, качество не меняется
- **Любой формат → TIFF**: без потерь, качество максимально сохраняется, размер максимальный

## Процесс конвертации в Image Converter

1. **Автоматическое распознавание исходного формата**: двойная проверка — расширение файла и его сигнатура (PNG `89 50 4E 47`, JPEG `FF D8 FF`, WebP `RIFF + WEBP`)
2. **Коррекция EXIF-поворота**: снятые на iPhone фото с меткой EXIF автоматически поворачиваются перед конвертацией
3. **Исключение бессмысленных целей**: исходный формат не появляется в списке целей
4. **Локальная обработка**: всё выполняется на устройстве, файлы не отправляются в интернет

## Какой формат выбрать: краткая шпаргалка

| Сценарий | Рекомендуемый формат | Причина |
|---|---|---|
| Публикация в соцсетях | JPG | Лучшая совместимость, маленький размер |
| Скриншоты / инструкции | PNG | Чёткость, резкие линии текста |
| Ресурсы веб / приложений | WebP | Минимальный размер, хорошее качество |
| Дизайн-макеты / логотипы | PNG | Поддержка прозрачности, без потерь |
| Печать / архивирование | TIFF | Максимальное качество, полные метаданные |
| Обработка в Windows | BMP | Совместимость с системой |

Если всё ещё не уверены — **JPG самый безопасный выбор**: поддерживается почти всеми платформами, размер минимален, единственная цена — отсутствие поддержки прозрачного фона.
