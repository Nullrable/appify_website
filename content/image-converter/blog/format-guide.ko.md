## 포맷 변환이 필요한 이유

휴대폰에는 다양한 포맷의 이미지가 있습니다 — JPG는 용량이 작고, PNG는 투명도가 우수하며, WebP는 화질과 용량을 모두 갖추고 있습니다. 각기 다른 상황에는 각기 다른 포맷이 필요합니다. Image Converter는 JPG, JPEG, PNG, WebP, BMP, TIFF 6가지 포맷 간 자유로운 전환을 지원하며, 변환은 기기에서 로컬로 처리되어 화질이 손상되지 않습니다.

## 6가지 포맷의 특징

### JPG / JPEG: 손실 압축, 용량이 가장 작음

가장 일반적인 사진 포맷으로, 거의 모든 카메라와 휴대폰이 기본적으로 JPG로 출력합니다. 손실 압축을 채택하여 사람의 눈이 잘 감지하지 못하는 디테일을 버리는 대신 작은 용량을 얻습니다. **장점**: 용량이 가장 작고 호환성이 가장 좋습니다. **단점**: 매번 다시 저장할 때마다 디테일이 손실되며 투명도를 지원하지 않습니다.

일반적인 용도: 사진 공유, 소셜 미디어, 웹 이미지.

### PNG: 무손실 압축, 투명 지원

무손실 압축 알고리즘을 채택하여 화질이 원본과 일치합니다. Alpha 채널(투명도)을 지원하여 아이콘, UI 디자인 파일, 스크린샷의首选 포맷입니다. **장점**: 무손실 화질, 투명 지원. **단점**: 용량이 JPG보다 3–5배 큽니다.

일반적인 용도: 아이콘, 로고, UI 디자인 파일, 투명 배경이 필요한 이미지.

### WebP: 현대 웹 포맷

Google에서推出的 현대 이미지 포맷으로, 화질과 용량을 모두 갖추어 JPG보다 25–35% 작고 PNG보다 더 나은 압축을 지원합니다. **장점**: 용량이 작고 손실/무손실/투명을 모두 지원합니다. **단점**: 오래된 기기에서 호환성이 떨어집니다(iOS 16+/Android 5+ 기본 지원).

일반적인 용도: 웹 이미지, 앱 리소스, 극단적인 용량 절감을 추구하는 상황.

### BMP: 비트맵 포맷, 압축 없음

Windows 시스템의 오랜 역사를 가진 포맷으로, 압축하지 않고 모든 원본 픽셀을 보존합니다. **장점**: 무손실 화질, 우수한 호환성. **단점**: 용량이 매우 커서 JPG의 5–10배입니다.

일반적인 용도: Windows 시스템 내장 도구 처리, 전문 소프트웨어 임시 파일.

### TIFF: 아카이빙 및 인쇄 수준

전문급 이미지 포맷으로, 무손실이며 다중 레이어와 CMYK 등 인쇄 색 공간을 지원합니다. **장점**: 최고 수준 화질, 풍부한 메타데이터 지원. **단점**: 용량이 매우 크고, JPG만큼 호환성이 좋지 않습니다.

일반적인 용도: 인쇄 출판, 전문 사진 아카이빙, 스캔 아카이빙.

## 변환 시 화질 보존의 핵심

- **동일 포맷/유사 포맷 간 변환**: JPG ↔ WebP는 모두 손실 포맷이므로 추가 손실이 없습니다
- **JPG → PNG**: 픽셀이 복사되며, 용량은 증가하지만 화질은 변하지 않습니다(무손실 변환)
- **PNG → JPG**: 투명 채널이 폐기되며(흰색으로 채워짐), 용량이 크게 줄어들고 화질은 변하지 않습니다
- **모든 포맷 → TIFF**: 무손실, 화질이 가장 잘 보존되며, 용량은 가장 큽니다

## Image Converter의 변환 과정

1. **원본 포맷 자동 인식**: 파일 확장자와 파일 시그니처 이중 인식(PNG 89 50 4E 47, JPEG FF D8 FF, WebP RIFF + WEBP)
2. **EXIF 회전 보정**: iPhone에서 촬영한 EXIF 태그가 있는 사진은 변환 전에 픽셀이 자동으로 회전됩니다
3. **무의미한 대상 제외**: 원본 포맷은 대상 포맷 목록에 나타나지 않습니다
4. **로컬 처리**: 전체 과정이 기기에서 완료되며 파일은 업로드되지 않습니다

## 어떤 포맷을 선택해야 할까: 시나리오 빠른 참조

| 시나리오 | 추천 포맷 | 이유 |
|---|---|---|
| SNS 공유 | JPG | 호환성 우수, 용량 작음 |
| 스크린샷 / 튜토리얼 | PNG | 선명하고 텍스트가 선명함 |
| 웹 / 앱 리소스 | WebP | 가장 작은 용량, 좋은 화질 |
| 디자인 파일 / 로고 | PNG | 투명 지원, 무손실 화질 |
| 인쇄 / 아카이빙 | TIFF | 최고 화질, 완전한 메타데이터 |
| Windows 시스템 처리 | BMP | 시스템 호환 |

아직 어떤 포맷을 선택할지 확신이 서지 않는다면, **JPG가 가장 안전한 선택입니다**: 거의 모든 플랫폼에서 지원하며, 용량도 가장 작습니다. 유일한 대가는 투명 배경을 지원하지 않는다는 것입니다.
