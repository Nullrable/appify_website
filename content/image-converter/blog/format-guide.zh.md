## 为什么需要转格式

手机里常有各种格式的图片——JPG 体积小、PNG 透明好、WebP 兼顾画质和体积……不同场景需要不同格式。Image Converter 支持 JPG、JPEG、PNG、WebP、BMP、TIFF 六种格式之间任意切换，转换在设备本地完成，画质不被破坏。

## 六大格式的特点

### JPG / JPEG：有损压缩，体积最小

最常见的照片格式，几乎所有相机和手机都默认输出 JPG。采用有损压缩，丢弃人眼不敏感的细节换取小体积。**优点**：体积最小、兼容性最好。**缺点**：每次重新保存都会损失细节，不支持透明。

典型用途：照片分享、社交媒体、网页图片。

### PNG：无损压缩，支持透明

采用无损压缩算法，画质与原图一致。支持 Alpha 通道（透明度），是图标、UI 设计稿、截图的首选格式。**优点**：画质无损、支持透明。**缺点**：体积比 JPG 大 3–5 倍。

典型用途：图标、Logo、UI 设计稿、需要透明背景的图片。

### WebP：现代网页格式

Google 推出的现代图片格式，画质与体积兼顾，比 JPG 小 25–35%、比 PNG 支持更好的压缩。**优点**：体积小、同时支持有损/无损/透明。**缺点**：老旧设备兼容性较差（iOS 16+/Android 5+ 原生支持）。

典型用途：网页图片、App 资源、追求极致体积的场景。

### BMP：位图格式，无压缩

Windows 系统历史悠久的格式，不压缩，保留所有原始像素。**优点**：画质无损、兼容性好。**缺点**：体积巨大，是 JPG 的 5–10 倍。

典型用途：Windows 系统内置工具处理、专业软件临时文件。

### TIFF：归档与印刷级

专业级图像格式，无损、支持多图层、支持 CMYK 等印刷色彩空间。**优点**：画质顶级、支持元数据丰富。**缺点**：体积巨大、兼容性不如 JPG。

典型用途：印刷出版、专业摄影归档、扫描存档。

## 转换时保留画质的关键

- **同格式 / 同类格式互转**：JPG ↔ WebP 都属有损，无额外损失
- **JPG → PNG**：像素被复制，体积会变大但画质不变（无损转换）
- **PNG → JPG**：透明通道被丢弃（白色填充），体积大幅缩小，画质不变
- **任何格式 → TIFF**：无损，画质保留最好，体积最大

## Image Converter 的转换流程

1. **自动识别原格式**：从文件扩展名 + 文件签名双重识别（PNG 89 50 4E 47、JPEG FF D8 FF、WebP RIFF + WEBP）
2. **修正 EXIF 旋转**：iPhone 拍摄的带 EXIF 标记的照片在转换前自动旋转像素
3. **排除无意义目标**：原格式不会出现在目标格式列表里
4. **本地处理**：全程在设备上完成，文件不上传

## 该选什么格式：场景速查

| 场景 | 推荐格式 | 理由 |
|---|---|---|
| 朋友圈 / 微博分享 | JPG | 兼容性好、体积小 |
| 截图 / 教程 | PNG | 清晰、文字锐利 |
| 网页 / App 资源 | WebP | 体积最小、画质好 |
| 设计稿 / Logo | PNG | 支持透明、画质无损 |
| 印刷 / 归档 | TIFF | 顶级画质、元数据完整 |
| Windows 系统处理 | BMP | 系统兼容 |

如果还不确定选什么，**JPG 是最安全的选择**：几乎所有平台都支持，体积也最小，唯一的代价是不支持透明背景。
