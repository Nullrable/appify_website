## 為什麼需要轉檔

手機裡常有各種格式的圖片——JPG 體積小、PNG 透明好、WebP 兼顧畫質和體積……不同場景需要不同格式。Image Converter 支援 JPG、JPEG、PNG、WebP、BMP、TIFF 六種格式之間任意切換，轉檔在裝置本機完成，畫質不被破壞。

## 六大格式的特點

### JPG / JPEG：有損壓縮，體積最小

最常見的照片格式，幾乎所有相機和手機都預設輸出 JPG。採用有損壓縮，捨棄人眼不敏感的細節以換取小體積。**優點**：體積最小、相容性最好。**缺點**：每次重新儲存都會損失細節，不支援透明。

典型用途：照片分享、社群媒體、網頁圖片。

### PNG：無損壓縮，支援透明

採用無損壓縮演算法，畫質與原圖一致。支援 Alpha 通道（透明度），是圖示、UI 設計稿、截圖的首選格式。**優點**：畫質無損、支援透明。**缺點**：體積比 JPG 大 3–5 倍。

典型用途：圖示、Logo、UI 設計稿、需要透明背景的圖片。

### WebP：現代網頁格式

Google 推出的現代圖片格式，畫質與體積兼顧，比 JPG 小 25–35%、比 PNG 支援更好的壓縮。**優點**：體積小、支援有損/無損/透明。**缺點**：老舊裝置相容性較差（iOS 16+/Android 5+ 原生支援）。

典型用途：網頁圖片、App 資源、追求極致體積的場景。

### BMP：點陣圖格式，無壓縮

Windows 系統歷史悠久的格式，不壓縮，保留所有原始像素。**優點**：畫質無損、相容性好。**缺點**：體積巨大，是 JPG 的 5–10 倍。

典型用途：Windows 系統內建工具處理、專業軟體暫存檔。

### TIFF：封存與印刷級

專業級影像格式，無損、支援多圖層、支援 CMYK 等印刷色彩空間。**優點**：畫質頂級、支援豐富中繼資料。**缺點**：體積巨大、相容性不如 JPG。

典型用途：印刷出版、專業攝影封存、掃描封存。

## 轉檔時保留畫質的關鍵

- **同格式 / 同類格式互轉**：JPG ↔ WebP 都屬有損，無額外損失
- **JPG → PNG**：像素被複製，體積會變大但畫質不變（無損轉檔）
- **PNG → JPG**：透明通道被捨棄（白色填補），體積大幅縮小，畫質不變
- **任何格式 → TIFF**：無損，畫質保留最好，體積最大

## Image Converter 的轉檔流程

1. **自動辨識原格式**：從副檔名 + 檔案簽名雙重辨識（PNG 89 50 4E 47、JPEG FF D8 FF、WebP RIFF + WEBP）
2. **修正 EXIF 旋轉**：iPhone 拍攝的帶 EXIF 標記的照片在轉檔前自動旋轉像素
3. **排除無意義目標**：原格式不會出現在目標格式清單中
4. **本機處理**：全程在裝置上完成，檔案不上傳

## 該選什麼格式：場景速查

| 場景 | 推薦格式 | 理由 |
|---|---|---|
| 朋友圈 / 微博分享 | JPG | 相容性好、體積小 |
| 截圖 / 教學 | PNG | 清晰、文字銳利 |
| 網頁 / App 資源 | WebP | 體積最小、畫質好 |
| 設計稿 / Logo | PNG | 支援透明、畫質無損 |
| 印刷 / 封存 | TIFF | 頂級畫質、中繼資料完整 |
| Windows 系統處理 | BMP | 系統相容 |

如果還不確定選什麼，**JPG 是最安全的選擇**：幾乎所有平台都支援，體積也最小，唯一的代價是不支援透明背景。
