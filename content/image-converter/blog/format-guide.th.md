## ทำไมต้องแปลงรูปแบบ

ในโทรศัพท์มีภาพหลากหลายรูปแบบ — JPG ขนาดเล็ก, PNG โปร่งใส, WebP สมดุลระหว่างคุณภาพและขนาด สถานการณ์ต่าง ๆ ต้องการรูปแบบต่างกัน Image Converter รองรับการสลับระหว่าง JPG, JPEG, PNG, WebP, BMP และ TIFF อย่างอิสระ ประมวลผลบนอุปกรณ์ คุณภาพไม่ลดลง

## ลักษณะของหกรูปแบบ

### JPG / JPEG: การบีบอัดแบบสูญเสีย ขนาดเล็กที่สุด

รูปแบบภาพถ่ายที่พบมากที่สุด กล้องและโทรศัพท์เกือบทุกเครื่องบันทึกเป็น JPG โดยค่าเริ่มต้น ใช้การบีบอัดแบบสูญเสีย ทิ้งรายละเอียดที่ตาไม่ไวต่อการมองเห็นเพื่อแลกกับขนาดที่เล็กลง **ข้อดี**: ขนาดเล็กที่สุด เข้ากันได้ดีที่สุด **ข้อเสีย**: ทุกครั้งที่บันทึกใหม่จะสูญเสียรายละเอียด ไม่รองรับความโปร่งใส

การใช้งานทั่วไป: แชร์ภาพถ่าย โซเชียลมีเดีย ภาพบนเว็บ

### PNG: การบีบอัดแบบไม่สูญเสีย รองรับความโปร่งใส

ใช้อัลกอริทึมบีบอัดแบบไม่สูญเสีย คุณภาพคงเดิม รองรับช่องอัลฟา (ความโปร่งใส) เป็นตัวเลือกแรกสำหรับไอคอน ไฟล์ออกแบบ UI และภาพหน้าจอ **ข้อดี**: ไม่สูญเสีย รองรับความโปร่งใส **ข้อเสีย**: ขนาดใหญ่กว่า JPG 3–5 เท่า

การใช้งานทั่วไป: ไอคอน โลโก้ ไฟล์ออกแบบ UI ภาพที่ต้องการพื้นหลังโปร่งใส

### WebP: รูปแบบเว็บสมัยใหม่

รูปแบบสมัยใหม่จาก Google สมดุลระหว่างคุณภาพและขนาด: เล็กกว่า JPG 25–35% และบีบอัดได้ดีกว่า PNG **ข้อดี**: ขนาดเล็ก รองรับทั้งแบบสูญเสีย ไม่สูญเสีย และโปร่งใส **ข้อเสีย**: อุปกรณ์เก่ารองรับไม่ดี (รองรับโดยกำเนิดใน iOS 16+ / Android 5+)

การใช้งานทั่วไป: ภาพบนเว็บ ทรัพยากรแอป สถานการณ์ที่ต้องการขนาดเล็กที่สุด

### BMP: รูปแบบบิตแมปแบบไม่บีบอัด

รูปแบบดั้งเดิมของ Windows ไม่มีการบีบอัด เก็บพิกเซลดั้งเดิมทั้งหมด **ข้อดี**: ไม่สูญเสีย เข้ากันได้ดี **ข้อเสีย**: ขนาดใหญ่มาก ใหญ่กว่า JPG 5–10 เท่า

การใช้งานทั่วไป: เครื่องมือในตัวของ Windows ไฟล์ชั่วคราวของซอฟต์แวร์มืออาชีพ

### TIFF: การเก็บถาวรและการพิมพ์

รูปแบบระดับมืออาชีพ ไม่สูญเสีย รองรับหลายเลเยอร์และพื้นที่สีสำหรับการพิมพ์ (CMYK) **ข้อดี**: คุณภาพสูงสุด เมตาดาต้ารวย **ข้อเสีย**: ขนาดใหญ่มาก ความเข้ากันได้แย่กว่า JPG

การใช้งานทั่วไป: การพิมพ์ การเก็บถาวรภาพถ่ายระดับมืออาชีพ การสแกนเก็บถาวร

## วิธีรักษาคุณภาพเมื่อแปลง

- **ระหว่างรูปแบบเดียวกัน / คล้ายกัน**: JPG ↔ WebP ทั้งคู่สูญเสีย ไม่มีการสูญเสียเพิ่ม
- **JPG → PNG**: คัดลอกพิกเซล ขนาดใหญ่ขึ้น แต่คุณภาพไม่เปลี่ยน (การแปลงแบบไม่สูญเสีย)
- **PNG → JPG**: ทิ้งช่องความโปร่งใส (เติมสีขาว) ขนาดเล็กลงอย่างมาก คุณภาพไม่เปลี่ยน
- **รูปแบบใด ๆ → TIFF**: ไม่สูญเสีย คุณภาพคงไว้ดีที่สุด ขนาดใหญ่ที่สุด

## กระบวนการแปลงใน Image Converter

1. **จดจำรูปแบบต้นฉบับอัตโนมัติ**: ตรวจสอบสองชั้นจากนามสกุลไฟล์และลายเซ็นไฟล์ (PNG `89 50 4E 47`, JPEG `FF D8 FF`, WebP `RIFF + WEBP`)
2. **แก้ไขการหมุน EXIF**: ภาพ iPhone ที่มีเครื่องหมาย EXIF จะถูกหมุนพิกเซลก่อนแปลง
3. **ตัดเป้าหมายที่ไม่จำเป็นออก**: รูปแบบต้นฉบับจะไม่ปรากฏในรายการเป้าหมาย
4. **ประมวลผลบนอุปกรณ์**: ทำทุกอย่างบนอุปกรณ์ ไม่อัปโหลดไฟล์

## ควรเลือกรูปแบบใด: ตารางสรุป

| สถานการณ์ | รูปแบบที่แนะนำ | เหตุผล |
|---|---|---|
| แชร์ในโซเชียล | JPG | เข้ากันได้ดี ขนาดเล็ก |
| ภาพหน้าจอ / บทช่วยสอน | PNG | คมชัด ตัวอักษรคม |
| ทรัพยากรเว็บ / แอป | WebP | ขนาดเล็กที่สุด คุณภาพดี |
| ไฟล์ออกแบบ / โลโก้ | PNG | รองรับความโปร่งใส ไม่สูญเสีย |
| การพิมพ์ / เก็บถาวร | TIFF | คุณภาพสูงสุด เมตาดาต้าครบ |
| การประมวลผลบน Windows | BMP | เข้ากันได้กับระบบ |

หากยังไม่แน่ใจ **JPG เป็นตัวเลือกที่ปลอดภัยที่สุด**: แทบทุกแพลตฟอร์มรองรับ ขนาดเล็กที่สุด ข้อแลกเปลี่ยนเพียงอย่างเดียวคือไม่รองรับพื้นหลังโปร่งใส
