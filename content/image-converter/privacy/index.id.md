Kebijakan privasi ini menjelaskan bagaimana **Image Converter**("**Aplikasi ini**") menangani informasi yang berkaitan dengan Anda. Singkatnya: gambar Anda hanya diproses di perangkat Anda, kami tidak mengumpulkan, tidak dapat melihat, dan tidak menjualnya.

## 1. Pemrosesan lokal, file tidak diunggah

Semua fungsi pemrosesan Aplikasi ini — konversi format, kompresi, rotasi, pemangkasan, penyesuaian ukuran, penjahitan — semuanya dilakukan secara lokal di perangkat Anda. **Gambar Anda tidak akan diunggah ke server kami atau server konversi mana pun**, hasil pemrosesan disimpan langsung di perangkat Anda.

Kami tidak menjual data Anda, dan juga tidak memiliki data gambar untuk dijual.

## 2. Data yang disimpan secara lokal

Data berikut hanya disimpan di perangkat Anda:

- Riwayat konversi (status operasi, durasi, format sumber dan keluaran, ukuran file), disimpan di basis data lokal perangkat
- File keluaran konversi, disimpan di direktori lokal aplikasi, hingga Anda menyimpannya secara terpisah melalui panel berbagi atau menghapus cache
- Pengaturan aplikasi (tema, bahasa, dll.)

Karena data ini hanya ada di perangkat Anda, kami tidak dapat mengakses, melihat, atau memulihkannya.

## 3. Izin sistem

- **Pustaka foto**: hanya digunakan saat Anda secara aktif memilih gambar dari pustaka foto, digunakan untuk membaca gambar yang Anda pilih, tidak membaca pustaka secara (massal) atau mengunggah otomatis
- **File**: hanya digunakan saat Anda secara aktif memilih gambar dari aplikasi "File", digunakan untuk membaca file yang Anda pilih

## 4. Iklan

Aplikasi ini didukung oleh iklan **Google AdMob**. Pengguna yang belum berlangganan Pro akan melihat iklan berinsentif saat masuk ke halaman fungsi. AdMob dapat menggunakan pengenal perangkat (seperti pengenal iklan yang diizinkan oleh hukum yang berlaku) untuk menayangkan dan mengukur iklan. Untuk detailnya lihat [Kebijakan Privasi Google](https://policies.google.com/privacy).

Anda dapat menghilangkan iklan kapan saja dengan berlangganan Pro. Jika hukum yang berlaku mensyaratkan, Anda juga dapat membatasi pelacakan iklan atau mengatur ulang pengenal iklan di pengaturan sistem.

## 5. Langganan Pro

Pembayaran langganan Pro ditangani oleh **Apple App Store**, verifikasi langganan dan manajemen hak dilakukan melalui **RevenueCat**. Kami tidak akan (mengakses) informasi pembayaran Anda (nomor kartu, alamat penagihan, dll.), juga tidak menyimpan bukti pembayaran apa pun. Informasi transaksi terkait tunduk pada [Kebijakan Privasi Apple](https://www.apple.com/legal/privacy/) dan [Kebijakan Privasi RevenueCat](https://revenuecat.com/privacy/).

## 6. Berbagi

Saat Anda berbagi file melalui aplikasi, file dikirim langsung melalui panel berbagi sistem ke tujuan yang Anda pilih (email, AirDrop, "File", dll.), seluruh proses dikontrol oleh Anda, kami tidak dapat (memperoleh) file-file ini dan juga tidak menerima pemberitahuan apa pun.

## 7. Penghapusan data

Karena semua data bersifat lokal, penghapusannya sangat menyeluruh:

- Anda dapat menghapus cache di pengaturan aplikasi untuk menghapus file keluaran dan riwayat di direktori aplikasi
- Menghapus instalan aplikasi akan (secara bersamaan) menghapus semua data lokal di perangkat

Operasi tidak dapat dibatalkan, harap simpan file penting secara terpisah terlebih dahulu.

## 8. Privasi anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah usia minimum yang dapat mengadakan kontrak yang ditentukan oleh hukum yang berlaku, dan kami juga tidak dengan sengaja mengumpulkan data anak-anak.

## 9. Perubahan kebijakan

Kami dapat memperbarui kebijakan privasi ini dari waktu ke waktu. Melanjutkan penggunaan Aplikasi ini setelah pembaruan (berlaku) constitutes (merupakan) penerimaan terhadap kebijakan yang diperbarui. Jika ada perubahan (penting), kami akan memberikan pemberitahuan yang wajar dalam aplikasi atau melalui halaman toko aplikasi.
