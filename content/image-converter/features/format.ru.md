## Преобразование форматов изображений

В повседневной работе нам часто приходится переключаться между форматами изображений: JPG — компактный и удобный для отправки, PNG сохраняет прозрачность, WebP сочетает качество и размер, BMP/TIFF используются для печати или архивирования. Image Converter поддерживает свободную конвертацию между этими шестью основными форматами, обработка выполняется локально на устройстве, файлы не отправляются на сервер.

## Поддерживаемые форматы

- **JPG / JPEG**: сжатие с потерями, минимальный размер; чаще всего используется для обмена фотографиями и веб-изображений
- **PNG**: сжатие без потерь, поддержка прозрачности; подходит для иконок, скриншотов и дизайн-макетов
- **WebP**: современный веб-формат, баланс качества и размера, нативная поддержка в iOS 16+
- **BMP**: растровый формат без сжатия, большой размер, распространён в системах Windows
- **TIFF**: формат без потерь, подходит для печати, издательских задач и архивирования

## Три шага для конвертации

1. **Выберите изображение**: выберите фото из галереи или приложения «Файлы»; приложение автоматически распознает исходный формат
2. **Выберите целевой формат**: список автоматически исключает исходный формат, чтобы избежать бессмысленных преобразований
3. **Сохраните**: результат отправляется через системную панель обмена и может быть сохранён в «Файлы», галерею или другое место

## Автоматическая коррекция поворота EXIF

Фотографии, снятые на iPhone, часто содержат метку поворота EXIF. Приложение автоматически корректирует ориентацию перед конвертацией, поэтому экспортированное изображение отображается правильно на любом устройстве — никаких «вроде правильно, а на деле криво».
