## Combinar imágenes

Chats que quieres enviar como una única captura larga, comparativas de producto en paralelo, varias fotos del mismo tema para montar un álbum: en todos estos casos hay que unir varias imágenes en una sola. Image Converter ofrece tres modos de combinación que cubren las necesidades más habituales.

## Tres modos de combinación

- **Combinación vertical**: las imágenes se colocan de arriba abajo, ideal para unir historiales de chat, capturas de artículos largos o pasos de un tutorial, generando una única imagen alargada
- **Combinación horizontal**: las imágenes se colocan de izquierda a derecha, ideal para comparativas en paralelo, como distintas versiones de un producto o diferentes ángulos de una misma escena
- **Cuadrícula 3×3**: las imágenes se organizan en una cuadrícula, perfecta para agrupar una serie de fotos con un estilo común, publicaciones de nueve imágenes o compartir un álbum

## Hasta 20 imágenes

La aplicación permite combinar hasta 20 imágenes en una sola (hasta 9 en el modo cuadrícula). Si se supera el límite aparece un aviso para evitar que el archivo resultante sea demasiado grande.

## Reordena libremente

Tras seleccionar las imágenes, la aplicación las muestra en una cuadrícula donde puedes:

- **Reordenar arrastrando**: mantén pulsada una imagen y arrástrala hasta la posición deseada
- **Eliminar una imagen**: pulsa el botón de eliminar en la esquina superior derecha de la imagen
- **Seguir añadiendo**: pulsa el botón "Añadir más" para seleccionar más imágenes

Tras ajustar el orden, cambia entre los distintos modos de combinación para previsualizar el resultado: lo que ves es lo que obtienes.

## Combinación en local

Todo el proceso se realiza en el dispositivo local; ni la imagen original ni el resultado se suben a ningún servidor. Para más detalles sobre el tratamiento de datos consulta la [política de privacidad](/es/image-converter/privacy/).
