## Unir imagens

Conversas de chat que quer enviar como uma única captura longa, comparações de produtos lado a lado, várias fotos do mesmo tema para montar um álbum: em todos estes casos é preciso unir várias imagens numa só. O Image Converter oferece três modos de combinação que cobrem as necessidades mais habituais.

## Três modos de combinação

- **Combinação vertical**: as imagens são dispostas de cima para baixo, ideal para unir históricos de chat, capturas de artigos longos ou passos de tutoriais, gerando uma única imagem alongada
- **Combinação horizontal**: as imagens são dispostas da esquerda para a direita, ideal para comparações lado a lado, como diferentes versões de um produto ou ângulos diferentes da mesma cena
- **Grelha 3×3**: as imagens organizam-se numa grelha, perfeita para agrupar várias fotos com estilo coerente, publicações de nove imagens ou partilha de álbuns

## Até 20 imagens

A aplicação permite combinar até 20 imagens numa só (até 9 no modo grelha). Se o limite for excedido aparece um aviso, para evitar que o ficheiro de saída fique demasiado grande.

## Reordenar livremente

Após selecionar as imagens, a aplicação mostra-as numa grelha onde pode:

- **Reordenar arrastando**: mantenha premida uma imagem e arraste-a até à posição pretendida
- **Eliminar uma imagem**: toque no botão de eliminar no canto superior direito da imagem
- **Continuar a adicionar**: toque no botão "Adicionar mais" para continuar a selecionar imagens

Depois de ajustar a ordem, alterne entre os diferentes modos de combinação para pré-visualizar o resultado: o que vê é o que obtém.

## Combinação local

Todo o processo é realizado no dispositivo local; nem a imagem original nem o resultado são carregados para qualquer servidor. Para mais detalhes sobre o tratamento de dados consulte a [política de privacidade](/pt/image-converter/privacy/).
