## 크기 조정

이미지 해상도가 너무 커서 공간을 차지하거나, 너무 작아서 화면에서 흐릿하게 보일 때 — 크기 조정은 이미지 처리의 기본적인 요구 사항입니다. Image Converter는 직관적인 크기 조정 도구를 제공합니다.

## 확대/축소 vs 자르기

두 가지 개념을 구분해야 합니다.

- **자르기**: 원본 이미지에서 일부를 잘라내어 출력 이미지의 "내용"이 변경됩니다
- **크기 조정(확대/축소)**: 전체 이미지를 비율에 맞춰 확대하거나 축소하여 출력 이미지의 "내용"이 변경되지 않습니다

크기 조정이 적합한 상황: 4000×3000의 큰 이미지를 1920×1080으로 변경하여 화면에 맞추거나, 모든 사진을 동일한 크기로 통일하여 콜라주를 만들거나, 이미지 해상도를 목표 해상도 이하로 압축합니다.

## 프리셋 및 사용자 지정

앱은 일반적인 해상도 프리셋(예: 1920×1080, 1280×720, 1080×1080 등)을 제공하며, 사용자 지정 너비와 높이도 지원합니다.

- 목표 너비를 입력하면 높이가 원본 비율에 따라 자동 계산됩니다
- 목표 높이를 입력하면 너비가 원본 비율에 따라 자동 계산됩니다
- 가로세로 비율 잠금 스위치를 끄면 너비와 높이를 자유롭게 지정할 수 있습니다(주의: 자유 지정 시 가로세로 비율이 변경될 수 있음)

## 가로세로 비율 유지의 중요성

가로세로 비율을 잠그지 않으면 이미지가 늘어나거나 납작해집니다. 인물 사진은 변형되고, 풍경은 왜곡되며, 텍스트는 휘게 됩니다. 특별한 요구 사항이 없는 한 원본 가로세로 비율을 항상 유지하고 크기만 변경할 것을 권장합니다.

크기 조정 과정은 기기에서 로컬로 완료되며, 원본 이미지는 업로드되지 않습니다. 확대/축소 결과는 시스템 공유 패널을 통해 내보내집니다. 자세한 데이터 처리 설명은 [개인정보 처리방침](/ko/image-converter/privacy/)을 참조하십시오.
