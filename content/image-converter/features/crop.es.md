## Recorte libre

Capturas con bordes sobrantes, fotos en las que el sujeto principal es demasiado pequeño y hay que ampliarlo, o imágenes que deben recortarse a una proporción concreta para una plataforma: en todos estos casos hace falta recortar. Image Converter usa la herramienta de recorte del sistema, con un manejo intuitivo y funciones completas.

## Escenarios habituales de recorte

- **Eliminar marcas de agua / bordes**: las capturas o imágenes descargadas a menudo traen bordes o márgenes blancos innecesarios; el recorte los elimina
- **Destacar el sujeto principal**: cuando el sujeto es demasiado pequeño en la foto, recorta el entorno para ampliarlo
- **Adaptarse a las proporciones de cada plataforma**: recorta a 1:1 (avatar), 4:3 (banner horizontal) o 16:9 (portada de vídeo)
- **Adaptación a redes sociales**: recorta una imagen horizontal a 9:16 para Stories, o una vertical a 1.91:1 para cabeceras de Weibo / X

## Proporciones fijas y recorte libre

La aplicación admite dos modos de recorte:

- **Proporción fija**: elige proporciones habituales como 1:1, 4:3, 16:9 o 9:16; el marco de recorte queda bloqueado en esa proporción para obtener rápidamente tamaños estándar
- **Recorte libre**: arrastra las cuatro esquinas del marco para ajustarlo a tu gusto, ideal para eliminar espacios irregulares

## Recorte realizado en local

El recorte se ejecuta en el dispositivo local; ni la imagen original ni el resultado se suben a ningún servidor. Para más detalles sobre el tratamiento de datos consulta la [política de privacidad](/es/image-converter/privacy/).
