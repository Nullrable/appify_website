## Recorte livre

Capturas com margens a mais, fotos em que o motivo principal é demasiado pequeno e precisa de ser ampliado, ou imagens que precisam de ser recortadas numa proporção específica para uma plataforma: em todos estes casos é preciso cortar. O Image Converter utiliza a ferramenta de recorte do sistema, com uma utilização intuitiva e funções completas.

## Cenários habituais de recorte

- **Remover marcas de água / margens**: capturas ou imagens descarregadas trazem frequentemente margens ou bordas brancas desnecessárias; o recorte elimina-as
- **Destacar o motivo principal**: quando o motivo é demasiado pequeno na foto, corte a área envolvente para o ampliar
- **Adaptar à proporção da plataforma**: recorte a imagem para 1:1 (avatar), 4:3 (banner horizontal) ou 16:9 (capa de vídeo)
- **Adaptação a redes sociais**: recorte uma imagem horizontal para 9:16 para Stories, ou uma vertical para 1.91:1 para cabeçalhos de Weibo / X

## Proporção fixa e recorte livre

A aplicação suporta dois modos de recorte:

- **Proporção fixa**: escolha proporções habituais como 1:1, 4:3, 16:9 ou 9:16; a moldura de recorte fica bloqueada nessa proporção para obter rapidamente tamanhos padrão
- **Recorte livre**: arraste os four cantos da moldura para ajustar livremente, ideal para eliminar espaços irregulares

## Recorte efetuado localmente

O recorte é executado no dispositivo local; nem a imagem original nem o resultado são carregados para qualquer servidor. Para mais detalhes sobre o tratamento de dados consulte a [política de privacidade](/pt/image-converter/privacy/).
