## Konversi format gambar

Dalam penggunaan sehari-hari, kita sering perlu beralih di antara berbagai format gambar: JPG berukuran kecil (mudah dibagikan), PNG mempertahankan saluran transparansi, WebP menyeimbangkan kualitas dan ukuran, BMP/TIFF (untuk pencetakan atau pengarsipan). Image Converter mendukung konversi bolak-balik secara bebas di antara enam format utama ini, konversi dilakukan secara lokal di perangkat, file tidak diunggah ke server.

## Format yang didukung

- **JPG / JPEG**: kompresi lossy, ukuran paling kecil, paling sering digunakan untuk berbagi foto dan tampilan web
- **PNG**: kompresi lossless, mendukung transparansi, cocok untuk ikon, tangkapan layar, file desain
- **WebP**: format yang umum digunakan di web modern, menyeimbangkan kualitas dan ukuran, didukung secara native di iOS 16+
- **BMP**: format bitmap, tidak dikompresi, ukuran besar, umumnya digunakan pada sistem Windows
- **TIFF**: format lossless, cocok untuk pencetakan, penerbitan, pengarsipan

## Selesaikan konversi dalam tiga langkah

1. **Pilih gambar**: pilih gambar dari album atau aplikasi "File", aplikasi akan secara otomatis mengenali format asli
2. **Pilih format target**: daftar kandidat akan secara otomatis mengecualikan format asli, menghindari konversi bolak-balik yang tidak berarti
3. **Simpan**: hasil konversi dikirim melalui panel berbagi sistem, dapat langsung disimpan ke "File", album, atau lokasi lain

## Koreksi otomatis rotasi EXIF

Foto yang diambil dengan iPhone sering kali membawa tag rotasi EXIF, aplikasi akan secara otomatis mengoreksi arah sebelum konversi. Gambar yang diekspor akan tampil tegak di perangkat mana pun, menghindari masalah "terlihat benar di layar, miring saat diekspor".
