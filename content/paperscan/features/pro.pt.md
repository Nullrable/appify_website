Pro é uma única assinatura que libera três melhorias pensadas para usuários avançados. A versão gratuita é suficiente para a maioria; Pro remove limites e anúncios. A assinatura é gerenciada pela App Store — cancele quando quiser, sem perguntas.

## Common use cases

- Digitalize centenas de páginas por semana sem atingir o limite diário de OCR
- Use o app para trabalhar sem o banner de anúncios acima da biblioteca
- Esqueça o envio manual para a nuvem — a sincronização acontece sozinha
- Apoie a evolução contínua do app
