Tous les filtres s'exécutent sur le GPU de l'appareil, donc l'aperçu est instantané. Choisissez le rendu adapté au document : noir et blanc pour le texte imprimé, couleur magique pour les reçus passés, mode photo pour préserver l'aspect original. Ajustez la luminosité, le contraste et les ombres après la prise — chaque modification reste sur l'appareil.

## Common use cases

- Noir et blanc pour les contrats et formulaires imprimés
- Couleur magique pour restaurer les reçus passés et vieilles pages
- Mode photo pour conserver l'aspect d'origine
- Réglage rapide luminosité/contraste quand la lumière est inégale
