Каждый документ живёт в локальной библиотеке. Стройте структуру папок, помечайте документы тегами, переключайтесь между сеткой и списком, выбирайте несколько для пакетных операций, объединяйте связанные страницы и ищите по полному тексту внутри всего. Всё локально и мгновенно — без задержки синхронизации.

## Common use cases

- Создайте папку на клиента или проект и помечайте статусом (открыт / отправлен / оплачен)
- Ищите по всем чекам, вводя поставщика или сумму
- Объедините пакет из 20 страниц в один документ двумя нажатиями
- Используйте сетку для просмотра, список для плотных библиотек
