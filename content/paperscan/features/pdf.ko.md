회의 자료 50페이지를 하나의 PDF로 합치고, 열람용 암호를 설정해 휴대전화의 어떤 앱으로든 공유하세요. 직접 인쇄하거나 이메일로 보내거나 클라우드 드라이브에 업로드할 수도 있습니다. 내보내기 파이프라인은 대량 배치를 위해 최적화되어 PDF를 깔끔하고 간결하게 만듭니다.

## Common use cases

- 30페이지 계약서를 단일 첨부 파일로 고객에게 이메일
- 암호가 설정된 민감한 문서 PDF 전송
- 휴대전화에서 직접 여러 페이지 보고서 인쇄
- 폴더 전체를 하나의 PDF로 아카이빙
