Every document lives in a local library. Build folder structures, tag documents, switch between grid and list views, multi-select for batch operations, merge related pages, and search the full text inside everything. All of it is local and instant — no syncing delay.

## Common use cases

- Set up a folder per client or project and tag by status (open / sent / paid)
- Search across all your receipts by typing a vendor or amount
- Merge a 20-page scan batch into one document with two taps
- Use grid view for browsing, list view for dense libraries
