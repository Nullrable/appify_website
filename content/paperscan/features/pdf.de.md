Nehmen Sie 50 Seiten aus einem Meeting, fügen Sie sie zu einer PDF zusammen, fügen Sie ein Passwort hinzu und teilen Sie sie über eine beliebige App auf Ihrem Telefon. Direkt drucken, per E-Mail senden oder in einen Cloud-Speicher hochladen. Die Export-Pipeline ist für große Stapel optimiert und erzeugt saubere, schlanke PDFs.

## Common use cases

- Einen 30-seitigen Vertrag als einzelnen Anhang an einen Kunden mailen
- Ein passwortgeschütztes PDF mit sensiblen Dokumenten senden
- Einen mehrseitigen Bericht direkt vom Telefon aus drucken
- Einen ganzen Ordner als ein PDF für die Archivierung exportieren
