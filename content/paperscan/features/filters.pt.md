Todos os filtros rodam na GPU do dispositivo, então a pré-visualização é instantânea. Escolha o visual que se adapta ao documento: preto e branco para texto impresso, cor mágica para recibos desbotados, modo foto para preservar o visual original. Ajuste brilho, contraste e sombras após a captura — cada alteração permanece no dispositivo.

## Common use cases

- Preto e branco para contratos e formulários impressos
- Cor mágica para restaurar recibos desbotados e páginas de livros antigos
- Modo foto quando você quer manter o visual original
- Ajuste rápido de brilho/contraste quando a luz está irregular
