Ambil 50 halaman dari rapat, gabungkan menjadi satu PDF, tambahkan kata sandi, dan bagikan melalui aplikasi apa pun di ponsel Anda. Cetak langsung, kirim lewat email, atau unggah ke drive cloud. Pipeline ekspor dioptimalkan untuk batch besar dan menghasilkan file PDF yang bersih dan ringkas.

## Common use cases

- Mengirim kontrak 30 halaman sebagai satu lampiran ke klien
- Mengirim PDF sensitif yang dilindungi kata sandi
- Mencetak laporan multi-halaman langsung dari ponsel
- Mengekspor seluruh folder sebagai satu PDF untuk pengarsipan
