Cada documento vive en una biblioteca local. Construye estructuras de carpetas, etiqueta documentos, alterna entre vistas de cuadrícula y lista, selecciona varios para operaciones por lotes, fusiona páginas relacionadas y busca el texto completo dentro de todo. Todo es local e instantáneo: sin retraso de sincronización.

## Common use cases

- Crea una carpeta por cliente o proyecto y etiqueta por estado (abierto / enviado / pagado)
- Busca en todos tus recibos escribiendo un proveedor o una cantidad
- Fusiona un lote de 20 páginas escaneadas en un solo documento con dos toques
- Usa la vista de cuadrícula para navegar, lista para bibliotecas densas
