Возьмите 50 страниц с совещания, объедините в один PDF, добавьте пароль и поделитесь через любое приложение на телефоне. Печатайте сразу, отправляйте по почте или загружайте в облачное хранилище. Конвейер экспорта оптимизирован под большие пакеты и создаёт чистые компактные PDF.

## Common use cases

- Отправить 30-страничный контракт одним вложением клиенту по почте
- Отправить PDF с паролем для конфиденциальных документов
- Распечатать многостраничный отчёт прямо с телефона
- Экспортировать всю папку одним PDF для архива
