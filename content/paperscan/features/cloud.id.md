Sinkronisasi cloud adalah fitur khusus Pro. Saat diaktifkan, perpustakaan Anda dicerminkan ke Google Drive atau iCloud Anda sendiri — bukan ke infrastruktur kami. Pindaian baru diunggah otomatis. Unduhan hanya berjalan saat Anda secara eksplisit memulihkan, sehingga sinkronisasi tidak pernah menimpa pengeditan lokal. Batalkan kapan saja; data Anda tetap di tempat Anda meletakkannya.

## Common use cases

- Beralih ponsel dan lanjut tepat dari tempat Anda berhenti
- Jaga cadangan jika perangkat hilang atau rusak
- Bagikan perpustakaan dengan pasangan atau keluarga menggunakan Drive bersama
- Pulihkan di perangkat baru setelah menghapus perangkat lama

## Pro

> Pro membuka sinkronisasi cloud — versi gratis tetap hanya lokal.
