Todos los filtros se ejecutan en la GPU del dispositivo, por lo que la vista previa es instantánea. Elige el aspecto que se adapte al documento: blanco y negro para texto impreso, color mágico para recibos desvanecidos, modo foto para conservar el aspecto original. Ajusta brillo, contraste y sombras después del disparo — cada cambio permanece en el dispositivo.

## Common use cases

- Blanco y negro para contratos y formularios impresos
- Color mágico para restaurar recibos desvanecidos y páginas antiguas
- Modo foto cuando quieras conservar el aspecto original
- Ajuste rápido de brillo/contraste cuando la luz es irregular
