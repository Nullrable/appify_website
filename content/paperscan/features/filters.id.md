Semua filter berjalan pada GPU perangkat, sehingga pratinjau instan. Pilih tampilan yang sesuai dengan dokumen: hitam-putih untuk teks tercetak, magic color untuk tanda terima yang pudar, mode foto untuk mempertahankan tampilan asli. Sesuaikan kecerahan, dan bayangan setelah pengambilan — setiap perubahan tetap di perangkat.

## Common use cases

- Hitam-putih untuk kontrak dan formulir tercetak
- Magic color untuk memulihkan tanda terima pudar dan halaman buku lama
- Mode foto saat ingin mempertahankan tampilan asli
- Penyesuaian cepat kecerahan/kontras saat pencahayaan tidak merata
