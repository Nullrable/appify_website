OCR работает полностью на устройстве с помощью ML-китов Apple и Google. Выделяйте текст в скане, копируйте в другое приложение или позволяйте строке поиска индексировать каждую страницу библиотеки. В бесплатной версии щедрая дневная квота; Pro снимает лимит для тех, кто сканирует сотни страниц в неделю.

## Common use cases

- Скопировать номер телефона или адрес со скана визитки
- Искать по году чеков по имени поставщика
- Цитировать отрывок из скана книги без перепечатки
- Пакетный OCR бумажной стопки, чтобы она стала доступной для поиска

## Pro

> Pro снимает дневной лимит OCR и обрабатывает всю библиотеку за один проход.
