Setiap dokumen hidup di perpustakaan lokal. Bangun struktur folder, beri tag pada dokumen, beralih antara tampilan grid dan daftar, pilih banyak untuk operasi batch, gabungkan halaman terkait, dan cari teks lengkap di dalam semuanya. Semuanya lokal dan instan — tanpa penundaan sinkronisasi.

## Common use cases

- Buat folder per klien atau proyek dan beri tag berdasarkan status (terbuka / terkirim / dibayar)
- Cari di semua tanda terima dengan mengetik nama vendor atau jumlah
- Gabungkan pemindaian 20 halaman menjadi satu dokumen dengan dua ketukan
- Gunakan tampilan grid untuk menjelajah, daftar untuk perpustakaan padat
