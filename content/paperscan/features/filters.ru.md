Все фильтры работают на GPU устройства, поэтому предпросмотр мгновенный. Выбирайте вид под документ: чёрно-белый для печатного текста, волшебный цвет для выцветших чеков, фото-режим для сохранения оригинала. Настройте яркость, контраст и тени после съёмки — всё остаётся на устройстве.

## Common use cases

- Чёрно-белый для контрактов и печатных форм
- Волшебный цвет для восстановления выцветших чеков и старых страниц
- Фото-режим, когда хочется сохранить оригинальный вид
- Быстрая подстройка яркости/контраста при неровном свете
