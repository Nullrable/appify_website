Paper Scan의 문서 목록은 중첩 폴더와 다중 태그를 모두 지원합니다. 폴더는 "어디에 있는지", 태그는 "무엇인지"에 답합니다. 함께 쓰면 수백 건의 라이브러리를 수동 검색 없이 찾을 수 있습니다.

### 폴더 모델

폴더는 트리를 형성하며 각 문서는 정확히 하나의 폴더에 속합니다. 안정적이고 계층적이며 문서당 하나인 차원에 적합합니다:

- 시간 기반 아카이브(연/분기/월)
- 프로젝트 구조(고객/프로젝트/단계)
- 물리적 위치(집/보일러/매뉴얼)
- 단일 관계 계정·공급업체

폴더 계층은 4단 이하를 권장합니다. 더 깊으면 보통 두 차원을 하나의 트리로 인코딩한 것이며 검색이 불안정해집니다.

### 태그 모델

태그는 평탄하고 가산적입니다. 문서는 임의 개수의 태그를 가질 수 있으며, 단일 폴더에 맞지 않는 횡단 질문에 답합니다:

- 문서 유형(`receipt`, `contract`, `manual`, `warranty`)
- 작업 상태(`urgent`, `to-review`, `to-file`)
- 기간 기반 그룹(`tax-2024`, `tax-2025`)
- 출처(`scanned-here`, `imported`)

태그 보기는 폴더를 넘어 일치하는 문서를 묶어 보여줍니다.

### 권장 워크플로

1. 적절한 폴더에 바로 스캔하세요. 캡처 중 새 폴더 만들기보다 기존 계층 활용.
2. 폴더 경계를 넘는 태그를 답니다(`urgent`, `q2-renewal` 등).
3. 태그 보기를 주기적으로 훑어 급한 스캔을 정리하세요.

### 피해야 할 패턴

- 과도한 태깅(문서당 2~3개 한도)
- 연도를 태그에 두기(폴더에 둠)
- 깊은 폴더 중첩(4단 한도)
- 불필요한 폴더명 변경(공유 링크, 导出, 동기화에서 참조됨)

100건 미만이고 분류가 명확하면 폴더만으로 충분합니다. 보통 200건 전후로 횡단 검색이 잦아지면 태그를 추가하세요.
