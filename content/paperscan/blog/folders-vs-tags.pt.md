A lista de Documentos do Paper Scan suporta pastas aninhadas e múltiplas tags. Pastas respondem "onde vive este documento", tags respondem "o que é". Juntas tornam uma biblioteca de centenas de documentos localizável sem busca manual.

### Modelo de pastas

Pastas formam uma árvore; cada documento pertence a exatamente uma pasta. Ideal para dimensões estáveis, hierárquicas, uma por documento: arquivos temporais (ano / trimestre / mês), estruturas de projeto (cliente / projeto / fase), locais físicos (casa / boiler / manuais), contas e fornecedores com relação única.

Mantenha a hierarquia em 4 níveis ou menos. Mais fundo geralmente indica duas dimensões codificadas em uma árvore, tornando a recuperação frágil.

### Modelo de tags

Tags são planas e aditivas. Um documento pode levar várias tags; respondem a perguntas transversais que não cabem em uma pasta: tipo (`receipt`, `contract`, `manual`, `warranty`), status (`urgent`, `to-review`, `to-file`), agrupamento temporal (`tax-2024`, `tax-2025`), fonte (`scanned-here`, `imported`).

### Fluxo recomendado

1. Escaneie direto para a pasta apropriada.
2. Aplique tags transversais (`urgent`, `q2-renewal`).
3. Revise a visualização de tags periodicamente.

### Padrões a evitar

- Tagging excessivo (2–3 tags / doc).
- Anos em tags (vão nas pastas).
- Aninhamento profundo (4 níveis máx.).
- Renomear sem necessidade.

Abaixo de 100 documentos, pastas bastam. Por volta dos 200, adicione tags.
