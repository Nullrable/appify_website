La liste Documents de Paper Scan prend en charge à la fois les dossiers imbriqués et les multi-étiquettes. Les dossiers répondent à « où vit ce document », les étiquettes à « qu'est-ce que c'est ». Ensemble, ils rendent une bibliothèque de plusieurs centaines de documents trouvable sans recherche manuelle.

### Modèle dossiers

Les dossiers forment un arbre ; chaque document appartient à exactement un dossier. Idéal pour les dimensions stables, hiérarchiques, uniques par document : archives temporelles (année / trimestre / mois), structures de projets (client / projet / phase), emplacements physiques (maison / chaudière / manuels), comptes et fournisseurs à relation unique.

Restez à 4 niveaux ou moins. Au-delà, vous encodez souvent deux dimensions dans un seul arbre, ce qui rend la récupération fragile.

### Modèle étiquettes

Les étiquettes sont plates et additives. Un document peut porter plusieurs étiquettes ; elles répondent aux questions transverses qui ne tiennent pas dans un seul dossier : type (`receipt`, `contract`, `manual`, `warranty`), statut (`urgent`, `to-review`, `to-file`), regroupement temporel (`tax-2024`, `tax-2025`), source (`scanned-here`, `imported`).

### Workflow recommandé

1. Scannez directement dans le bon dossier.
2. Appliquez des étiquettes transverses (`urgent`, `q2-renewal`, etc.).
3. Revoyez périodiquement la vue étiquettes.

### À éviter

- Étiquetage excessif (2–3 par doc max).
- Années en étiquettes (place dans les dossiers).
- Imbrication trop profonde (4 niveaux max).
- Renommer sans nécessité (référencés par liens de partage, 导出, synchro).

Pour moins de 100 documents, les dossiers suffisent. Vers 200, ajoutez les étiquettes.
