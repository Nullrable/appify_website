Экспорт PDF в Paper Scan спроектирован для случая, когда несколько отсканированных страниц нужно объединить в один файл и доставить через стандартное системное окно «Поделиться». Поддерживает пакетное слияние, опциональную защиту паролем и именование, всё на устройстве.

### Стандартный поток экспорта

1. **Множественный выбор в списке документов.** Долгое нажатие на документ включает режим выбора, затем нажмите на остальные. Для пакетов в одном месте есть ярлык «выбрать всё в папке».
2. **Нажмите кнопку «Поделиться».** Откроется системное окно «Поделиться». Экспорт PDF от Paper Scan появится среди целей.
3. **Настройте параметры.** Включите слияние, если объединяете несколько страниц, введите пароль при необходимости и по желанию задайте имя файла. Нажмите «Экспорт».
4. **Дождитесь обработки.** На современных устройствах пакет из 50 страниц с двумя фильтрами обычно завершается менее чем за 5 секунд. Пакет из 300 страниц занимает 15–30 секунд. В окне экспорта отображается индикатор прогресса; приложение остаётся отзывчивым.
5. **Поделитесь.** Когда файл готов, появляется стандартное окно «Поделиться». Файл можно отправить по почте, через AirDrop, Drive, Slack или любое другое приложение, принимающее PDF.

### Распространённые сценарии

- **Пересылка материалов совещания.** Объедините 50–80 страниц контрактов и подписанных приложений в один PDF для юридической проверки.
- **Архивирование расходных чеков.** Объедините чеки за месяц в один PDF для бухгалтерии.
- **Обмен исследовательскими пакетами.** Скомпилируйте несколько справочных документов в один файл для коллег.
- **Архивирование проектов.** Соберите все документы завершённого проекта в один поставляемый артефакт.

### Установка пароля

Окно экспорта содержит одно поле пароля и поле «подтверждение пароля» для проверки ввода. Экспорт продолжается только при совпадении; несовпадающие значения отклоняются до обработки.

Если поле пароля оставлено пустым, на выходе стандартный PDF без ограничений. При заданном пароле получатели должны ввести его перед открытием любой страницы. Защита паролем рекомендуется для документов с персональными данными: контракты, медицинские записи, финансовые отчёты.

Практическое руководство: оставляйте пустым, если защита явно не требуется. Удалить пароль из PDF после — сложно, тогда как незащищённый PDF можно повторно экспортировать с паролем при необходимости.

### Когда объединять, когда разделять

Один большой PDF — не всегда правильный вывод. Разделять лучше, когда: у получателей ограничена память устройств, разным получателям нужны разные части пакета, или требуются разные пароли. У каждого экспортируемого файла собственное поле пароля.

Paper Scan экспортирует выбор как есть. Принудительного слияния нет; вывод отражает выбор пользователя.

### Производительность на больших пакетах

300+ страниц обычно занимают 15–30 секунд; полоса прогресса показывает статус. Сканы с тяжёлыми фильтрами (например, magic color на выцветшем чеке) занимают примерно вдвое больше, чем чистые. Шифрование заметно не замедляет экспорт на современных устройствах (узкое место — кодирование изображений). Крупный зашифрованный экспорт нагревает устройство и расходует несколько процентов аккумулятора, что приемлемо для эпизодического использования.
