L'esportazione PDF di Paper Scan è pensata per il caso in cui più pagine scansionate devono essere combinate in un unico file e recapitate tramite il foglio di condivisione standard del sistema. Supporta fusione in batch, protezione opzionale tramite password e denominazione, il tutto sul dispositivo.

### Flusso di esportazione standard

1. **Selezione multipla nell'elenco Documenti.** Tieni premuto un documento per entrare in modalità selezione, poi tocca gli altri. È disponibile una scorciatoia "seleziona tutto nella cartella" per i batch nella stessa posizione.
2. **Tocca il pulsante Condividi.** Si apre il foglio di condivisione del sistema. L'esportazione PDF di Paper Scan appare tra le destinazioni.
3. **Configura le opzioni.** Attiva la fusione se combini più pagine, inserisci una password se necessario e assegna opzionalmente un nome al file. Tocca Esporta.
4. **Attendi l'elaborazione.** Su dispositivi recenti, un batch di 50 pagine con due filtri di solito termina in meno di 5 secondi. Un batch di 300 pagine richiede 15–30 secondi. Il foglio di esportazione mostra un indicatore di avanzamento; l'app resta reattiva.
5. **Condividi.** Quando il file è pronto, appare il foglio di condivisione standard. Il file può essere inviato via email, AirDrop, Drive, Slack o qualsiasi app che accetti PDF.

### Casi d'uso comuni

- **Inoltrare materiali di riunione.** Unisci 50–80 pagine di contratti e allegati firmati in un unico PDF per la revisione legale.
- **Archiviare ricevute spese.** Unisci le ricevute di un mese in un unico PDF per la contabilità.
- **Condividere pacchetti di ricerca.** Compila più documenti di riferimento in un unico file per i colleghi.
- **Archiviare progetti.** Raggruppa tutti i documenti di un progetto completato in un unico deliverable.

### Impostare una password

Il foglio di esportazione contiene un unico campo password con un campo "conferma password" per la verifica. l'esportazione procede solo quando entrambi corrispondono; input non corrispondenti vengono rifiutati prima dell'elaborazione.

Lasciando il campo password vuoto, l'output è un PDF standard senza restrizioni. Impostando una password, i destinatari devono inserirla prima di aprire qualsiasi pagina. La protezione con password è consigliata per documenti contenenti dati personali: contratti, cartelle cliniche, rendiconti finanziari.

Guida pratica: lascia vuoto a meno che la protezione non sia esplicitamente richiesta. Rimuovere una password da un PDF dopo è difficile, mentre un PDF senza protezione può essere ri-esportato con password se necessario.

### Quando unire, quando dividere

Un unico PDF grande non è sempre l'output corretto. È meglio dividere quando: la memoria dei dispositivi destinatari è limitata, diversi destinatari necessitano di parti diverse del batch, o servono password diverse. Ogni file esportato ha il proprio campo password.

Paper Scan esporta la selezione così com'è. Nessuna fusione forzata; l'output riflette ciò che l'utente ha selezionato.

### Prestazioni per batch grandi

300+ pagine richiedono in genere 15–30 secondi; la barra di avanzamento mostra lo stato. Le scansioni con filtri pesanti (es. magic color su una ricevuta sbiadita) richiedono circa il doppio rispetto alle scansioni pulite. La crittografia non rallenta in modo evidente l'esportazione sui dispositivi moderni (il collo di bottiglia è la codifica delle immagini). Un'esportazione crittata grande scalda il dispositivo e consuma alcuni punti percentuali di batteria, il che è accettabile per un uso occasionale.
