Daftar Dokumen Paper Scan mendukung folder bertingkat dan banyak tag. Folder menjawab "di mana", tag menjawab "apa". Dipakai bersama, keduanya membuat ratusan dokumen mudah ditemukan tanpa pencarian manual.

### Model folder

Folder membentuk pohon; setiap dokumen berada di tepat satu folder. Cocok untuk dimensi stabil, hierarkis, satu per dokumen: arsip berbasis waktu (tahun / kuartal / bulan), struktur proyek (klien / proyek / fase), lokasi fisik (rumah / boiler / manual), serta akun dan vendor relasi tunggal.

Disarankan menjaga hierarki folder maksimal empat tingkat. Lebih dalam biasanya menandakan dua dimensi dikodekan ke satu pohon, membuat pencarian rapuh.

### Model tag

Tag datar dan aditif. Satu dokumen dapat membawa berapa pun jumlah tag; tag menjawab pertanyaan lintas batas yang tidak pas dalam satu folder: jenis dokumen (`receipt`, `contract`, `manual`, `warranty`), status tindakan (`urgent`, `to-review`, `to-file`), pengelompokan berbasis waktu (`tax-2024`, `tax-2025`), sumber (`scanned-here`, `imported`).

### Alur kerja yang direkomendasikan

1. Pindai langsung ke folder yang sesuai; pakai hierarki yang ada.
2. Pasang tag lintas folder (`urgent`, `q2-renewal`, dll.).
3. Tinjau tampilan tag secara berkala untuk merapikan dokumen yang dipindai terburu-buru.

### Pola yang harus dihindari

- Memberi tag berlebihan (2–3 tag / dokumen adalah batas).
- Meletakkankan tahun di tag (masuk folder).
- Folder bertingkat terlalu dalam (maks. empat tingkat).
- Mengganti nama folder tanpa keperluan (direferensikan oleh tautan berbagi, 导出, sinkronisasi).

Untuk pustaka di bawah 100 dokumen, folder saja cukup. Sekitar 200 dokumen, tambahkan tag untuk pencarian lintas batas.
