ไปป์ไลน์ OCR และการแปลเดียวกันที่ประมวลผลการจับภาพสดยังประมวลผลภาพถ่ายที่นำเข้าจากคลังของอุปกรณ์ด้วย ใช้สำหรับสกรีนช็อต ภาพถ่ายที่บันทึกไว้ของป้ายหรือเมนู และภาพที่เพื่อนแชร์

## วิธีการทำงานของการนำเข้า

1. **เลือกจากแกลเลอรี** การแตะไอคอนแกลเลอรีในหน้ากล้องจะเปิดตัวเลือกรูปภาพของระบบผ่าน `image_picker` ภาพที่เลือกจะถูกคัดลอกไปยังไดเรกทอรีชั่วคราวของแอป ต้นฉบับจะอยู่ในที่เดิม
2. **อ่านการวางแนวทางกายภาพ** ภาพถ่ายในคลังมีแท็กการวางแนว EXIF ที่เชื่อถือได้ ดังนั้นเส้นทางการนำเข้าจึงใช้ EXIF โดยตรงโดยไม่แตะต้องมาตรความเร่ง ภาพจะถูกหมุนให้อยู่ในแนวตั้งที่ถูกต้องก่อน OCR
3. **ไปป์ไลน์ OCR เดียวกัน** ภาพถูกป้อนเข้าสู่เอนจิน `vision_text_recognition` ที่ fork แล้วตัวเดียวกับที่ใช้ในเส้นทางกล้อง ไม่จำเป็นต้องจัดการพิเศษสำหรับ "นำเข้า" เทียบกับ "จับภาพ" — หน้าผลลัพธ์และพฤติกรรมการแปลเหมือนกัน
4. **บันทึกลงประวัติ** เช่นเดียวกับการจับภาพด้วยกล้อง ภาพถ่ายที่นำเข้าสามารถบันทึกลงในประวัติการแปลในเครื่องได้ สำเนาที่บันทึกเป็นภาพขนาดย่อที่บีบอัด ไม่ใช่ภาพถ่ายในคลังฉบับเต็ม เพื่อให้พื้นที่จัดเก็บยังคงอยู่ในขอบเขต

## เมื่อใดควรนำเข้าแทนการจับภาพ

- **สกรีนช็อต** แปลสตริง UI กล่องโต้ตอบข้อผิดพลาด หรือส่วนของเว็บที่บันทึกเป็นสกรีนช็อต
- **ภาพถ่ายที่ถ่ายไปแล้ว** แปลภาพจากการเดินทาง การประชุม หรือแชทของเพื่อนโดยไม่ต้องถ่ายใหม่
- **ภาพร่างหรือไวท์บอร์ด** ภาพถ่ายบันทึกไวท์บอร์ดและภาพร่างมักจะชัดเจนกว่าการถ่ายซ้ำ โดยเฉพาะเมื่อพื้นผิวมีแสงสะท้อน
- **เอกสาร** ภาพสแน็ปช็อตของใบเสร็จ นามบัตร และฉลากที่จับโดยแอปอื่นสามารถแปลได้โดยไม่ต้องสลับเครื่องมือ

## ความเป็นส่วนตัว

ภาพถ่ายที่นำเข้าผ่านไปป์ไลน์บนอุปกรณ์เดียวกับภาพถ่ายสด ภาพจะถูกประมวลผลในหน่วยความจำและไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ใด ๆ ที่เราดำเนินการ สำเนาประวัติที่บันทึกจะถูกจัดเก็บไว้บนอุปกรณ์เท่านั้น ในฐานข้อมูลท้องถิ่นของแอป และสามารถลบทีละรายการจากหน้าประวัติ

## ข้อจำกัด

- **การหมุนที่มีอยู่จะได้รับการเคารพ** ภาพถ่ายที่ถูกหมุนโดยระบบปฏิบัติการจะถูกหมุนกลับเป็นแนวตั้งก่อน OCR ซึ่งเป็นสาเหตุที่พบบ่อยที่สุดของปัญหา "OCR ส่งคืนข้อความที่อ่านไม่ออก" เมื่อนำเข้า
- **ต้นฉบับขนาดใหญ่จะถูกลดขนาดลง** ภาพถ่ายที่เกินความละเอียดที่แนะนำของเอนจิน OCR จะถูกลดขนาดก่อนการรู้จำ ภาพต้นฉบับบนอุปกรณ์จะไม่ได้รับผลกระทบ
- **ไม่มีการนำเข้าเป็นชุด** แต่ละภาพต้องการการแตะครั้งเดียวของตัวเอง หากคุณต้องการแปลภาพถ่ายที่บันทึกไว้จำนวนมาก ให้รันทีละภาพ OCR + การแปลสำหรับภาพเดียวมักจะเสร็จสิ้นภายในไม่กี่วินาที
