텍스트 번역 페이지는 소스가 이미 텍스트인 경우를 위한 카메라 페이지와는 별도의 진입점입니다. 카메라 페이지 하단에서 열어 단락을 붙여넣거나 입력하거나 받아쓰세요. 동일한 ML Kit 엔진이 번역을 반환합니다.

## 별도의 페이지가 필요한 이유

카메라 OCR은 이미지에 최적화되어 있습니다. 소스가 이미 텍스트(이메일 스니펫, 채팅 메시지, 붙여넣은 단락)인 경우 OCR 단계는 오버헤드입니다. 텍스트 번역 페이지는 OCR을 완전히 건너뛰고 입력을 ML Kit 번역기에 직접 전달합니다.

또한 사진을 찍는 대신 복사하여 붙여넣기로 더 긴 단락을 일괄 번역할 수 있습니다. 사진을 찍기에 편리한 페이지가 없는 밀도 있는 텍스트의 경우 이것이 더 빠르고 정확합니다.

## 작동 방식

- **공유 언어 상태.** 텍스트 페이지는 카메라 페이지와 동일한 소스/대상 언어 쌍을 읽고 씁니다. 한 곳에서 대상 언어를 선택하면 다른 곳에도 적용됩니다. 앞뒤로 전환해도 언어를 다시 선택할 필요가 없습니다.
- **소스 자동 감지.** 소스가 "자동 감지"로 설정된 경우 앱은 입력 텍스트에 대해 Dart 레이어 문자 집합 휴리스틱을 실행하여 ML Kit 지원 언어 중에서 선택합니다. 순수 라틴 문자는 영어로 기본 설정되고, 한자는 간체 중국어로 기본 설정되며, 혼합 스크립트는 다수 문자 클래스를 따릅니다.
- **단일 패스 번역.** 전체 입력이 한 번의 호출로 ML Kit으로 전송됩니다. 결과가 버튼 아래의 입력 영역을 대체합니다. 다시 번역하려면 입력을 지웁니다.
- **키보드 처리.** 번역을 탭하면 온스크린 키보드가 닫혀 결과 영역이 키보드 뒤에 숨겨지지 않습니다.

## 사용 시기

- **긴 단락.** 여러 문장 텍스트를 입력하거나 붙여넣습니다. 텍스트가 가득한 화면을 촬영하면 OCR 노이즈가 발생하지만 텍스트를 붙여넣으면 노이즈가 발생하지 않습니다.
- **채팅 스니펫.** 카메라를 열기 위해 대화를 떠나지 않고 친구의 짧은 메시지를 번역합니다.
- **텍스트가 있는 화면.** 시스템 공유를 통해 스크린샷에서 텍스트를 가져와 텍스트 번역 페이지에 붙여넣어 OCR보다 깨끗한 번역을 얻습니다.
- **음성 받아쓰기.** 시스템 받아쓰기 키를 사용하여 입력 대신 텍스트를 받아씁니다.

## 제한 사항

- **서식 보존 없음.** 일반 텍스트만 가능. Markdown, 굵게, 기울임꼴 및 기타 서식은 삭제됩니다.
- **기록 자동 저장 없음.** 카메라 캡처와 달리 텍스트 번역은 자동 저장되지 않습니다. 결과는 지우기를 탭하거나 탐색할 때까지 결과 영역에 남아 있습니다.
