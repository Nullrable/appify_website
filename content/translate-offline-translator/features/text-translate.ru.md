Страница перевода текста — это отдельный вход со страницы камеры для случаев, когда источник уже является текстом. Откройте её снизу страницы камеры и вставьте, наберите или продиктуйте абзац; тот же движок ML Kit возвращает перевод.

## Почему отдельная страница

OCR камеры оптимизирован для изображений. Когда источник уже текст — фрагмент письма, сообщение в чате, вставленный абзац — шаг OCR избыточен. Страница перевода текста полностью пропускает OCR и передаёт ввод напрямую переводчику ML Kit.

Она также позволяет переводить пакетно, копируя и вставляя более длинный абзац, вместо того чтобы его фотографировать. Для плотного текста без удобной страницы для фотографирования это быстрее и точнее.

## Как это работает

- **Общее состояние языка.** Текстовая страница читает и пишет ту же пару исходный/целевой язык, что и страница камеры. Выбор целевого языка в одном месте применяется к другому; переключение туда и обратно не требует повторного выбора языков.
- **Авто-определение для источника.** Если источник установлен в «Авто-определение», приложение запускает эвристику на уровне классов символов на Dart по входному тексту, чтобы выбрать между поддерживаемыми ML Kit языками. Чистая латиница по умолчанию — английский; символы хань по умолчанию — упрощённый китайский; смешанные шрифты следуют за классом символов большинства.
- **Однопроходный перевод.** Весь ввод отправляется в ML Kit одним вызовом. Результат заменяет область ввода под кнопкой; очистите ввод, чтобы перевести снова.
- **Обработка клавиатуры.** Нажатие «Перевести» закрывает экранную клавиатуру, чтобы область результата не была скрыта за ней.

## Когда использовать

- **Длинные абзацы.** Наберите или вставьте текст из нескольких предложений. Фотографирование экрана, полного текста, вносит шум OCR; вставка текста — нет.
- **Фрагменты чата.** Переведите короткое сообщение от друга, не покидая разговор, чтобы открыть камеру.
- **Экраны с текстом.** Извлеките текст из скриншота через системную отправку и вставьте его в страницу перевода текста для более чистого перевода, чем OCR.
- **Голосовая диктовка.** Используйте системную клавишу диктовки, чтобы диктовать текст вместо набора.

## Ограничения

- **Форматирование не сохраняется.** Только обычный текст. Markdown, жирный, курсив и другое форматирование отбрасываются.
- **Автосохранение в историю отсутствует.** В отличие от снимков камеры, текстовые переводы автоматически не сохраняются. Результат остаётся в области результата, пока вы не нажмёте «Очистить» или не уйдёте со страницы.
