該應用程式透過 Google ML Kit 在裝置本地翻譯 19 種語言。完整列表：阿拉伯語、中文（簡體）、捷克語、荷蘭語、英語、法語、德語、克羅埃西亞語、匈牙利語、義大利語、日語、韓語、波蘭語、葡萄牙語、羅馬尼亞語、俄語、斯洛伐克語、斯洛維尼亞語和西班牙語。隨著 ML Kit 推出新的裝置本地模型，將新增新的語言。

## 語言選取器

選取器是選擇來源和目標語言的唯一進入點，可從相機頁面或文字翻譯頁面頂部的語言列存取。

- **搜尋。** 在搜尋欄位中輸入以按英文名稱或語言代碼過濾。鍵入時清單會更新。
- **最近使用。** 頂部區段顯示你在最近幾次翻譯中使用的語言。選擇會自動將它們移至頂部。
- **自動偵測（僅限來源）。** 顯示為來源選取器中的第一個選項。選擇它會使應用程式在每次拍攝時猜測來源語言（見下文）。
- **所有語言。** 在最近使用區段下方，是 19 種支援語言的完整清單及其國旗。

來源和目標選取器可以獨立開啟。選擇與目標相同的來源會在選取器中醒目提示，以防止意外的同翻譯。

## 來源的自動偵測

當來源設定為「自動偵測」時，應用程式需要在每次翻譯時挑選特定的 ML Kit 來源語言。使用兩種策略：

- **對於照片拍攝。** OCR 引擎的每區塊語言提示會被彙總；跨區塊的主要語言成為 ML Kit 來源。單語言頁面解析乾淨；混合字型頁面回退到預設值。
- **對於文字翻譯。** Dart 層啟發式按字型類別計算字元：漢字 → 簡體中文，假名 → 日文，韓文字母 → 韓文，拉丁文 → 英文，西里爾文 → 俄文，阿拉伯文 → 阿拉伯文等。空白或僅空白輸入預設為英文。

自動偵測永遠不會無聲失敗。頁面在翻譯執行時始終具有特定的 ML Kit 來源語言。

## 為什麼是 19 種而不是更多

此計數受 ML Kit 作為裝置本地模型發佈的內容限制。此清單之外的語言無法使用 ML Kit 在裝置本地翻譯。清單經過精心策劃：每個條目都有一個 10–50 MB 的可下載模型。選取器排除 ML Kit 不支援的語言，即使它們是有效的 BCP 47 代碼。

## UI 的國際化

應用程式本身的介面（選單、設定、錯誤訊息）已翻譯為 10 種語言：阿拉伯語、英語、德語、韓語、法語、日語、俄語、西班牙語、越南語和中文（簡體）。翻譯語言對於幾個常見配對（en ↔ ja、en ↔ zh、en ↔ es、en ↔ fr）是 i18n 集的超集。
