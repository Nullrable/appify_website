Каждый снимок камеры можно сохранить в локальной истории переводов. Каждая запись хранит исходное фото (сжатое), определённый исходный язык, целевой язык, блоки OCR и переводы по блокам. Открытие сохранённой записи воспроизводит страницу результатов в режиме только для чтения.

## Что хранится

Каждая запись истории содержит:

- **Исходное фото** в виде миниатюры JPEG, уменьшенной до максимальной длины края. Фото в полном разрешении отбрасывается после уменьшения для ограничения хранилища.
- **Исходный язык**, определённый OCR (или установленный вручную).
- **Целевой язык**, выбранный для захвата.
- **Блоки OCR** с их ограничивающими рамками, распознанным текстом и уверенностью.
- **Переводы** по блокам и соединённый полный абзацный перевод.
- **Временная метка создания** для сортировки и отображения.

Никакая копия фото или текста перевода не загружается на серверы, которыми мы управляем. Вся история хранится в локальной базе данных SQLite на устройстве, управляемой Drift.

## Как заполняется история

- **Снимки камеры.** После завершения OCR + перевода страница результатов предлагает действие «Сохранить». Сохранение сохраняет запись, описанную выше.
- **Импортированные фото.** Тот же поток: после перевода страница результатов может сохранить запись в историю.
- **Текстовые переводы.** Не сохраняются автоматически. Текстовые переводы появляются только в области результата страницы перевода текста и исчезают при «Очистить» или навигации. Используйте камеру или импорт, если вам нужна постоянная запись.

## Просмотр и удаление

- **Вид списка.** Страница истории показывает записи в обратном порядке с миниатюрой фото, фрагментом источника, фрагментом цели и временной меткой.
- **Нажмите для открытия.** Нажатие на строку открывает страницу результатов в режиме только для чтения. Наложение воспроизводится с сохранёнными переводами; ML Kit не запускается заново.
- **Удалить.** Каждая строка имеет кнопку удаления. Удаление защищено диалогом подтверждения для предотвращения случайного удаления. Удаление удаляет запись и её миниатюру фото с устройства; ничего не отправляется за пределы устройства.
- **Пустое состояние.** Когда история пуста, заполнитель объясняет, как её заполнить.

## Конфиденциальность

История — это локальный артефакт. Модель конфиденциальности приложения:

- **Нет загрузок.** История никогда не загружается, не синхронизируется и не резервируется на каком-либо сервере.
- **Нет аналитики по содержимому истории.** Отчёты о сбоях и анонимная аналитика использования не включают содержимое истории, текст OCR или текст перевода.
- **Удаление необратимо.** Удаление записи истории навсегда удаляет её из локальной базы данных. Облачной копии для очистки нет.

## Рост хранилища

Каждая запись занимает примерно 50–500 КБ в зависимости от размера фото. История из нескольких сотен записей обычно остаётся ниже 50 МБ. Фото сжимаются при сохранении; оригинал в полном разрешении никогда не сохраняется.

Чтобы освободить место: откройте страницу истории и удалите ненужные записи. Удаление приложения удаляет всю базу данных истории как часть удаления с платформы.
