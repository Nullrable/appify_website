该应用通过 Google ML Kit 在设备本地翻译 19 种语言。完整列表：阿拉伯语、中文（简体）、捷克语、荷兰语、英语、法语、德语、克罗地亚语、匈牙利语、意大利语、日语、韩语、波兰语、葡萄牙语、罗马尼亚语、俄语、斯洛伐克语、斯洛文尼亚语和西班牙语。随着 ML Kit 推出新的设备本地模型，将添加新的语言。

## 语言选择器

选择器是选择源和目标语言的唯一入口点，可从相机页面或文本翻译页面顶部的语言栏访问。

- **搜索。** 在搜索字段中输入以按英文名称或语言代码过滤。键入时列表会更新。
- **最近使用。** 顶部部分显示你在最近几次翻译中使用的语言。选择会自动将它们移至顶部。
- **自动检测（仅源）。** 显示为源选择器中的第一个选项。选择它会使应用每次捕获时猜测源语言（见下文）。
- **所有语言。** 在最近使用部分下方，是 19 种支持语言的完整列表及其国旗。

源和目标选择器可以独立打开。选择与目标相同的源会在选择器中突出显示此点，以防止意外的同语种翻译。

## 源的自动检测

当源设置为"自动检测"时，应用需要在每次翻译时选择特定的 ML Kit 源语言。使用两种策略：

- **对于照片捕获。** OCR 引擎的每块语言提示被聚合；跨块的主要语言成为 ML Kit 源。单语言页面解析干净；混合脚本页面回退到默认值。
- **对于文本翻译。** Dart 层启发式按脚本类计算字符：汉字 → 简体中文，假名 → 日语，韩文字母 → 韩语，拉丁文 → 英语，西里尔文 → 俄语，阿拉伯文字 → 阿拉伯语等。空或仅空白输入默认为英语。

自动检测永远不会静默失败。页面在翻译运行时始终具有特定的 ML Kit 源语言。

## 为什么是 19 种而不是更多

此计数受 ML Kit 作为设备本地模型发布的内容限制。此列表之外的语言无法使用 ML Kit 在设备本地翻译。该列表经过精心策划：每个条目都有一个 10–50 MB 的可下载模型。选择器排除 ML Kit 不支持的语言，即使它们是有效的 BCP 47 代码。

## UI 的国际化

应用本身的界面（菜单、设置、错误消息）已翻译为 10 种语言：阿拉伯语、英语、德语、韩语、法语、日语、俄语、西班牙语、越南语和中文（简体）。翻译语言对于几个常见对（en ↔ ja、en ↔ zh、en ↔ es、en ↔ fr）是 i18n 集的超集。
