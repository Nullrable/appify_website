## ฟรี vs Pro: อะไรเปลี่ยนเมื่อคุณสมัครสมาชิก

ระดับฟรีของแอปรวมคุณสมบัติการแปลทุกอย่าง: OCR กล้อง, การนำเข้ารูปภาพ, การแปลข้อความ, เลเยอร์ซ้อนทับบล็อก, ตัวจัดการโมเดล, ประวัติ และการสตรีมการแปลแบบบล็อก ไม่มีขีดจำกัดการใช้งาน, ไม่มีขีดจำกัดต่อตัวอักษร และไม่มีข้อจำกัดด้านภาษาในระดับฟรี Pro ลบโฆษณาและเพิ่มตรา Pro ให้กับแถบสมัครสมาชิก\n\n## สิ่งที่ฟรี\n\n- **ภาษาทั้งหมด 19 ภาษา** ทุกภาษาที่ ML Kit รองรับมีให้ในระดับฟรี\n- **การแปลไม่จำกัด** ไม่มีขีดจำกัดการใช้งาน, ไม่มีการรีเซ็ตรายเดือน, ไม่มีขีดจำกัดต่อตัวอักษร\n- **จุดเข้าถึงทั้งหมด** OCR กล้อง, การนำเข้ารูปภาพ, การแปลข้อความ, ประวัติ, ตัวจัดการโมเดล\n- **ไปป์ไลน์บนอุปกรณ์** ไม่มีการอัปโหลดรูปภาพหรือข้อความ ความเป็นส่วนตัวเหมือนกันทั้งในฟรีและ Pro\n- **ประวัติในเครื่อง** บันทึกและเรียกดูการแปลในเครื่อง; ลบได้ตลอดเวลา\n\n## สิ่งที่ Pro เพิ่ม\n\n- **ไม่มีโฆษณา** โฆษณาแบนเนอร์ด้านล่างที่ปรากฏในจุดเข้าถึงบางจุดสำหรับผู้ใช้ฟรีจะถูกลบออกสำหรับผู้ใช้ Pro\n- **ตรา Pro** แถบสมัครสมาชิกแสดงสถานะ Pro · ใช้งานอยู่ แทนที่จะเป็นข้อความแจ้งให้อัปเกรด\n\nนี่คือความแตกต่างทั้งหมด ไปป์ไลน์การแปลเหมือนกัน\n\n## ทำไมโครงสร้างนี้\n\nค่าใช้จ่ายในการแปลจ่ายต่อตัวอักษรโดย Cloud API แอปไม่ใช้ Cloud API; มันรัน ML Kit บนอุปกรณ์ ดังนั้นต้นทุนส่วนเพิ่มของการแปลคือการคำนวณบนโทรศัพท์ของผู้ใช้เอง ระดับฟรีจึงสามารถรวมไปป์ไลน์เต็มโดยไม่มีกำแพงจ่ายเงิน\n\nโฆษณาและการสมัครสมาชิก Pro มีไว้เพื่อสนับสนุนการพัฒนาอย่างต่อเนื่อง ไม่ใช่เพื่อจำกัดคุณสมบัติ\n\n## สิ่งที่ไม่ถูกจำกัด\n\n- **ไม่มีข้อจำกัดด้านภาษา** ภาษา ML Kit ทั้งหมด 19 ภาษาทำงานในระดับฟรี\n- **ไม่มีข้อจำกัดคุณสมบัติ** OCR กล้อง, การนำเข้ารูปภาพ, การแปลข้อความ, เลเยอร์ซ้อนทับบล็อก, ประวัติ, ตัวจัดการโมเดล — ทั้งหมดฟรี\n- **ไม่มีขีดจำกัดการใช้งาน** การแปลไม่จำกัด, รายการประวัติไม่จำกัด\n- **ไม่มีคิวลำดับความสำคัญ** ความเร็วในการแปลเหมือนกันสำหรับผู้ใช้ฟรีและ Pro; ทั้งคู่รันบนเอนจินบนอุปกรณ์เดียวกัน\n- **ไม่มีการวิเคราะห์เกี่ยวกับเนื้อหาการแปล** รายงานข้อขัดข้องและตัวนับรวมไม่รวมเนื้อหารูปภาพ, ข้อความ OCR หรือข้อความแปล ความเป็นส่วนตัวเหมือนกัน\n\n## วิธีสมัครสมาชิก\n\nแถบสมัครสมาชิกในหน้ากล้อง (ด้านล่าง) และหน้าการตั้งค่า (ด้านบน) เปิดเพย์วอลล์ ระดับ Pro ขายเป็นการสมัครสมาชิกผ่านโฟลว์การซื้อในแอปมาตรฐานของแพลตฟอร์ม การสมัครสมาชิกต่ออายุอัตโนมัติจนกว่าจะถูกยกเลิกในการตั้งค่าการสมัครสมาชิกของแพลตฟอร์ม\n\n## วิธีกู้คืนการสมัครสมาชิกก่อนหน้า\n\nหากคุณติดตั้งแอปใหม่หรือเปลี่ยนอุปกรณ์, ไอคอนรายการสมัครสมาชิกในแถบด้านบนของหน้าการตั้งค่าจะกู้คืนการซื้อก่อนหน้าผ่านการตรวจสอบใบเสร็จมาตรฐานของแพลตฟอร์ม ไม่จำเป็นต้องมีบัญชี\n\n## วิธีตรวจสอบสถานะปัจจุบัน\n\nหากคุณสมัครสมาชิก, แถบสมัครสมาชิกจะแสดง Pro · ใช้งานอยู่ ไอคอนรายการสมัครสมาชิกในแถบด้านบนของหน้ากล้องและแถบด้านบนของหน้าการตั้งค่าแสดงสถานะเดียวกัน\n\n## สรุปในหนึ่งประโยค\n\nฟรีคือแอปเต็มที่มีโฆษณา Pro คือแอปเต็มที่ไม่มีโฆษณาและมีตรา Pro ไม่มีอะไรในไปป์ไลน์การแปลถูกจำกัด
