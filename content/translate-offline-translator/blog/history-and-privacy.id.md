## Riwayat terjemahan dan privasi: apa yang tetap di perangkat Anda

Riwayat terjemahan adalah artefak lokal. Setiap entri riwayat disimpan dalam database SQLite lokal di perangkat yang dikelola oleh Drift, ditambah thumbnail JPEG dari foto sumber. Tidak ada yang diunggah ke server mana pun. Posting ini menjelaskan secara rinci apa yang disimpan, apa yang dihapus, dan apa model privasi aplikasi.\n\n## Apa yang disimpan riwayat\n\nSetiap catatan riwayat berisi:\n\n- **Foto asli** sebagai thumbnail JPEG, diperkecil agar sesuai dengan tepi maksimum. Foto dengan resolusi penuh dibuang setelah pengecilan untuk menjaga penyimpanan tetap terbatas.\n- **Bahasa sumber** terdeteksi oleh OCR (atau diatur secara manual).\n- **Bahasa target** dipilih untuk tangkapan.\n- **Blok OCR** dengan kotak pembatas, teks terdeteksi, dan keyakinan.\n- **Terjemahan** per blok dan terjemahan paragraf lengkap yang digabungkan.\n- **Stempel waktu pembuatan** untuk pengurutan dan tampilan.\n\nTerjemahan teks tidak disimpan otomatis. Halaman terjemahan teks menampilkan hasil di area hasilnya sampai Anda mengetuk Hapus atau menavigasi pergi. Tangkapan kamera dan foto yang diimpor dapat disimpan ke riwayat dari halaman hasil.\n\n## Di mana tinggalnya\n\nRiwayat disimpan di dua tempat:\n\n- **Database.** Database SQLite lokal di perangkat yang dikelola oleh Drift. File database berada di sandbox aplikasi; tidak dapat diakses oleh aplikasi lain.\n- **Foto.** Thumbnail JPEG dalam sistem file sandbox aplikasi di bawah direktori khusus riwayat.\n\nKeduanya dihapus saat aplikasi di-uninstall.\n\n## Apa yang tidak pernah diunggah\n\n- **Foto.** Tidak diunggah, tidak disinkronkan, tidak dicadangkan.\n- **Teks OCR.** Tidak diunggah.\n- **Teks terjemahan.** Tidak diunggah.\n- **Entri riwayat.** Tidak diunggah, tidak disinkronkan, tidak dicadangkan.\n- **Preferensi bahasa.** Tidak diunggah.\n\nSeluruh riwayat ada di perangkat. Tidak ada salinan cloud untuk dibersihkan.\n\n## Penghapusan bersifat permanen\n\n- **Hapus satu.** Tombol hapus pada baris halaman riwayat removes the record and its photo thumbnail. Tindakan ini dijaga oleh dialog konfirmasi untuk mencegah penghapusan yang tidak disengaja.\n- **Hapus semua.** Meng-uninstall aplikasi removes the entire history database as part of the platform uninstall.\n- **Tidak ada salinan cloud.** Penghapusan bersifat permanen. Tidak ada status sisi cloud untuk dibersihkan.\n\n## Analitik\n\nAplikasi mengeluarkan laporan crash anonim dan penghitung agregat (mis., \"terjemahan per hari\") untuk tujuan memahami stabilitas aplikasi dan pola penggunaan. Ini不包括:\n\n- Konten foto\n- Teks OCR\n- Teks terjemahan\n- Entri riwayat\n\nJika laporan di masa depan pernah menyertakan konten, itu akan menjadi bug dan harus dilaporkan.\n\n## Model ancaman praktis\n\nAplikasi dirancang untuk pengguna yang ingin menerjemahkan dokumen sensitif tanpa mengirimkannya ke pihak ketiga. Ancaman yang relevan adalah:\n\n- **Eksfiltrasi cloud.** Tidak mungkin karena tidak ada yang diunggah.\n- **Akses lintas aplikasi.** Tidak mungkin karena sandbox mengisolasi database dan file foto.\n- **Kebocoran backup.** Tidak mungkin karena sandbox dikecualikan dari backup cloud otomatis perangkat.\n- **Kehilangan perangkat.** Riwayat hilang bersama perangkat kecuali cadangan manual perangkat dibuat; cadangan manual dienkripsi dan hanya dapat diakses oleh pemilik perangkat.\n\nUntuk pengguna yang model ancamannya mencakup musuh tingkat negara, pipeline on-device menghilangkan permukaan serangan jaringan tetapi tidak melindungi dari perangkat yang disusupi. Penguatan perangkat standar berlaku.\n\n## Ringkasan dalam satu kalimat\n\nRiwayat bersifat lokal. Foto bersifat lokal. Terjemahan bersifat lokal. Menghapus entri akan menghapusnya dari perangkat; tidak ada salinan cloud untuk dihapus.
