## Gratuit vs Pro : ce qui change quand vous vous abonnez

Le niveau gratuit de l'app inclut chaque fonctionnalité de traduction : OCR caméra, import de photos, traduction de texte, overlay par bloc, gestionnaire de modèles, historique et streaming de traduction par bloc. Il n'y a pas de plafond d'utilisation, pas de limite par caractère et pas de restriction de langue dans le niveau gratuit. Pro supprime les publicités et ajoute un badge Pro à la barre d'abonnement.\n\n## Ce qui est gratuit\n\n- **Les 19 langues.** Chaque langue prise en charge par ML Kit est disponible dans le niveau gratuit.\n- **Traductions illimitées.** Pas de plafond d'utilisation, pas de réinitialisation mensuelle, pas de limite par caractère.\n- **Tous les points d'entrée.** OCR caméra, import de photos, traduction de texte, historique, gestionnaire de modèles.\n- **Pipeline sur l'appareil.** Pas de téléchargement de photos ou de texte. La confidentialité est la même en gratuit et Pro.\n- **Historique local.** Enregistrez et parcourez les traductions localement ; supprimez à tout moment.\n\n## Ce que Pro ajoute\n\n- **Pas de publicités.** La bannière publicitaire inférieure qui apparaît dans certains points d'entrée pour les utilisateurs gratuits est supprimée pour les utilisateurs Pro.\n- **Badge Pro.** La barre d'abonnement affiche un état Pro · Actif au lieu d'une invite de mise à niveau.\n\nC'est la différence complète. Le pipeline de traduction lui-même est le même.\n\n## Pourquoi cette structure\n\nLe coût de traduction est payé par caractère par les API cloud. L'app n'utilise pas d'API cloud ; elle exécute ML Kit sur l'appareil, donc le coût marginal d'une traduction est le calcul sur le propre téléphone de l'utilisateur. Le niveau gratuit peut donc inclure le pipeline complet sans paywall.\n\nLes publicités et l'abonnement Pro existent pour financer le développement continu, pas pour limiter les fonctionnalités.\n\n## Ce qui n'est pas verrouillé\n\n- **Pas de restriction de langue.** Les 19 langues ML Kit fonctionnent toutes dans le niveau gratuit.\n- **Pas de restriction de fonctionnalité.** OCR caméra, import de photos, traduction de texte, overlay par bloc, historique, gestionnaire de modèles — tout est gratuit.\n- **Pas de plafond d'utilisation.** Traductions illimitées, entrées d'historique illimitées.\n- **Pas de file de priorité.** La vitesse de traduction est la même pour les utilisateurs gratuits et Pro ; les deux fonctionnent sur le même moteur sur l'appareil.\n- **Pas d'analyses sur le contenu de traduction.** Les rapports de plantage et les compteurs agrégés n'incluent pas le contenu photo, le texte OCR ou le texte traduit. La confidentialité est la même.\n\n## Comment s'abonner\n\nLa barre d'abonnement dans la page caméra (en bas) et la page des paramètres (en haut) ouvre le paywall. Le niveau Pro est vendu comme abonnement via le flux standard d'achat intégré de la plateforme. L'abonnement se renouvelle automatiquement jusqu'à ce qu'il soit annulé dans les paramètres d'abonnement de la plateforme.\n\n## Comment restaurer un abonnement précédent\n\nSi vous réinstallez l'app ou changez d'appareil, l'icône d'entrée d'abonnement dans la barre supérieure de la page des paramètres restaure l'achat précédent via la validation de reçu standard de la plateforme. Aucun compte n'est requis.\n\n## Comment vérifier l'état actuel\n\nSi vous êtes abonné, la barre d'abonnement affiche Pro · Actif. L'icône d'entrée d'abonnement dans la barre supérieure de la page caméra et la barre supérieure de la page des paramètres affiche le même état.\n\n## Un résumé en une phrase\n\nGratuit est l'app complète avec publicités. Pro est l'app complète sans publicités et avec un badge Pro. Rien dans le pipeline de traduction n'est verrouillé.
