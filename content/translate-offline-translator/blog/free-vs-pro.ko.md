## 무료 vs Pro: 구독하면 무엇이 달라지는가

앱의 무료 등급에는 모든 번역 기능이 포함됩니다: 카메라 OCR, 사진 가져오기, 텍스트 번역, 블록 오버레이, 모델 관리자, 기록, 블록 단위 번역 스트리밍. 무료 등급에는 사용 제한, 문자당 제한, 언어 제한이 없습니다. Pro는 광고를 제거하고 구독 바에 Pro 배지를 추가합니다.\n\n## 무료인 것\n\n- **19개 언어 모두.** ML Kit에서 지원하는 모든 언어는 무료 등급에서 사용 가능합니다.\n- **무제한 번역.** 사용 제한 없음, 월간 재설정 없음, 문자당 제한 없음.\n- **모든 진입점.** 카메라 OCR, 사진 가져오기, 텍스트 번역, 기록, 모델 관리자.\n- **온디바이스 파이프라인.** 사진이나 텍스트 업로드 없음. 무료와 Pro의 프라이버시는 동일합니다.\n- **로컬 기록.** 번역을 로컬에 저장하고 탐색; 언제든지 삭제.\n\n## Pro가 추가하는 것\n\n- **광고 없음.** 일부 진입점에서 무료 사용자에게 표시되는 하단 배너 광고가 Pro 사용자에게는 제거됩니다.\n- **Pro 배지.** 구독 바는 업그레이드 프롬프트 대신 Pro · Active 상태를 표시합니다.\n\n이것이 전체 차이점입니다. 번역 파이프라인 자체는 동일합니다.\n\n## 왜 이런 구조인가\n\n번역 비용은 클라우드 API에서 문자당 지불됩니다. 이 앱은 클라우드 API를 사용하지 않습니다. ML Kit를 온디바이스에서 실행하므로 번역의 한계 비용은 사용자 자신의 휴대전화의 컴퓨팅입니다. 따라서 무료 등급은 유료 게이트 없이 전체 파이프라인을 포함할 수 있습니다.\n\n광고와 Pro 구독은 기능에 게이트를 두기 위해서가 아니라 지속적인 개발에 자금을 지원하기 위해 존재합니다.\n\n## 게이트되지 않은 것\n\n- **언어 제한 없음.** 19개 ML Kit 언어 모두 무료 등급에서 작동.\n- **기능 제한 없음.** 카메라 OCR, 사진 가져오기, 텍스트 번역, 블록 오버레이, 기록, 모델 관리자 — 모두 무료.\n- **사용 제한 없음.** 무제한 번역, 무제한 기록 항목.\n- **우선 순위 대기열 없음.** 번역 속도는 무료 및 Pro 사용자에게 동일합니다. 둘 다 동일한 온디바이스 엔진에서 실행됩니다.\n- **번역 콘텐츠에 대한 분석 없음.** 충돌 보고서 및 집계 카운터는 사진 콘텐츠, OCR 텍스트 또는 번역 텍스트를 포함하지 않습니다. 프라이버시는 동일합니다.\n\n## 구독 방법\n\n카메라 페이지(하단) 및 설정 페이지(상단)의 구독 바가 결제 페이월을 엽니다. Pro 등급은 플랫폼의 표준 인앱 구매 흐름을 통해 구독으로 판매됩니다. 구독은 플랫폼 구독 설정에서 취소할 때까지 자동 갱신됩니다.\n\n## 이전 구독 복원 방법\n\n앱을 다시 설치하거나 기기를 전환하는 경우, 설정 페이지 상단 바의 구독 진입 아이콘은 플랫폼의 표준 영수증 검증을 통해 이전 구매를 복원합니다. 계정은 필요하지 않습니다.\n\n## 현재 상태 확인 방법\n\n구독한 경우 구독 바에 Pro · Active가 표시됩니다. 카메라 페이지 상단 바 및 설정 페이지 상단 바의 구독 진입 아이콘은 동일한 상태를 표시합니다.\n\n## 한 문장 요약\n\n무료는 광고가 있는 전체 앱입니다. Pro는 광고가 없고 Pro 배지가 있는 전체 앱입니다. 번역 파이프라인에는 게이트된 것이 없습니다.
