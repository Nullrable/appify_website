## 無料 vs Pro：サブスクライブすると何が変わるか

アプリの無料ティアには、すべての翻訳機能が含まれています：カメラ OCR、写真インポート、テキスト翻訳、ブロック オーバーレイ、モデル マネージャー、履歴、ブロック単位の翻訳ストリーミング。使用上限、文字数制限、言語制限は無料ティアにはありません。Pro は広告を削除し、サブスクリプション バーに Pro バッジを追加します。\n\n## 無料の内容\n\n- **19 言語すべて。** ML Kit がサポートするすべての言語が無料ティアで利用可能。\n- **無制限の翻訳。** 使用上限なし、月次リセットなし、文字数制限なし。\n- **すべてのエントリ ポイント。** カメラ OCR、写真インポート、テキスト翻訳、履歴、模型 Manager。\n- **オンデバイス パイプライン。** 写真やテキストのアップロードなし。無料と Pro でプライバシーは同じ。\n- **ローカル履歴。** 翻訳をローカルに保存して閲覧；いつでも削除可能。\n\n## Pro で追加されるもの\n\n- **広告なし。** 一部のエントリ ポイントで無料ユーザーに表示される下部バナー広告は、Pro ユーザーには表示されません。\n- **Pro バッジ。** サブスクリプション バーはアップグレード プロンプトではなく、Pro · Active 状態を表示します。\n\nこれが完全な違いです。翻訳パイプライン自体は同じです。\n\n## なぜこの構造か\n\n翻訳コストはクラウド API によって文字単位で支払われます。アプリはクラウド API を使用しません。ML Kit をオンデバイスで実行するため、翻訳の限界費用はユーザーの自分のスマートフォンでの計算です。したがって、無料ティアは有料ゲートなしで完全なパイプラインを含めることができます。\n\n広告と Pro サブスクリプションは、機能にゲートを設けるためではなく、継続的な開発に資金を提供するために存在します。\n\n## ゲートされていないもの\n\n- **言語制限なし。** 19 の ML Kit 言語すべてが無料ティアで動作。\n- **機能制限なし。** カメラ OCR、写真インポート、テキスト翻訳、ブロック オーバーレイ、履歴、模型 Manager — すべて無料。\n- **使用上限なし。** 無制限の翻訳、無制限の履歴エントリ。\n- **優先キューなし。** 翻訳速度は無料ユーザーと Pro ユーザーで同じ。両方とも同じオンデバイス エンジンで実行されます。\n- **翻訳コンテンツに関する分析なし。** クラッシュ レポートと集約カウンターには、写真コンテンツ、OCR テキスト、翻訳テキストは含まれません。プライバシーは同じです。\n\n## サブスクライブする方法\n\nカメラ ページ（下部）と設定ページ（上部）のサブスクリプション バーがペイウォールを開きます。Pro ティアは、プラットフォームの標準アプリ内購入フロー経由でサブスクリプションとして販売されます。サブスクリプションは、プラットフォームのサブスクリプション設定でキャンセルされるまで自動更新されます。\n\n## 以前のサブスクリプションを復元する方法\n\nアプリを再インストールするか、デバイスを切り替える場合、設定頁面上頂部バーのサブスクリプション エントリ アイコンは、プラットフォームの標準レシート検証を介して以前の購入を復元します。アカウントは必要ありません。\n\n## 現在のステータスを確認する方法\n\n- サブスクライブしている場合、サブスクリプション バーは Pro · Active を表示します。カメラ ページ上部のバーと設定ページ上部のバーのサブスクリプション エントリ アイコンは同じ状態を表示します。\n\n## 一文での要約\n\n無料は広告付きのフルアプリ。Pro は広告なしのフルアプリで、Pro バッジ付き。翻訳パイプラインにゲートされているものはありません。
