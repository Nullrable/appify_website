## 자동 감지 언어: 앱이 소스 언어를 선택하는 방법

자동 감지는 소스 언어 선택기의 첫 번째 옵션입니다. 선택한다고 해서 앱이 소스에 대해 의견이 없다는 의미는 아닙니다 — 이는 앱이 번역당 OCR 블록별 언어 힌트(사진의 경우) 또는 Dart 레이어 문자 집합 휴리스틱(텍스트의 경우)을 사용하여 특정 ML Kit 소스 언어를 선택한다는 의미입니다.

## 번역당인 이유

ML Kit의 온디바이스 번역기는 번역이 실행되기 전에 특정 소스 언어를 다운로드해야 합니다. 자동 감지는 "어떤 언어에서든 번역"을 의미할 수 없습니다. 지원되는 19개 언어 중 하나로 번역당 해결되어야 합니다. 앱이 이 해결을 자동으로 수행합니다.

## 사진에서 작동 방식

카메라 캡처의 경우 OCR 엔진은 인식된 각 블록에 대해 블록별 언어 힌트를 출력합니다. 힌트는 페이지 전체에서 집계되며, 다수 언어가 해당 번역의 ML Kit 소스 언어가 됩니다.

단일 언어 페이지는 깔끔하게 해결됩니다: 한국어 캡션의 페이지는 한국어로 해결되고, 프랑스어 본문의 페이지는 프랑스어로 해결됩니다. 혼합 스크립트 페이지는 단일 언어가 지배적이지 않은 경우 기본값으로 폴백합니다.

블록별 번역은 이러한 힌트를 더 세분화하여 사용합니다. 영어 헤드라인과 일본어 캡션이 있는 페이지는 다수 언어가 불분명한 경우에도 블록별로 적절한 소스를 사용하여 번역할 수 있습니다.

## 텍스트에서 작동 방식

텍스트 번역의 경우 앱은 스크립트 클래스별로 문자를 계산하는 Dart 레이어 휴리스틱을 실행합니다:

- 한자 → 간체 중국어
- 가나 → 일본어
- 한글 → 한국어
- 라틴 문자 → 영어
- 키릴 문자 → 러시아어
- 아랍어 문자 → 아랍어

혼합 입력은 다수 문자 클래스를 따릅니다. 비어 있거나 공백만 있는 입력은 기본값으로 영어가 됩니다.

휴리스틱은 빠르고(입력에 대한 단일 선형 스캔) ML Kit 호출 전에 실행됩니다. 선택된 소스 언어가 번역 요청에 사용됩니다.

## 자동 감지가 실패하는 경우

- **분음 부호가 없는 라틴 문자.** 10자의 라틴 전용 스니펫은 영어, 프랑스어, 독일어, 이탈리아어, 포르투갈어, 스페인어, 네덜란드어, 폴란드어, 체코어 또는 기타 여러 언어일 수 있습니다. 휴리스틱은 기본값으로 영어를 선택합니다. 소스가 영어가 아니면 번역 품질이 저하될 수 있습니다. 짧은 라틴 스니펫의 경우 소스 언어를 수동으로 고정하세요.
- **구체성이 없는 키릴 문자.** 키릴 문자는 러시아어, 우크라이나어 또는 다른 슬라브 스크립트일 수 있습니다. 앱은 러시아어를 선택합니다.
- **한자 스크립트 모호성.** 간체와 번체 중국어는 대부분의 문자를 공유합니다. 한자의 짧은 스니펫은 더 긴 컨텍스트 없이는 하나로 해결될 수 없습니다. 앱은 간체 중국어를 선택합니다.

이러한 경우 선택기에서 소스 언어를 수동으로 고정하세요.

## 자동 감지는 결코 조용하지 않습니다

번역이 실행될 때 페이지에는 항상 특정 ML Kit 소스 언어가 있습니다. 휴리스틱이 잘못된 기본값을 반환하면 번역이 잘못될 수 있습니다. 올바른 언어를 반환하면 번역이 작동합니다. 앱이 "언어를 선택하지 못하는" 모드는 없습니다. 기본값으로 폴스루하여 번역합니다.

## 실용적인 조언

길고 단일 언어 문서의 경우 자동 감지가 작동합니다. 짧은 스니펫이나 혼합 스크립트 페이지의 경우 선택기에서 소스 언어를 수동으로 고정하세요. 선택기는 최근 언어를 상단에 기억하므로 두 번째로 사용하는 언어는 한 번의 탭입니다.
