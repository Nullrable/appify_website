## Panduan Lengkap Mengonversi Foto Ponsel ke PDF

Ada lebih banyak skenario mengubah foto menjadi PDF daripada yang Anda kira: mengirim bukti reimbursement, mengirim kontrak yang dipindai, mengatur salinan dokumen, mengarsipkan catatan kelas. Dengan Image to PDF, seluruh proses dilakukan di ponsel dalam tiga langkah — pilih gambar, urutkan, ekspor.

## Langkah 1: Pilih Sumber Gambar yang Tepat

Aplikasi ini menyediakan dua cara untuk memilih gambar:

- **Pilih dari Album**: cocok untuk foto yang diambil dengan ponsel. Anda dapat memilih banyak sekaligus, lalu langsung masuk ke pengurutan;
- **Pilih dari "Berkas"**: cocok untuk gambar yang sudah disimpan di iCloud Drive atau folder lokal.

Untuk format, aplikasi ini mendukung JPG, PNG, HEIC/HEIF, WebP, BMP, GIF. HEIC layak disebut secara khusus — ini adalah format pengambilan gambar default di iPhone; banyak alat konversi daring tidak mendukungnya, atau memerlukan unggahan tambahan saat mengonversi. Di sini, Anda dapat menggunakannya secara langsung, menghilangkan langkah perantara "konversi format dulu, lalu ke PDF".

## Langkah 2: Atur Urutan Halaman

Saat mengonversi banyak gambar menjadi satu PDF, urutan halaman adalah urutan baca. Gambar yang dipilih disusun dalam kisi; tekan lama dan seret untuk menyesuaikan urutan. Disarankan untuk ditinjau sebelum mengekspor sesuai penggunaan akhir:

- **Bukti reimbursement**: susun berdasarkan tanggal untuk memudahkan verifikasi;
- **Materi kontrak**: teks utama dulu, lampiran di belakang;
- **Materi identitas**: bagian depan dulu, bagian belakang di belakang.

## Langkah 3: Ekspor dan Berbagi

Setelah mengetuk konversi, ukuran halaman PDF ditentukan oleh ukuran asli setiap gambar — tidak ada penskalaan, tidak ada margin, dan kejelasan gambar asli dipertahankan sepenuhnya. Hasil ekspor dikirim melalui panel Sharing sistem: simpan ke "Berkas", kirim email, AirDrop ke kolega di dekatnya. Catatan ini juga secara otomatis masuk ke riwayat lokal; saat perlu mengirim lagi, cukup bagikan langsung dari riwayat.

## Mengapa "Pemrosesan Lokal" Penting

Sebagian besar alat daring untuk mengonversi gambar ke PDF perlu mengunggah gambar ke server untuk diproses. Ini berarti kuitansi, kontrak, dan foto identitas Anda akan melewati server yang tidak Anda kendalikan. Semua konversi Image to PDF dilakukan secara lokal di perangkat, dan berkas tidak pernah meninggalkan ponsel — untuk materi sensitif, perbedaan ini lebih值得 diperhatikan daripada kecepatan konversi.

Jika Anda sering menangani berkas semacam ini, pertimbangkan untuk menghubungkan konversi, penggabungan, dan enkripsi: pertama konversi ke PDF, gabungkan beberapa materi dengan fungsi penggabungan, lalu gunakan fungsi enkripsi untuk menambahkan kata sandi sebelum mengirim.
