## Полное руководство по преобразованию фото с телефона в PDF

Существует больше сценариев преобразования фото в PDF, чем вы думаете: отправка отчётов о расходах, отправка сканов контрактов, организация копий документов, архивирование конспектов лекций. С Image to PDF весь процесс выполняется на телефоне в три шага — выберите изображения, упорядочьте, экспортируйте.

## Шаг 1: Выберите правильный источник изображений

Приложение предлагает два способа выбора изображений:

- **Выбор из альбома**: подходит для фотографий, сделанных на телефоне. Можно выбрать несколько сразу, а затем сразу перейти к упорядочиванию;
- **Выбор из "Файлов"**: подходит для изображений, уже сохранённых в iCloud Drive или локальных папках.

Что касается форматов, приложение поддерживает JPG, PNG, HEIC/HEIF, WebP, BMP, GIF. HEIC заслуживает особого упоминания — это формат съёмки по умолчанию в iPhone; многие онлайн-инструменты для конвертации его не поддерживают или требуют дополнительной загрузки при конвертации. Здесь вы можете использовать его напрямую, устраняя промежуточный шаг "сначала конвертировать формат, затем в PDF".

## Шаг 2: Упорядочьте страницы

При преобразовании нескольких изображений в один PDF порядок страниц является порядком чтения. Выбранные изображения располагаются в виде сетки; нажмите и удерживайте, затем перетащите, чтобы настроить порядок. Рекомендуется просмотреть перед экспортом в соответствии с конечным использованием:

- **Отчёты о расходах**: расположите по дате для удобства проверки;
- **Документы контракта**: основной текст сначала, приложения после;
- **Документы удостоверения личности**: лицевая сторона сначала, оборотная после.

## Шаг 3: Экспорт и общий доступ

После нажатия конвертировать размер страницы PDF определяется исходным размером каждого изображения — без масштабирования, без полей, и чёткость исходного изображения полностью сохраняется. Результат экспорта отправляется через системную панель общего доступа: сохранить в "Файлы", отправить по электронной почте, AirDrop ближайшему коллеге. Эта запись также автоматически попадает в локальную историю; когда в будущем потребуется отправить снова, просто поделитесь прямо из истории.

## Почему "локальная обработка" заслуживает внимания

Большинство онлайн-инструментов для преобразования изображений в PDF требуют загрузки изображений на сервер для обработки. Это означает, что ваши отчёты, контракты и фотографии документов удостоверения личности пройдут через сервер, который вы не контролируете. Все преобразования Image to PDF выполняются локально на устройстве, и файлы никогда не покидают телефон — для конфиденциальных материалов это различие заслуживает большего внимания, чем скорость преобразования.

Если вы часто работаете с такими файлами, рассмотрите возможность объединения преобразования, слияния и шифрования: сначала преобразуйте в PDF, объедините несколько материалов с помощью функции слияния, а затем используйте функцию шифрования для добавления пароля перед отправкой.
