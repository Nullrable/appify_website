## 휴대폰 이미지를 PDF로 변환하는 완전한 가이드

사진을 PDF로 만드는 상황은 생각보다 많습니다. 경비 증빙 제출, 계약서 스캔본 발송, 신분증 사본 정리, 수업 노트 보관. Image to PDF로 핸드폰에서 3단계(선택, 정렬, 내보내기)로 완료됩니다.

## 1단계: 올바른 이미지 출처 선택

앱은 두 가지 이미지 선택 방식을 제공합니다.

- **사진 앱에서**: 휴대폰으로 촬영한 사진에 적합. 한 번에 여러 장 선택 가능, 선택 후 바로 정렬로 이동
- **"파일"에서**: iCloud 드라이브 또는 로컬 폴더에 저장된 이미지에 적합

형식 측면에서 앱은 JPG, PNG, HEIC/HEIF, WebP, BMP, GIF를 지원합니다. 특히 HEIC는 iPhone의 기본 촬영 형식으로, 많은 온라인 변환 도구가 지원하지 않거나 별도 업로드가 필요합니다. 여기서는 바로 사용할 수 있어 "먼저 형식 변환, 그다음 PDF 변환"의 중간 단계가 필요 없습니다.

## 2단계: 페이지 순서 정리

여러 이미지를 하나의 PDF로 만들 때 페이지 순서는 곧 읽기 순서입니다. 앱에서 선택한 이미지는 그리드로 정렬되며, 길게 눌러 드래그하면 순서를 조정할 수 있습니다. 내보내기 전에 최종 용도에 맞게 한 번 점검하세요.

- **경비 증빙**: 날짜 순으로 정렬하면 대조하기 쉽습니다.
- **계약 자료**: 본문이 먼저, 첨부가 나중.
- **신분증 자료**: 앞면이 먼저, 뒷면이 나중.

## 3단계: 내보내기 및 공유

변환을 누르면 PDF 페이지 크기는 각 이미지의 원본 크기로 결정됩니다. 확대/축소 없음, 여백 없음, 원본의 선명함이 그대로 유지됩니다. 내보내기 결과는 시스템 공유 시트를 통해 전송됩니다. "파일"에 저장, 메일 발송, 가까운 동료에게 AirDrop 모두 가능. 이 기록은 자동으로 로컬 기록에 저장되어, 나중에 다시 보내야 할 때 기록에서 바로 공유할 수 있습니다.

## "로컬 처리"가 중요한 이유

대부분의 온라인 이미지→PDF 도구는 처리를 위해 이미지를 서버로 업로드해야 합니다. 즉, 증빙, 계약서, 신분증 사진이 사용자가 통제할 수 없는 서버를 통과합니다. Image to PDF의 모든 변환은 기기에서 로컬로 완료되며, 파일은 처음부터 끝까지 휴대폰을 떠나지 않습니다. 민감한 자료의 경우 이 차이는 변환 속도보다 더 주목할 가치가 있습니다.

이러한 파일을 자주 다룬다면 변환 → 병합 → 암호화를 연쇄적으로 활용해 보세요. 먼저 PDF로 변환하고, 여러 자료를 병합 기능으로 통합한 다음, 마지막에 암호화 기능으로 비밀번호를 설정해 발송합니다.
