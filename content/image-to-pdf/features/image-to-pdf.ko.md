## 이미지→PDF

휴대폰의 이미지를 PDF 한 개로 만드는 데 3단계면 됩니다: 선택, 정렬, 내보내기. 모든 과정은 기기에서 로컬로 완료되므로 이미지는 어떤 서버에도 업로드되지 않습니다.

## 사진과 "파일" 두 가지 선택 경로

이미지→PDF 기능에 들어가면 두 출처에서 이미지를 일괄 선택할 수 있습니다.

- **사진**: 앨범에서 여러 장 선택. 휴대폰으로 촬영한 콘텐츠 정리에 적합.
- **"파일" 앱**: iCloud 드라이브 또는 로컬 폴더에서 선택. 이미 보관된 이미지를 처리하기에 적합.

지원 형식은 JPG, PNG, HEIC/HEIF, WebP, BMP, GIF — iPhone 기본 촬영인 HEIC 사진은 그대로 사용할 수 있어 사전 형식 변환이 필요 없습니다.

## 드래그로 순서 조정

선택한 이미지는 그리드 형태로 정렬되며, 길게 눌러 드래그하면 PDF 안의 페이지 순서를 변경할 수 있습니다. 페이지 순서가 중요한 자료(계약서, 영수증, 신분증)는 내보내기 전에 한 페이지씩 확인하세요.

## 원본 크기로 내보내기

PDF 페이지 크기는 각 이미지의 원본 크기로 결정됩니다. 확대/축소 없음, 여백 없음, 이미지의 선명함이 PDF 안에서 완전히 보존됩니다. 내보낸 후 시스템 공유 시트로 바로 전송할 수 있고, 결과는 로컬 기록에 자동 저장되어 나중에 검색과 재공유가 간편합니다.
