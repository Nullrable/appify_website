## Penggabungan PDF

Menggabungkan banyak PDF menjadi satu berkas lengkap. Berkas pindaian, lampiran kontrak, materi multi-bab, dan berkas yang disimpan逐次 akhirnya perlu digabungkan menjadi satu, semuanya dapat完成 secara langsung di ponsel.

## Pilihan Banyak dan Pratinjau Thumbnail

Pilih banyak file PDF sekaligus; aplikasi akan menghasilkan thumbnail untuk setiap file, Anda dapat直观 mengonfirmasi konten setiap file,避免 salah pilih atau漏选.

## Urutan dengan Menyeret

Urutan penggabungan penting —正文 kontrak di depan, lampiran di belakang, atau disusun按 waktu, semuanya由 Anda决定. Dengan menyeret thumbnail, Anda dapat menyesuaikan urutan setiap PDF dalam hasil penggabungan, dan setelah mengonfirmasi benar, lakukan penggabungan.

## Pemrosesan Lokal, Pencatatan Otomatis

Proses penggabungan dilakukan secara lokal di perangkat; file tidak akan diunggah ke server mana pun. Hasil penggabungan dikirim melalui panel berbagi sistem dan secara otomatis存入 riwayat lokal, sehingga Anda dapat随时 menemukan dan membagikan berkas ini dari riwayat kapan saja.
