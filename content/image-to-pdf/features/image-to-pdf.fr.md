## Images vers PDF

Transformer les images de votre téléphone en PDF ne prend que trois étapes : sélectionnez les images, organisez-les, exportez-les. L'ensemble du processus s'effectue localement sur l'appareil ; les images ne seront pas téléchargées vers aucun serveur.

## Deux sources pour sélectionner les images : Album et « Fichiers »

Après être entré dans la fonction images vers PDF, vous pouvez sélectionner des images par lot depuis deux sources :

- **Album** : sélectionnez plusieurs photos à la fois, adapté pour organiser le contenu pris avec le téléphone ;
- **Application « Fichiers »** : sélectionnez depuis iCloud Drive ou des dossiers locaux, adapté pour traiter les images déjà archivées.

Les formats pris en charge incluent JPG, PNG, HEIC/HEIF, WebP, BMP, GIF — les photos HEIC prises par défaut sur iPhone peuvent être utilisées directement, sans conversion préalable.

## Ajustement de l'ordre par glisser-déposer

Les images sélectionnées sont disposées en grille ; appuyez longuement et faites glisser pour ajuster l'ordre de chaque image dans les pages PDF. Pour les documents sensibles à l'ordre des pages comme les contrats, les reçus et les pièces d'identité, vous pouvez vérifier page par page avant l'exportation.

## Exportation à la taille d'origine

La taille de la page PDF est déterminée par la taille d'origine de chaque image, sans mise à l'échelle ni ajout de marges, et la netteté de l'image est entièrement préservée dans le PDF. Après l'exportation, vous pouvez envoyer directement via le panneau de partage système ; les résultats de conversion sont également automatiquement stockés dans l'historique local, pour faciliter la recherche et le partage à nouveau à l'avenir.
