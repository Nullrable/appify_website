## Расшифровка PDF

При условии знания пароля, снимите защиту шифрования с PDF. Зашифрованные PDF нельзя редактировать, объединять или конвертировать в изображения напрямую — сначала расшифруйте, и дальнейшая обработка пройдёт гладко.

## Обнаружение шифрования

После выбора файла приложение автоматически определяет, зашифрован ли этот PDF, вам не нужно判断 состояние файла по памяти.

## Введите пароль, снимите шифрование

Введите правильный пароль, и приложение снимет защиту шифрования этого PDF локально, создав новый файл, который больше не требует пароля. Выходной файл можно正常 открывать, редактировать, объединять или конвертировать в изображения.

## Распространённые сценарии

- Ранее зашифрованные материалы, которые теперь больше не нужно держать в секрете, — после расшифровки方便 для просмотра в любое время;
- Хотите объединить несколько зашифрованных PDF в один — сначала расшифруйте каждый по отдельности, затем объедините;
- Зашифрованные PDF необходимо конвертировать в изображения — после расшифровки можно использовать функцию PDF в изображения.

Весь процесс расшифровки выполняется локально на устройстве; файлы и пароли не будут загружены ни на какой сервер.
