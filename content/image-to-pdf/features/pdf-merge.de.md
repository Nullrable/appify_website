## PDF-Zusammenführung

Mehrere PDFs zu einer vollständigen Datei zusammenführen. Scandateien, Vertragsanhänge, mehrkapitelige Unterlagen, schrittweise gespeicherte Dateien müssen schließlich zu einer zusammengeführt werden — alles kann direkt auf dem Telefon erledigt werden.

## Mehrfachauswahl und Miniaturvorschau

Wählen Sie mehrere PDF-Dateien gleichzeitig aus; die App generiert Miniaturbilder für jede Datei, Sie können den Inhalt jeder Datei直观 bestätigen und Fehl- oder Verpassungsauswahl vermeiden.

## Reihenfolge per Drag & Drop festlegen

Die Zusammenführungsreihenfolge ist wichtig — Vertragshaupteil zuerst, Anhänge danach, oder按 chronologischer Reihenfolge geordnet, alles liegt bei Ihnen. Durch Ziehen der Miniaturbilder können Sie die Reihenfolge jeder PDF im Zusammenführungsergebnis anpassen, und nachdem Sie die Richtigkeit bestätigt haben, die Zusammenführung durchführen.

## Lokale Verarbeitung, automatische Aufzeichnung

Der Zusammenführungsprozess wird lokal auf dem Gerät durchgeführt; Dateien werden auf keinen Server hochgeladen. Die Zusammenführungsergebnisse werden über das System-Sharing-Bedienfeld gesendet und automatisch im lokalen Verlauf gespeichert, damit Sie diese Datei jederzeit aus dem Verlauf wiederfinden und teilen können.
