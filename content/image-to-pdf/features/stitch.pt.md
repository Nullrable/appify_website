## Montagem de imagens

Montar várias imagens em uma imagem longa ou uma imagem combinada não requer um software de edição de imagens complexo. Selecione as imagens, escolha um modo de montagem, exporte — feito em três etapas.

## Três modos de montagem

- **Montagem vertical**: as imagens são organizadas de cima para baixo, adequado para montar capturas de tela de registros de chat e capturas de artigos longos, produzindo uma imagem longa completa;
- **Montagem horizontal**: as imagens são organizadas da esquerda para a direita, adequado para comparação lado a lado, como comparar capturas de tela de diferentes planos;
- **Grade de nove**: as imagens são organizadas em grade, adequado para organizar um grupo de imagens com estilo unificado, como várias fotos do mesmo cena.

## Mantém a proporção original

O processo de montagem não estica nem corta as imagens; cada imagem mantém sua proporção original e é combinada de forma compacta. A nitidez da imagem exportada é consistente com a imagem original, sem perda de qualidade pela montagem.

## Visualização e ajuste

Você pode visualizar o efeito antes da montagem e ajustar a ordem das imagens arrastando e soltando. Uma vez satisfeito com o efeito, exporte; os resultados são enviados pelo painel de compartilhamento do sistema e salvos automaticamente no histórico local. Todo o processo é feito localmente no dispositivo; as imagens não serão enviadas para nenhum servidor.
