## PDF Decrypt

Knowing the password, you can remove the encryption protection on a PDF. An encrypted PDF can't be directly edited, merged, or converted to images — decrypt it first, and the rest of the workflow is smooth.

## Encryption Detection

Once you select the file, the App automatically checks whether this PDF is already encrypted. You don't have to remember whether the file is protected.

## Enter the Password, Remove Encryption

Enter the correct password and the App will remove the PDF's encryption locally, producing a new file that no longer requires a password. The output file opens, edits, merges, or converts to image normally.

## Common Scenarios

- Previously encrypted materials no longer need to be confidential — decrypt for easier access any time.
- Want to merge multiple encrypted PDFs into one — decrypt each one first, then merge.
- Need to convert an encrypted PDF to images — decrypt first, then use PDF to Image.

The whole decryption runs locally on your device, so the file and the password are never uploaded to any server.
