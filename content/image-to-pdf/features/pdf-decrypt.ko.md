## PDF 복호화

비밀번호를 알고 있다면 PDF의 암호화 보호를 제거할 수 있습니다. 암호화된 PDF는 직접 편집, 병합, 이미지 변환이 불가능합니다. 먼저 복호화하고 나면 이후 작업이 매끄럽게 진행됩니다.

## 암호화 감지

파일을 선택하면 앱이 자동으로 이 PDF가 이미 암호화되어 있는지 감지합니다. 파일 상태를 기억해서 판단할 필요가 없습니다.

## 비밀번호 입력, 암호화 제거

올바른 비밀번호를 입력하면 앱이 이 PDF의 암호화를 로컬에서 제거하여 더 이상 비밀번호가 필요 없는 새 파일을 생성합니다. 출력 파일은 정상적으로 열람, 편집, 병합, 이미지 변환이 가능합니다.

## 일반적인 사용 상황

- 이전에 암호화한 자료를 더 이상 기밀로 유지할 필요가 없을 때 — 복호화하면 언제든 쉽게 볼 수 있음
- 여러 암호화 PDF를 하나로 병합하고 싶을 때 — 개별 복호화 후 병합
- 암호화 PDF를 이미지로 변환해야 할 때 — 복호화 후 PDF→이미지 기능 사용

복호화 전체는 기기에서 로컬로 완료되므로 파일과 비밀번호는 어떤 서버에도 업로드되지 않습니다.
