## Fusione PDF

Unisci più PDF in un unico file completo. File scansionati, allegati di contratti, documenti multi-capitolo, file salvati per fasi che alla fine devono essere consolidati in uno, tutto può essere completato direttamente sul telefono.

## Selezione multipla e anteprima miniature

Seleziona più file PDF contemporaneamente; l'applicazione genererà miniature per ciascun file, puoi confermare intuitivamente il contenuto di ciascun file, evitando selezioni errate o omissioni.

## Determina l'ordine con trascinamento

L'ordine di fusione è importante — il testo principale del contratto prima, gli allegati dopo, o按 ordine cronologico, tutto dipende da te. Trascinando le miniature, puoi regolare l'ordine di ciascun PDF nel risultato della fusione, e dopo aver confermato la correttezza, esegui la fusione.

## Elaborazione locale, registrazione automatica

Il processo di fusione viene eseguito localmente sul dispositivo; i file non verranno caricati su alcun server. I risultati della fusione vengono inviati tramite il pannello di condivisione di sistema e salvati automaticamente nella cronologia locale, così puoi trovare e condividere questo file dalla cronologia in qualsiasi momento.
