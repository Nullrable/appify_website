## Descifrado de PDF

Bajo la condición de conocer la contraseña, elimine la protección de cifrado del PDF. Los PDF cifrados no se pueden editar, fusionar ni convertir a imágenes directamente — primero descifre, el procesamiento posterior será fluido.

## Detección de cifrado

Tras seleccionar el archivo, la aplicación detecta automáticamente si este PDF está cifrado, no necesita判断 el estado del archivo de memoria.

## Ingrese la contraseña, elimine el cifrado

Ingrese la contraseña correcta, y la aplicación eliminará la protección de cifrado de este PDF localmente, generando un archivo nuevo que ya no necesita contraseña. El archivo de salida se puede abrir, editar, fusionar o convertir a imágenes normalmente.

## Escenarios comunes

- Materiales previamente cifrados, que ya no necesitan mantenerse confidenciales — tras el descifrado方便 para revisar en cualquier momento;
- Quiere fusionar múltiples PDF cifrados en uno — descifre uno por uno primero y luego fusione;
- PDF cifrados que necesitan convertirse a imágenes — tras el descifrado, puede usar la función PDF a imágenes.

Todo el proceso de descifrado se realiza localmente en el dispositivo; los archivos y las contraseñas no se subirán a ningún servidor.
