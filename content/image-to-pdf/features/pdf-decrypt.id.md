## Dekripsi PDF

Dengan syarat mengetahui kata sandi, menghapus perlindungan enkripsi pada PDF. PDF terenkripsi tidak dapat diedit, digabungkan, atau diubah menjadi gambar secara langsung — dekripsi terlebih dahulu, dan pemrosesan berikutnya akan lancar.

## Deteksi Enkripsi

Setelah memilih file, aplikasi secara otomatis mendeteksi apakah PDF ini telah dienkripsi, Anda tidak perlu menentukan状态 file dari ingatan.

## Masukkan Kata Sandi, Hapus Enkripsi

Masukkan kata sandi yang benar, dan aplikasi akan menghapus perlindungan enkripsi PDF ini secara lokal, menghasilkan file baru yang tidak lagi memerlukan kata sandi. File output dapat dibuka, diedit, digabungkan, atau dikonversi ke gambar secara normal.

## Skenario Umum

- Materi yang sebelumnya dienkripsi, sekarang tidak perlu保密 lagi — setelah dekripsi方便 untuk查看 kapan saja;
- Ingin menggabungkan banyak PDF terenkripsi menjadi satu — dekripsi satu per satu terlebih dahulu lalu gabungkan;
- PDF terenkripsi perlu dikonversi ke gambar — setelah dekripsi, fitur PDF ke gambar dapat digunakan.

Seluruh proses dekripsi dilakukan secara lokal di perangkat; file dan kata sandi tidak akan diunggah ke server mana pun.
