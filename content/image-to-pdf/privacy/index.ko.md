본 개인정보 처리방침은 **Image to PDF**(이하 "**본 앱**")이 사용자의 정보를 어떻게 처리하는지 설명합니다. 요약하면, 사용자의 이미지와 PDF 파일은 사용자의 기기에서만 처리되며 당사는 이를 수집·열람·판매하지 않습니다.

## 1. 로컬 처리, 파일은 업로드되지 않음

본 앱의 모든 변환 기능(이미지→PDF, 이미지 결합, PDF→이미지, PDF 병합, PDF 암호화, PDF 복호화)은 사용자의 기기에서 로컬로 실행됩니다. **사용자의 이미지와 PDF 파일은 당사 또는 어떤 변환 서버에도 업로드되지 않으며**, 처리 결과는 사용자의 기기에 직접 저장됩니다.

당사는 사용자 데이터를 판매하지 않으며, 판매할 수 있는 파일 데이터도 보유하고 있지 않습니다.

## 2. 로컬에 저장되는 데이터

다음 데이터는 사용자의 기기에만 저장됩니다.

- 변환 기록(작업 상태, 소요 시간, 원본 및 출력 형식, 파일 크기). 기기의 로컬 데이터베이스에 저장됩니다.
- 변환 출력 파일. 사용자가 공유 시트를 통해 내보내거나 캐시를 삭제할 때까지 앱 로컬 디렉터리에 저장됩니다.
- 앱 설정(테마, 언어 등)

이 데이터는 사용자의 기기에만 존재하므로 당사는 접근, 열람, 복원이 불가능합니다.

## 3. 시스템 권한

- **사진 라이브러리**: 사용자가 사진 앱에서 직접 이미지를 선택할 때만 사용됩니다. 사용자가 선택한 이미지를 읽는 데만 사용되며 사진 일괄 읽기나 자동 업로드는 수행하지 않습니다.
- **파일**: 사용자가 "파일" 앱에서 이미지나 PDF를 직접 선택할 때만 사용됩니다. 사용자가 선택한 파일을 읽는 데만 사용됩니다.

## 4. 광고

본 앱은 **Google AdMob** 광고로 지원됩니다. Pro를 구독하지 않은 사용자는 기능 화면 진입 시 보상형 광고를 보게 됩니다. AdMob은 관련 법률이 허용하는 경우 기기 식별자(광고 식별자 등)를 사용하여 광고를 게재하고 측정할 수 있습니다. 자세한 내용은 [Google 개인정보 처리방침](https://policies.google.com/privacy)을 참조하세요.

Pro를 구독하면 언제든지 광고를 제거할 수 있습니다. 관련 법률이 요구하는 경우 시스템 설정에서 광고 추적을 제한하거나 광고 식별자를 재설정할 수도 있습니다.

## 5. Pro 구독

Pro 구독 결제는 **Apple App Store**가 처리하며, 구독 검증과 권한 관리는 **RevenueCat**을 통해 이루어집니다. 당사는 사용자의 결제 정보(카드 번호, 청구 주소 등)에 일절 접근하지 않으며 결제 자격 증명을 보관하지 않습니다. 관련 거래 정보는 [Apple 개인정보 처리방침](https://www.apple.com/legal/privacy/) 및 [RevenueCat 개인정보 처리방침](https://revenuecat.com/privacy/)의 적용을 받습니다.

## 6. 공유

앱을 통해 파일을 공유하면 시스템 공유 시트를 거쳐 사용자가 선택한 대상(메일, AirDrop, 파일 등)으로 직접 전송됩니다. 사용자가 완전히 제어하며 당사는 이러한 파일에 접근할 수 없고 알림을 받지도 않습니다.

## 7. 데이터 삭제

모든 데이터가 로컬에 있으므로 삭제가 완전히 이루어집니다.

- 앱 설정에서 캐시를 지우면 앱 디렉터리의 출력 파일과 기록이 삭제됩니다.
- 앱을 삭제하면 기기의 모든 로컬 데이터도 함께 삭제됩니다.

이 작업은 되돌릴 수 없으므로 중요한 파일은 먼저 다른 곳에 저장해 주세요.

## 8. 아동 개인정보

본 앱은 관련 법률상 계약 체결 가능 최저 연령에 미달하는 아동을 대상으로 하지 않으며, 아동으로부터 의도적으로 데이터를 수집하지 않습니다.
