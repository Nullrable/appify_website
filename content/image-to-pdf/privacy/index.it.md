Questa informativa sulla privacy spiega come **Image to PDF** ("**questa applicazione**") gestisce le informazioni che ti riguardano. In breve: le tue immagini e i tuoi file PDF vengono elaborati solo sul tuo dispositivo; non li raccogliamo, non li vediamo e non li vendiamo.

## 1. Elaborazione locale, nessun caricamento di file

Tutte le funzioni di conversione di questa applicazione — immagini in PDF, unione di immagini, PDF in immagini, fusione di PDF, crittografia PDF, decrittografia PDF — vengono eseguite localmente sul tuo dispositivo. **Le tue immagini e i tuoi file PDF non verranno caricati sui nostri server né su alcun server di conversione**, e i risultati vengono salvati direttamente sul tuo dispositivo.

Non vendiamo i tuoi dati, e non abbiamo dati di file da vendere.

## 2. Dati memorizzati localmente

I seguenti dati vengono memorizzati solo sul tuo dispositivo:

- Cronologia delle conversioni (stato dell'operazione, durata, formati di origine e output, dimensione del file), memorizzata in un database locale sul dispositivo
- File di output delle conversioni, salvati nella directory locale dell'applicazione finché non li salvi o svuoti la cache tramite il pannello di condivisione
- Impostazioni dell'applicazione (tema, lingua, ecc.)

Poiché questi dati esistono solo sul tuo dispositivo, non possiamo accedervi, visualizzarli o recuperarli.

## 3. Autorizzazioni di sistema

- **Libreria foto**: utilizzata solo quando selezioni attivamente immagini dall'album, per leggere le immagini selezionate, senza lettura massiccia dell'album o caricamento automatico
- **File**: utilizzato solo quando selezioni attivamente immagini o PDF dall'app "File", per leggere i file selezionati

## 4. Pubblicità

Questa applicazione è supportata dalla pubblicità di **Google AdMob**. Gli utenti non abbonati a Pro vedranno annunci rewarded quando entrano nelle pagine delle funzioni. AdMob può utilizzare identifier del dispositivo (come l'identifier pubblicitario ove consentito dalla legge applicabile) per erogare e misurare gli annunci. Per i dettagli, consulta l'[informativa sulla privacy di Google](https://policies.google.com/privacy).

Puoi rimuovere gli annunci in qualsiasi momento abbonandoti a Pro. Se la legge applicabile lo richiede, puoi anche limitare il tracciamento degli annunci o reimpostare l'identifier pubblicitario nelle impostazioni di sistema.

## 5. Abbonamento Pro

Il pagamento dell'abbonamento Pro è gestito da **Apple App Store**, mentre la verifica dell'abbonamento e la gestione dei vantaggi sono effettuate tramite **RevenueCat**. Non accediamo alle tue informazioni di pagamento (numero di carta, indirizzo di fatturazione, ecc.) e non conserviamo alcuna prova di pagamento. Le informazioni sulle transazioni correlate sono soggette all'[informativa sulla privacy di Apple](https://www.apple.com/legal/privacy/) e all'[informativa sulla privacy di RevenueCat](https://revenuecat.com/privacy/).

## 6. Condivisione

Quando condividi file tramite l'applicazione, i file vengono inviati tramite il pannello di condivisione di sistema direttamente alla destinazione che scegli (e-mail, AirDrop, "File", ecc.), sotto il tuo controllo. Non possiamo accedere a questi file e non riceviamo alcuna notifica.

## 7. Eliminazione dei dati

Poiché tutti i dati sono locali, l'eliminazione è completa:

- Puoi svuotare la cache nelle impostazioni dell'applicazione per eliminare i file di output e la cronologia nella directory dell'applicazione
- La disinstallazione dell'applicazione eliminerà anche tutti i dati locali sul dispositivo

Questa operazione è irreversibile; salva prima i file importanti.

## 8. Privacy dei bambini

Questa applicazione non è destinata a bambini di età inferiore all'età minima per stipulare contratti secondo la legge applicabile, e non raccogliamo consapevolmente dati di bambini.

## 9. Modifiche all'informativa

Possiamo aggiornare questa informativa sulla隐私 di tanto in tanto. Continuare a utilizzare l'applicazione dopo l'entrata in vigore degli aggiornamenti costituisce accettazione dell'informativa aggiornata. In caso di modifiche sostanziali, forniremo un avviso ragionevole nell'applicazione o tramite la pagina dell'App Store.
