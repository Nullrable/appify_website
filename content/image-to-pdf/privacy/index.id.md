Kebijakan Privasi ini menjelaskan bagaimana **Image to PDF** ("**Aplikasi ini**") menangani informasi yang berkaitan dengan Anda. Singkatnya: gambar dan file PDF Anda hanya diproses di perangkat Anda; kami tidak mengumpulkan, tidak dapat melihat, dan tidak menjualnya.

## 1. Pemrosesan Lokal, File Tidak Diunggah

Semua fungsi konversi aplikasi ini — gambar ke PDF, penggabungan gambar, PDF ke gambar, penggabungan PDF, enkripsi PDF, dekripsi PDF — dilakukan secara lokal di perangkat Anda. **Gambar dan file PDF Anda tidak akan diunggah ke server kami atau server konversi mana pun**, dan hasilnya disimpan langsung di perangkat Anda.

Kami tidak menjual data Anda, dan kami juga tidak memiliki data file Anda untuk dijual.

## 2. Data yang Disimpan Secara Lokal

Data berikut hanya disimpan di perangkat Anda:

- Riwayat konversi (status operasi, durasi, format sumber dan output, ukuran file), disimpan dalam basis data lokal perangkat
- Berkas output konversi, disimpan di direktori lokal aplikasi hingga Anda menyimpan atau membersihkan cache melalui panel berbagi
- Pengaturan aplikasi (tema, bahasa, dll.)

Karena data ini hanya ada di perangkat Anda, kami tidak dapat mengakses, melihat, atau memulihkannya.

## 3. Izin Sistem

- **Pustaka Foto**: hanya digunakan saat Anda secara aktif memilih gambar dari album, untuk membaca gambar yang Anda pilih, tanpa membaca album secara massal atau mengunggah otomatis
- **Berkas**: hanya digunakan saat Anda secara aktif memilih gambar atau PDF dari aplikasi "Berkas", untuk membaca berkas yang Anda pilih

## 4. Iklan

Aplikasi ini didukung oleh iklan **Google AdMob**. Pengguna yang belum berlangganan Pro akan melihat iklan berhadiah saat masuk ke halaman fitur. AdMob dapat menggunakan pengidentifikasi perangkat (seperti pengidentifikasi iklan jika diizinkan oleh hukum yang berlaku) untuk menayangkan dan mengukur iklan. Untuk detailnya, lihat [Kebijakan Privasi Google](https://policies.google.com/privacy).

Anda dapat menghapus iklan kapan saja dengan berlangganan Pro. Jika hukum yang berlaku mengharuskannya, Anda juga dapat membatasi pelacakan iklan atau mengatur ulang pengidentifikasi iklan di pengaturan sistem.

## 5. Langganan Pro

Pembayaran langganan Pro ditangani oleh **Apple App Store**, sedangkan verifikasi langganan dan manajemen hak dilakukan melalui **RevenueCat**. Kami tidak menyentuh informasi pembayaran Anda (nomor kartu, alamat penagihan, dll.) dan tidak menyimpan bukti pembayaran apa pun. Informasi transaksi terkait tunduk pada [Kebijakan Privasi Apple](https://www.apple.com/legal/privacy/) dan [Kebijakan Privasi RevenueCat](https://revenuecat.com/privacy/).

## 6. Berbagi

Saat Anda membagikan berkas melalui aplikasi, berkas dikirimkan melalui panel berbagi sistem langsung ke tujuan yang Anda pilih (email, AirDrop, "Berkas", dll.),全程 dikendalikan oleh Anda. Kami tidak dapat mengakses berkas-berkas ini dan tidak menerima pemberitahuan apa pun.

## 7. Penghapusan Data

Karena semua data bersifat lokal, penghapusannya menyeluruh:

- Anda dapat menghapus cache di pengaturan aplikasi untuk menghapus berkas output dan riwayat di direktori aplikasi
- Menghapus instalan aplikasi juga akan menghapus semua data lokal di perangkat

Tindakan ini tidak dapat dibatalkan; harap simpan berkas penting terlebih dahulu.

## 8. Privasi Anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah usia minimum yang dapat订立 kontrak sesuai hukum yang berlaku, dan kami juga tidak dengan sengaja mengumpulkan data anak-anak.

## 9. Perubahan Kebijakan

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Melanjutkan penggunaan aplikasi setelah pembaruan生效意味着 penerimaan terhadap kebijakan yang diperbarui. Jika terdapat perubahan重大, kami akan memberikan pemberitahuan yang wajar di dalam aplikasi atau melalui halaman toko aplikasi.
