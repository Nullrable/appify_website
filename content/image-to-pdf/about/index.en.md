Image to PDF is an iPhone toolkit for the PDF chores that come up in daily life. It turns photos into PDFs, stitches multiple photos into one image, splits a PDF back into images, merges PDFs, and adds or removes encryption. All files stay on your phone.

## Photos to PDF

Pick multiple photos from your library or the Files app. JPG, PNG, HEIC, WebP, GIF and similar formats are accepted. Drag to set the order, then export a PDF at each image's original size. The PDF keeps the source resolution, so a phone-camera-quality PDF stays that way.

## Stitch photos into one image

Stitch photos vertically for long chat screenshots, horizontally for side-by-side comparisons, or in a 3×3 grid for a gallery. Original aspect ratios are preserved, the preview updates live, and you can drag to reorder before exporting.

## PDF to images

Open any PDF, preview every page, pick the ones you need, and export them as PNG images. Five zoom levels from 1.0× to 3.0× are available so you can match the resolution to where the image will be used.

## Merge multiple PDFs

Combine several PDFs into a single file. Each file gets a thumbnail preview so you can confirm the order before merging, and you can drag to rearrange them.

## Encrypt with AES-256

Set a user password and an optional owner password. Control whether the recipient can print, copy text, or modify the document. AES-256 is the default cipher; weaker options exist if you need to open the PDF in older readers.

## Decrypt a PDF

Open an encrypted PDF, enter the password, and the file is saved back without encryption. The app detects whether a file is encrypted before asking for a password, so plain PDFs go straight through.

## Sharing and history

Export a PDF through the system share sheet to email, AirDrop, or the Files app. Every conversion is saved to an on-device history automatically, and reopening it brings back the same output.

## Everything on your device

Image conversion, stitching, PDF merging, encryption, and decryption all run locally. Files never leave your phone, and the conversion history is stored only in a local database.

## Free and Pro

All tools are free to use. Free users see a short rewarded ad before each conversion. Pro subscribers convert without ads. Pro is sold as an auto-renewing subscription through the App Store.
