Gambar ke PDF adalah perangkat iPhone yang merangkum pekerjaan PDF harian. Aplikasi mengubah foto menjadi PDF, menggabungkan banyak foto menjadi satu gambar, memecah PDF kembali menjadi gambar, menggabungkan banyak PDF, serta menambah atau menghapus enkripsi. Semua file tetap di ponsel Anda.

## Foto ke PDF

Pilih banyak foto dari pustaka atau aplikasi File. JPG, PNG, HEIC, WebP, GIF, dan format serupa didukung. Seret untuk mengatur urutan, lalu ekspor PDF pada ukuran asli tiap foto. PDF mempertahankan resolusi sumber, sehingga kualitas dari kamera ponsel tidak berkurang.

## Gabungkan foto menjadi satu

Gabungkan secara vertikal untuk tangkapan layar obrolan panjang, secara horizontal untuk perbandingan berdampingan, atau dalam grid 3×3 untuk galeri. Rasio aspek asli dipertahankan, pratinjau diperbarui langsung, dan Anda dapat menyeret untuk mengatur ulang sebelum mengekspor.

## PDF ke gambar

Buka PDF apa pun, pratinjau setiap halaman, pilih halaman yang Anda butuhkan, lalu ekspor sebagai gambar PNG. Tersedia lima tingkat zoom dari 1.0× hingga 3.0× agar Anda dapat memilih resolusi sesuai tujuan penggunaan.

## Gabungkan beberapa PDF

Satukan beberapa PDF menjadi satu file. Setiap PDF mendapat pratinjau thumbnail sehingga Anda dapat memastikan urutan sebelum menggabungkan, dan dapat menyeret untuk menata ulang.

## Enkripsi dengan AES-256

Atur kata sandi pengguna dan kata sandi pemilik opsional. Kontrol apakah penerima dapat mencetak, menyalin teks, atau mengubah dokumen. AES-256 adalah sandi bawaan; tersedia opsi yang lebih lemah bila Anda perlu membuka PDF di pembaca lama.

## Dekripsi PDF

Buka PDF yang dienkripsi, masukkan kata sandi, dan file disimpan ulang tanpa enkripsi. Aplikasi mendeteksi apakah sebuah file dienkripsi sebelum meminta kata sandi, sehingga PDF biasa langsung lewat.

## Berbagi dan riwayat

Ekspor PDF lewat lembar berbagi sistem ke email, AirDrop, atau aplikasi File. Setiap hasil konversi otomatis tersimpan di riwayat pada perangkat, dan membukanya kembali akan memunculkan keluaran yang sama.

## Semuanya di perangkat Anda

Konversi gambar, penggabungan, penggabungan PDF, enkripsi, dan dekripsi berjalan secara lokal. File tidak pernah meninggalkan ponsel, dan riwayat konversi hanya tersimpan di basis data lokal.

## Gratis dan Pro

Semua alat dapat dipakai gratis. Pengguna gratis melihat iklan berhadiah singkat sebelum setiap konversi. Pelanggan Pro mengonversi tanpa iklan. Pro dijual sebagai langganan dengan perpanjangan otomatis melalui App Store.
