## Duplicate Contacts Cleanup

A phone's contact list drifts over time: the same person saved twice on iCloud and Google, a friend's new number added without removing the old one, a contact imported from a backup that overlaps with the live address book. Duplicate Contacts surfaces these duplicates and lets you merge them in a few taps.

### Matched by name and number

The scan compares contact entries on the field most likely to be the same person — display name and phone number — and groups every match. A friend saved as "Alex" with one number and as "Alex K." with the same number will appear together, ready to merge.

### Review before merging

Each group lists every duplicate with the fields it contains, so you can see at a glance whether one entry has more information than the other. Pick the one to keep, choose which fields to carry over, and confirm — the merge only happens after your explicit confirmation.

### Fields preserved, not overwritten

A merge keeps the fullest set of information across the duplicates. If one entry has a home address and the other has a work email, the merged contact can carry both, so cleanup does not mean losing the details you had scattered across copies.

### Permission and privacy

Reading your contacts requires the standard system permission, which you grant once. The scan runs locally, contact data never leaves your device, and there is no cloud copy made by the app. The merged contact is written back to the system address book you already use.
