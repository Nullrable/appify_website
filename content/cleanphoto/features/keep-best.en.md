## Keep the Best Shot

The slowest part of cleanup is not deleting — it is choosing. When eight near-identical photos stare back at you, picking a keeper takes longer than removing the other seven. Keep Best turns that choice into a glance.

### Size as a quality signal

Within each group, photos are sorted by file size, and file sizes are loaded before you start reviewing. For photos from the same moment — a burst, a re-save, an import — the largest file is almost always the copy that retained the most detail: highest resolution, least compression. It rises to the top as the natural keeper.

### A glance, not a debate

You no longer compare photos pixel by pixel. Check the recommended shot, confirm it looks right, and mark the rest for deletion. The decision shrinks from "which of these eight is best?" to "is this one good?" — and that is a question you can answer instantly.

### Works across the scans

The same size sorting applies everywhere groups appear — exact duplicates, similar photos, and screenshots all show their items with file sizes loaded, so the quality signal is always available no matter which scan you are working through.

### Nothing silent

Keep Best only sorts and recommends. It never deletes on its own: every deletion still goes through your selection and a confirmation, and the removal itself runs through the system photo library.

### Built for big libraries

The heavier your backlog, the more this adds up. A hundred groups that each take a minute of deliberation become a hundred quick confirmations, and an afternoon of cleanup shrinks to a coffee break.
