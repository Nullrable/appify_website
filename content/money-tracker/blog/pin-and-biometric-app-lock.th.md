Money Tracker ออกมาพร้อมล็อกปิดอยู่ เปิดมันในการตั้งค่า เลือกตัวเลขหกหลักเป็น PIN และตั้งแต่นั้นเป็นต้นมา PIN จะปิดกั้นทางเข้าทุกครั้งที่คุณกลับมาที่แอป

PIN คือพื้น: มันทำงานบนทุกเครื่องโดยไม่พึ่งฮาร์ดแวร์ เหนือขึ้นไปเป็นชั้นไบโอเมตริกซ์เสริม — Face ID หรือ Touch ID บน iOS ลายนิ้วมือ (หรือใบหน้า เมื่อเครื่องเปิดเผยผ่าน API เดียวกัน) บน Android ต้องตั้ง PIN ก่อนจึงจะเปิดไบโอเมตริกซ์ได้ และการล้าง PIN จะพาไบโอเมตริกซ์หายไปด้วย ถ้านิ้วเปียกหรือหน้ากากทำให้ข้อความแจ้งเตือนไบโอเมตริกซ์ใช้ไม่ได้ ระบบจะร่วงกลับไปใช้รหัสผ่านของเครื่อง ไม่ใช่ PIN ของแอป ดังนั้นห่วงโซ่ความไว้วางใจจึงยังคงยึดกับแพลตฟอร์ม

ล็อกจะทำงานทุกครั้งที่แอปกลับมาที่เบื้องหน้า — ไม่ใช่แค่ตอนเปิดใหม่ การสลับไปแอปอื่นแป๊บหนึ่ง การแอบดูการแจ้งเตือน การหายไปหนึ่งชั่วโมงแล้วกลับมา: ทุกครั้งจะดึงล็อกกลับขึ้นมา จนกว่า PIN หรือไบโอเมตริกซ์จะเป็นที่พอใจ บัญชี ธุรกรรม สถิติ และการตั้งค่าจะยังคงถูกซ่อนไว้
