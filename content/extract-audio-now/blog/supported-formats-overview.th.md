## รายการรูปแบบครบถ้วน

บทความนี้เป็นสารคดี — ทุกรูปแบบวิดีโอและเสียงที่ Extract Audio Now รองรับอยู่ที่นี่ พร้อมคำแนะนำว่าสถานการณ์ไหนเลือกอะไร

## รูปแบบวิดีโอเอาต์พุต (11 แบบ)

เครื่องมือแปลงรูปแบบวิดีโอสามารถแปลงเป็นรูปแบบใดก็ได้ต่อไปนี้:

| รูปแบบ | สถานการณ์ที่เหมาะ |
|---|---|
| **mp4** | ใช้ทั่วไป เกือบทุกอุปกรณ์และเครื่องเล่นรู้จัก ตัวเลือกแรกโดยค่าเริ่มต้น |
| **mov** | ตัวเลือกอันดับแรกในระบบ Apple, iMovie, Final Cut, Logic เปิดได้ |
| **m4v** | คอนเทนเนอร์ยุค iTunes คล้าย mp4 บนอุปกรณ์ Apple |
| **mkv** | คอนเทนเนอร์โอเพนซอร์ส ใส่หลายแทร็กเสียง หลายซับไตเติลได้ เหมาะเก็บ HD |
| **avi** | คอนเทนเนอร์เก่า เข้ากันได้ดีที่สุดกับแอป Windows เก่า |
| **flv** | รูปแบบสตรีมยุค Flash เก่า พบน้อยลง แปลงให้ฟุตเทจเก่า |
| **ts** | MPEG-TS รูปแบบสถานีโทรทัศน์ แผ่นบลูเรย์ใช้บ่อย |
| **mpg / mpeg** | MPEG-1 / MPEG-2 Program Stream มรดกยุค VCD / DVD |
| **3gp / 3g2** | วิดีโอมือถือยุค 3G ฟีเจอร์โฟนเก่ารู้จักแค่นี้ |

## รูปแบบเสียงเอาต์พุต (6 แบบ)

เครื่องมือแยกเสียงสามารถแยกแทร็กเสียงออกเป็นรูปแบบใดก็ได้ต่อไปนี้:

| รูปแบบ | สถานการณ์ที่เหมาะ |
|---|---|
| **MP3** | เครื่องเล่นทั่วไป ระบบรถยนต์ แนบอีเมล |
| **AAC** | ตัวเลือกอันดับแรกในระบบ Apple รายละเอียดดี ไฟล์เล็ก |
| **M4A** | เวอร์ชันคอนเทนเนอร์ของ AAC นามสกุลต่างกัน แต่เนื้อหาคล้ายกัน |
| **WAV** | ต้นฉบับไม่บีบ เหมาะมิกซ์ เก็บถาวร ตัดต่อต่อ |
| **FLAC** | ไม่บีบแต่บีบขนาด ประมาณครึ่งหนึ่งของ WAV |
| **OGG** | คอนเทนเนอร์โอเพนซอร์ส เครื่องเล่นมืออาชีพบางตัวชอบ |

## วิธีเลือก

- **ส่งให้เพื่อน / กลุ่มแชท** → mp4 วิดีโอ, MP3 เสียง
- **ซอฟต์แวร์ตัดต่อทำต่อ** → mov วิดีโอ, WAV เสียง
- **เก็บถาวร** → mkv วิดีโอ, FLAC เสียง
- **อุปกรณ์เก่าเข้ากันได้** → 3gp / 3g2 วิดีโอ, MP3 เสียง
- **แพร่ภาพหรือสตรีมมืออาชีพ** → ts วิดีโอ

ไม่ต้องคิดมาก — ส่วนใหญ่ mp4 + MP3 พอใช้แล้ว เจอปัญหาเข้ากันไม่ได้กับแพลตฟอร์มหรืออุปกรณ์เฉพาะ ค่อยกลับมาเปิดสารคดีนี้
