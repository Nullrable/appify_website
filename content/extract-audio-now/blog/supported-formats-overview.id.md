## Daftar format lengkap

Ini contekan singkat - setiap format video dan audio yang didukung Extract Audio, dan kapan pilih yang mana.

## Format output video (11)

Alat Konversi bisa membungkus ulang video Anda ke salah satu dari ini:

| Format | Kapan pakai |
|---|---|
| **mp4** | Universal. Dikenali hampir semua perangkat dan pemutar. Pilihan default. |
| **mov** | Default ekosistem Apple - iMovie, Final Cut, Logic semua menerima. |
| **m4v** | Kontainer video era iTunes, berperilaku seperti mp4 di perangkat Apple. |
| **mkv** | Kontainer sumber terbuka, bisa muat banyak trek audio dan subtitle. Bagus untuk pengarsipan HD. |
| **avi** | Kontainer klasik, kompatibilitas terbaik dengan app Windows lawas. |
| **flv** | Format streaming era Flash lama, sekarang jarang - berguna untuk footage lawas. |
| **ts** | MPEG-TS, format TV broadcast, umum di rip Blu-ray. |
| **mpg / mpeg** | MPEG-1 / MPEG-2 program stream, peninggalan era VCD / DVD. |
| **3gp / 3g2** | Video ponsel era 3G; yang diterima feature phone lama. |

## Format output audio (6)

Alat Ekstrak Audio bisa menarik salah satu trek audio ini dari video:

| Format | Kapan pakai |
|---|---|
| **MP3** | Pemutar universal, sistem mobil, lampiran email. |
| **AAC** | Default ekosistem Apple, detail bagus di ukuran kecil. |
| **M4A** | AAC dalam kontainer berbeda - konten sama, ekstensi file beda. |
| **WAV** | Master tanpa kompresi, ideal untuk mixing, arsip, atau edit ulang. |
| **FLAC** | Lossless terkompresi - kira-kira setengah ukuran WAV. |
| **OGG** | Kontainer sumber terbuka, disukai sebagian pemutar profesional. |

## Cara memilih

- **Kirim ke teman / chat grup** -> video mp4, audio MP3
- **Pemrosesan lanjutan di software edit** -> video mov, audio WAV
- **Pengarsipan jangka panjang** -> video mkv, audio FLAC
- **Kompatibilitas perangkat lama** -> video 3gp / 3g2, audio MP3
- **Broadcast atau streaming pro** -> video ts

Jangan terlalu dipikirkan - di kebanyakan kasus, mp4 + MP3 sudah cukup. Saat Anda menemukan masalah kompatibilitas platform atau perangkat tertentu, kembali ke daftar ini.
