## 完整格式清單

這篇文章是一份速查表 — 提取音訊支援的視訊和音訊格式都列在這裡,以及什麼場景該選哪個。

## 視訊輸出格式(11 種)

視訊格式轉檔工具能重新封裝成以下任意一種:

| 格式 | 適合場景 |
|---|---|
| **mp4** | 通用,幾乎所有裝置和播放器都認。預設首選。 |
| **mov** | Apple 生態首選,iMovie、Final Cut、Logic 都吃。 |
| **m4v** | iTunes 時代的視訊容器,Apple 裝置上跟 mp4 類似。 |
| **mkv** | 開源容器,能裝多音軌、多字幕。適合高清收藏。 |
| **avi** | 老牌容器,Windows 老應用相容性最好。 |
| **flv** | 老 Flash 時代的串流格式,現在很少見,轉給老素材用。 |
| **ts** | MPEG-TS,廣播電視台格式,藍光原盤多用。 |
| **mpg / mpeg** | MPEG-1 / MPEG-2 程式流,VCD / DVD 時代遺留。 |
| **3gp / 3g2** | 3G 時代的手機視訊,老功能機只認這個。 |

## 音訊輸出格式(6 種)

音訊提取工具能從任何視訊裡剝離出以下任意一種音軌:

| 格式 | 適合場景 |
|---|---|
| **MP3** | 通用播放器、車載系統、郵件附件。 |
| **AAC** | Apple 生態首選,細節好、體積小。 |
| **M4A** | AAC 的容器版本,檔案後綴不同但內容相近。 |
| **WAV** | 無損母帶,適合混音、存檔、二次剪輯。 |
| **FLAC** | 壓縮後的無損,體積約為 WAV 的一半。 |
| **OGG** | 開源容器,部分專業播放器偏好。 |

## 怎麼選

- **發給朋友 / 群聊** → mp4 視訊、MP3 音訊
- **剪輯軟體二次處理** → mov 視訊、WAV 音訊
- **存檔保留** → mkv 視訊、FLAC 音訊
- **老裝置相容** → 3gp / 3g2 視訊、MP3 音訊
- **廣播或專業串流** → ts 視訊

不需要想太多 — 大多數情況下,mp4 + MP3 已經夠用。遇到具體平台或裝置的相容問題,再回來翻這份清單。
