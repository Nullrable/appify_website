## 対応フォーマット一覧

この記事はある意味チートシート — Extract Audio が対応する動画と音声のフォーマットすべてと、どの場面でどれを選ぶかを一覧します。

## 動画出力フォーマット(11 種)

変換ツールは以下のいずれかに再ラップできます:

| フォーマット | 向いている場面 |
|---|---|
| **mp4** | 汎用、ほぼすべての端末とプレーヤーが認識。デフォルトの第一選択。 |
| **mov** | Apple エコシステムの定番、iMovie、Final Cut、Logic がそのまま受け付ける。 |
| **m4v** | iTunes 世代の動画コンテナ、Apple 端末では mp4 と似た挙動。 |
| **mkv** | オープンソースコンテナ、複数音声トラック・複数字幕を格納可能。HD コレクション向き。 |
| **avi** | 老舗コンテナ、レガシー Windows アプリの互換性が一番。 |
| **flv** | 旧 Flash 世代のストリーミング形式、今や希少、レガシー素材向け。 |
| **ts** | MPEG-TS、放送局の形式、Blu-ray リップで多用。 |
| **mpg / mpeg** | MPEG-1 / MPEG-2 プログラムストリーム、VCD / DVD 時代の遺物。 |
| **3gp / 3g2** | 3G 世代の携帯電話動画、古いフィーチャーフォン用。 |

## 音声出力フォーマット(6 種)

音声抽出ツールは動画から以下のいずれかの音声トラックを取り出せます:

| フォーマット | 向いている場面 |
|---|---|
| **MP3** | 汎用プレーヤー、車載システム、メール添付。 |
| **AAC** | Apple エコシステムの定番、サイズが小さくディテールが良い。 |
| **M4A** | AAC のコンテナ違い、拡張子は違うが中身はほぼ同じ。 |
| **WAV** | 非圧縮マスター、ミキシング・アーカイブ・再編集向き。 |
| **FLAC** | 非可逆圧縮ロスレス、WAV の半分ほどのサイズ。 |
| **OGG** | オープンソースコンテナ、一部のプロプレーヤーが好む。 |

## 選び方の指針

- **友人/グループチャットに送る** → mp4 動画、MP3 音声
- **編集ソフトで二次処理** → mov 動画、WAV 音声
- **長期アーカイブ** → mkv 動画、FLAC 音声
- **古い端末との互換** → 3gp / 3g2 動画、MP3 音声
- **放送・プロ向けストリーミング** → ts 動画

あまり悩まないでください — 大抵は mp4 + MP3 で足ります。具体的なプラットフォームや端末との互換性问题に当たったら、この一覧を見直してください。
