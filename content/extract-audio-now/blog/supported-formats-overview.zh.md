## 完整格式清单

这篇文章是一份速查表 — 提取音频支持的视频和音频格式都列在这里,以及什么场景该选哪个。

## 视频输出格式(11 种)

视频格式转换工具能重新封装成以下任意一种:

| 格式 | 适合场景 |
|---|---|
| **mp4** | 通用,几乎所有设备和播放器都认。默认首选。 |
| **mov** | Apple 生态首选,iMovie、Final Cut、Logic 都吃。 |
| **m4v** | iTunes 时代的视频容器,Apple 设备上跟 mp4 类似。 |
| **mkv** | 开源容器,能装多音轨、多字幕。适合高清收藏。 |
| **avi** | 老牌容器,Windows 老应用兼容性最好。 |
| **flv** | 老 Flash 时代的流媒体格式,现在很少见,转给老素材用。 |
| **ts** | MPEG-TS,广播电视台格式,蓝光原盘多用。 |
| **mpg / mpeg** | MPEG-1 / MPEG-2 程序流,VCD / DVD 时代遗留。 |
| **3gp / 3g2** | 3G 时代的手机视频,老功能机只认这个。 |

## 音频输出格式(6 种)

音频提取工具能从任何视频里剥离出以下任意一种音轨:

| 格式 | 适合场景 |
|---|---|
| **MP3** | 通用播放器、车载系统、邮件附件。 |
| **AAC** | Apple 生态首选,细节好、体积小。 |
| **M4A** | AAC 的容器版本,文件后缀不同但内容相近。 |
| **WAV** | 无损母带,适合混音、存档、二次剪辑。 |
| **FLAC** | 压缩后的无损,体积约为 WAV 的一半。 |
| **OGG** | 开源容器,部分专业播放器偏好。 |

## 怎么选

- **发给朋友 / 群聊** → mp4 视频、MP3 音频
- **剪辑软件二次处理** → mov 视频、WAV 音频
- **存档保留** → mkv 视频、FLAC 音频
- **老设备兼容** → 3gp / 3g2 视频、MP3 音频
- **广播或专业流媒体** → ts 视频

不需要想太多 — 大多数情况下,mp4 + MP3 已经够用。遇到具体平台或设备的兼容问题,再回来翻这份清单。
