## قائمة التنسيقات الكاملة

هذا ورقة مرجعية سريعة - كل تنسيقات الفيديو والصوت التي يدعمها Extract Audio، ومتى تختار أيها.

## تنسيقات إخراج الفيديو (11)

أداة التحويل يمكنها إعادة تغليف فيديوك إلى أي من هذه:

| التنسيق | متى تستخدمه |
|---|---|
| **mp4** | عالمي. يتعرف عليه كل جهاز ومشغل تقريباً. الاختيار الافتراضي. |
| **mov** | الافتراضي في نظام Apple - iMovie و Final Cut و Logic كلها تقبله. |
| **m4v** | حاوية فيديو من عصر iTunes، تتصرف مثل mp4 على أجهزة Apple. |
| **mkv** | حاوية مفتوحة المصدر، تستوعب مسارات صوت وترجمات متعددة. جيدة لأرشفة HD. |
| **avi** | حاوية كلاسيكية، أفضل توافق مع تطبيقات Windows القديمة. |
| **flv** | تنسيق بث من عصر Flash القديم، نادر اليوم - مفيد للمادة القديمة. |
| **ts** | MPEG-TS، تنسيق البث التلفزيوني، شائع في ريب Blu-ray. |
| **mpg / mpeg** | MPEG-1 / MPEG-2 program stream، بقايا من عصر VCD / DVD. |
| **3gp / 3g2** | فيديو هواتف عصر 3G؛ ما تقبله الهواتف المميزة القديمة. |

## تنسيقات إخراج الصوت (6)

أداة استخراج الصوت يمكنها سحب أي من مسارات الصوت هذه من الفيديو:

| التنسيق | متى تستخدمه |
|---|---|
| **MP3** | مشغلات عالمية، أنظمة السيارة، مرفقات البريد الإلكتروني. |
| **AAC** | الافتراضي في نظام Apple، تفاصيل جيدة بحجم صغير. |
| **M4A** | AAC في حاوية مختلفة - نفس المحتوى، امتداد ملف مختلف. |
| **WAV** | ماستر غير مضغوط، مثالي للمكسج، الأرشفة، أو إعادة التحرير. |
| **FLAC** | بدون فقدان مضغوط - حوالي نصف حجم WAV. |
| **OGG** | حاوية مفتوحة المصدر، يفضلها بعض المشغلات الاحترافية. |

## كيف تختار

- **أرسل لصديق / محادثة جماعية** -> فيديو mp4، صوت MP3
- **معالجة ثانية في برنامج تحرير** -> فيديو mov، صوت WAV
- **أرشفة طويلة المدى** -> فيديو mkv، صوت FLAC
- **توافق مع أجهزة قديمة** -> فيديو 3gp / 3g2، صوت MP3
- **بث تلفزيوني أو احترافي** -> فيديو ts

لا تفكر كثيراً - في معظم الحالات، mp4 + MP3 سيكفي. عندما تواجه مشكلة توافق مع منصة أو جهاز معين، ارجع لهذه القائمة.
