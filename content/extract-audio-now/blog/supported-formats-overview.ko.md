## 전체 형식 목록

이 글은 빠른 참조표입니다 — 오디오 추출이 지원하는 비디오와 오디오 형식을 모두 여기 나열하고, 어떤 상황에서 어느 것을 고르는지 정리합니다.

## 비디오 출력 형식(11종)

비디오 형식 변환 도구가 다음 컨테이너 중 하나로 다시 포장할 수 있습니다.

| 형식 | 적합한 상황 |
|---|---|
| **mp4** | 범용, 거의 모든 기기와 플레이어가 인식. 기본 첫 선택. |
| **mov** | Apple 생태계 첫 선택, iMovie, Final Cut, Logic이 받음. |
| **m4v** | iTunes 시대의 비디오 컨테이너, Apple 기기에서 mp4와 비슷. |
| **mkv** | 오픈소스 컨테이너, 여러 음轨, 여러 자막 담을 수 있음. HD 콜렉션에 적합. |
| **avi** | 베테랑 컨테이너, Windows 오래된 앱 호환성 최고. |
| **flv** | 옛 Flash 시대 스트리밍 형식, 지금은 드묾, 오래된 자료 변환용. |
| **ts** | MPEG-TS, 방송국 형식, Blu-ray 원반에 흔히 쓰임. |
| **mpg / mpeg** | MPEG-1 / MPEG-2 프로그램 스트림, VCD / DVD 시대 유산. |
| **3gp / 3g2** | 3G 시대 휴대폰 비디오, 오래된 피처폰만 인식. |

## 오디오 출력 형식(6종)

오디오 추출 도구가 어떤 비디오에서든 다음 음轨 중 하나로 분리합니다.

| 형식 | 적합한 상황 |
|---|---|
| **MP3** | 범용 플레이어, 차량 시스템, 메일 첨부. |
| **AAC** | Apple 생태계 첫 선택, 디테일 좋고 용량 작음. |
| **M4A** | AAC의 컨테이너 버전, 확장자가 다르고 내용은 비슷. |
| **WAV** | 무손실 마스터, 믹싱, 아카이브, 2차 편집에 적합. |
| **FLAC** | 압축 무손실, WAV의 약 절반 크기. |
| **OGG** | 오픈소스 컨테이너, 일부 프로 플레이어가 선호. |

## 어떻게 고를까

- **친구나 그룹 채팅에 보냄** → mp4 비디오, MP3 오디오
- **편집 소프트웨어에서 2차 처리** → mov 비디오, WAV 오디오
- **보관용 장기 저장** → mkv 비디오, FLAC 오디오
- **오래된 기기 호환** → 3gp / 3g2 비디오, MP3 오디오
- **방송 또는 전문 스트리밍** → ts 비디오

너무 고민할 필요 없습니다 — 대부분 상황에서 mp4 + MP3이면 충분. 구체 플랫폼이나 기기의 호환 문제가 생기면 다시 이 목록을 확인하세요.
