## Complete format list

This is a cheat sheet - every video and audio format Extract Audio supports, and when to pick which.

## Video output formats (11)

The Convert tool can re-wrap your video into any of these:

| Format | When to use |
|---|---|
| **mp4** | Universal. Recognized by virtually every device and player. Default pick. |
| **mov** | Apple ecosystem default - iMovie, Final Cut, Logic all take it. |
| **m4v** | iTunes-era video container, behaves like mp4 on Apple devices. |
| **mkv** | Open-source container, can hold multiple audio tracks and subtitles. Good for HD archival. |
| **avi** | Old-school container, best compatibility with legacy Windows apps. |
| **flv** | Old Flash-era streaming format, rarely seen today - useful for legacy footage. |
| **ts** | MPEG-TS, the broadcast TV format, common on Blu-ray rips. |
| **mpg / mpeg** | MPEG-1 / MPEG-2 program stream, leftover from VCD / DVD days. |
| **3gp / 3g2** | 3G-era phone video; what old feature phones accept. |

## Audio output formats (6)

The Extract Audio tool can pull any of these audio tracks out of a video:

| Format | When to use |
|---|---|
| **MP3** | Universal players, car systems, email attachments. |
| **AAC** | Apple ecosystem default, great detail at small size. |
| **M4A** | AAC inside a different container - same content, different file extension. |
| **WAV** | Lossless master, ideal for mixing, archival, or re-editing. |
| **FLAC** | Lossless but compressed - roughly half the size of WAV. |
| **OGG** | Open-source container, preferred by some professional players. |

## How to choose

- **Send to a friend / group chat** -> mp4 video, MP3 audio
- **Second pass in editing software** -> mov video, WAV audio
- **Long-term archival** -> mkv video, FLAC audio
- **Compatibility with older devices** -> 3gp / 3g2 video, MP3 audio
- **Broadcast or pro streaming** -> ts video

Don't overthink it - in most cases, mp4 + MP3 will do. When you hit a specific platform or device compatibility issue, come back to this list.
