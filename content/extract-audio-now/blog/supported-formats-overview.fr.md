## Liste complète des formats

Cet article fait office de mémento — tous les formats vidéo et audio pris en charge par Extract Audio Now y sont listés, avec le bon usage pour chacun.

## Formats vidéo de sortie (11)

L'outil de conversion vidéo peut ré-encoder dans n'importe lequel de ces formats :

| Format | Contexte adapté |
|---|---|
| **mp4** | Universel, reconnu par presque tous les appareils et lecteurs. Premier choix par défaut. |
| **mov** | Premier choix dans l'écosystème Apple, lu par iMovie, Final Cut, Logic. |
| **m4v** | Conteneur de l'époque iTunes, se comporte comme mp4 sur les appareils Apple. |
| **mkv** | Conteneur libre, accepte plusieurs pistes audio et sous-titres. Idéal pour l'archivage HD. |
| **avi** | Conteneur historique, meilleure compatibilité avec les vieilles applis Windows. |
| **flv** | Format de streaming de l'ère Flash, devenu rare, utile pour convertir d'anciennes sources. |
| **ts** | MPEG-TS, format broadcast TV, utilisé pour les Blu-ray. |
| **mpg / mpeg** | MPEG-1 / MPEG-2 Program Stream, héritage VCD / DVD. |
| **3gp / 3g2** | Vidéo mobile de l'ère 3G, seul format reconnu par les vieux feature phones. |

## Formats audio de sortie (6)

L'outil d'extraction audio peut extraire n'importe laquelle de ces pistes :

| Format | Contexte adapté |
|---|---|
| **MP3** | Lecteurs classiques, systèmes automobiles, pièces jointes mail. |
| **AAC** | Premier choix dans l'écosystème Apple, détaillé et léger. |
| **M4A** | Version conteneur de l'AAC, extension différente mais contenu proche. |
| **WAV** | Master sans perte, pour mixage, archivage, futur montage. |
| **FLAC** | Sans perte compressé, environ la moitié du poids d'un WAV. |
| **OGG** | Conteneur libre, apprécié par certains lecteurs pro. |

## Comment choisir

- **Envoi à des proches / groupe de chat** → mp4 pour la vidéo, MP3 pour l'audio
- **Reprise en montage** → mov pour la vidéo, WAV pour l'audio
- **Archivage** → mkv pour la vidéo, FLAC pour l'audio
- **Compatibilité appareils anciens** → 3gp / 3g2 pour la vidéo, MP3 pour l'audio
- **Diffusion broadcast ou streaming pro** → ts pour la vidéo

Pas besoin de trop réfléchir — dans la majorité des cas, mp4 + MP3 suffisent. En cas de souci de compatibilité avec une plateforme ou un appareil précis, revenez consulter cette liste.
