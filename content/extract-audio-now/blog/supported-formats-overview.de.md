## Vollständige Formatliste

Dieser Artikel ist ein Spickzettel — alle Video- und Audioformate, die Extract Audio Now unterstützt, sind hier aufgeführt, samt Empfehlung, welcher Anlass zu welchem Format passt.

## Videoausgabeformate (11)

Das Videoformat-Konvertierungswerkzeug kann in jedes der folgenden Formate neu verpacken:

| Format | Passende Szenarien |
|---|---|
| **mp4** | Universell, fast alle Geräte und Player erkennen es. Erste Wahl als Standard. |
| **mov** | Erste Wahl im Apple-Ökosystem, iMovie, Final Cut, Logic spielen es. |
| **m4v** | Container aus der iTunes-Ära, verhält sich auf Apple-Geräten ähnlich wie mp4. |
| **mkv** | Open-Source-Container, nimmt mehrere Tonspuren und Untertitel auf. Gut für HD-Archivierung. |
| **avi** | Klassischer Container, beste Kompatibilität mit älteren Windows-Anwendungen. |
| **flv** | Streaming-Format der Flash-Ära, selten geworden, nützlich für alte Quellen. |
| **ts** | MPEG-TS, Broadcast-Format der TV-Sender, oft auf Blu-ray-Originalen. |
| **mpg / mpeg** | MPEG-1 / MPEG-2 Program Stream, Erbe der VCD / DVD-Ära. |
| **3gp / 3g2** | 3G-Zeit-Mobile-Video, ältere Feature-Phones verstehen nur das. |

## Audioausgabeformate (6)

Das Audioextraktionswerkzeug kann jede dieser Tonspuren aus einem Video herauslösen:

| Format | Passende Szenarien |
|---|---|
| **MP3** | Übliche Player, Autoanlagen, Mailanhänge. |
| **AAC** | Erste Wahl im Apple-Ökosystem, detailreich und kompakt. |
| **M4A** | Container-Variante von AAC, andere Endung, ähnlicher Inhalt. |
| **WAV** | Verlustfreies Master, für Mixing, Archivierung, weiteren Schnitt. |
| **FLAC** | Verlustfrei komprimiert, etwa halb so groß wie WAV. |
| **OGG** | Open-Source-Container, bei manchen Profi-Playern beliebt. |

## Wie wählt man

- **An Freunde / Gruppenchat senden** → mp4 für Video, MP3 für Audio
- **Weiterverarbeitung in Schnittsoftware** → mov für Video, WAV für Audio
- **Archivierung** → mkv für Video, FLAC für Audio
- **Kompatibilität mit alten Geräten** → 3gp / 3g2 für Video, MP3 für Audio
- **Broadcast oder professionelles Streaming** → ts für Video

Kein Grund, sich verrückt zu machen — in den meisten Fällen reichen mp4 + MP3. Bei spezifischen Kompatibilitätsproblemen mit einer Plattform oder einem Gerät schauen Sie wieder in diese Liste.
