## Полный список форматов

Это шпаргалка — все видео- и аудиоформаты, которые поддерживает «Извлечение аудио», и какой для чего подходит.

## Видео на выходе (11 форматов)

Инструмент конвертации перепаковывает видео в любой из этих контейнеров:

| Формат | Когда подходит |
|---|---|
| **mp4** | Универсальный, читается почти везде. Выбор по умолчанию. |
| **mov** | Выбор в экосистеме Apple, iMovie, Final Cut и Logic его берут. |
| **m4v** | Видеоконтейнер эпохи iTunes, на устройствах Apple близок к mp4. |
| **mkv** | Открытый контейнер, вмещает несколько аудиодорожек и субтитров. Подходит для коллекций в высоком качестве. |
| **avi** | Контейнер-ветеран, лучшая совместимость со старыми приложениями Windows. |
| **flv** | Формат эпохи Flash, сейчас редкость — для олдскульного материала. |
| **ts** | MPEG-TS, вещательный формат, часто используется на Blu-ray. |
| **mpg / mpeg** | Программный поток MPEG-1 / MPEG-2, наследие эпохи VCD / DVD. |
| **3gp / 3g2** | Видео эпохи 3G, старые кнопочные телефоны читали только это. |

## Аудио на выходе (6 форматов)

Инструмент извлечения аудио отделяет от любого видео звуковую дорожку в любом из этих форматов:

| Формат | Когда подходит |
|---|---|
| **MP3** | Универсальные плееры, автомобильные системы, почтовые вложения. |
| **AAC** | Выбор в экосистеме Apple, хорошая детализация при малом размере. |
| **M4A** | Контейнерная версия AAC, другое расширение, похожее содержимое. |
| **WAV** | Без сжатия, для сведения, архива, дальнейшего монтажа. |
| **FLAC** | Сжатое без потерь, примерно вдвое меньше WAV. |
| **OGG** | Открытый контейнер, часть профессиональных плееров его предпочитает. |

## Как выбрать

- **Отправить другу или в чат** → mp4 для видео, MP3 для аудио.
- **Передать в видеоредактор для дальнейшей обработки** → mov для видео, WAV для аудио.
- **Долгосрочное хранение** → mkv для видео, FLAC для аудио.
- **Совместимость со старым устройством** → 3gp / 3g2 для видео, MP3 для аудио.
- **Вещание или профессиональный стриминг** → ts для видео.

Не нужно задумываться слишком сильно — в большинстве случаев mp4 + MP3 достаточно. Когда всплывёт конкретная проблема совместимости с площадкой или устройством, вернитесь к этой шпаргалке.
