## Сжатие видео

Минута 4K легко съедает несколько сотен мегабайт. Когда в хранилище телефона осталось мало места, видео обычно главные пожиратели. Сжатие делает одну вещь: уменьшает файл, стараясь не терять детали.

### Три пресета

Пресеты три: низкий, средний, высокий.

- **Низкий** — файл минимален, годится для почты, мессенджеров. Детализация падает заметно — для непритязательного материала.
- **Средний** — золотая середина для большинства задач. Файл становится в полтора-два раза меньше, для повседневных публикаций разница незаметна.
- **Высокий** — сжатие мягкое, качество в приоритете. Для важных кадров, архива, материала под дальнейший монтаж.

Разница между пресетами — не «чем выше качество, тем больше файл», а выбор приоритета под конкретную задачу.

### Свой битрейт

Если пресеты не подходят, сдвиньте ползунок битрейта. Битрейт определяет объём данных в секунду: выше — качественнее, но больше; ниже — компактнее, но возможна мыльная картинка. Найдите удобное значение и запускайте.

### Пакетная обработка

Можно сжимать сразу несколько видео, по очереди. Каждое обрабатывается независимо. Время зависит от длины и целевого битрейта — минутный ролик на низком пресете готов за несколько секунд.

### В отличие от конвертации

Сжатие меняет битрейт, картинка теряет в качестве. Конвертация меняет только контейнер, качество остаётся. Нужно облегчить для отправки — сжатие. Нужно подстроиться под плеер — конвертация.
