## Извлечение аудио из видео

В видео часто ценна только звуковая часть — голос, музыка, интервью. Чистый аудиофайл удобнее: послушать позже, закинуть в подкаст, вложить в монтаж. Поддерживаются **шесть выходных форматов: MP3, AAC, M4A, WAV, FLAC, OGG**.

### Выбор видео и формата

Откройте «Фото» или «Файлы», выберите одно или несколько видео — не больше двадцати за раз. Сверху появится лента чипов с форматами: MP3 для универсальности, AAC для экосистемы Apple, WAV для мастер-копии без потерь, FLAC для сжатого без потерь, OGG для опенсорс-плееров. Любой вариант — на ваш выбор.

### Последовательная обработка

Двадцать клипов не запустятся одновременно — кодек работает с одним файлом за другим. Время зависит от длины и выбранного формата. Короткие ролики — несколько секунд; несколько записей вебинаров — очередь, можно отойти за кофе.

### Куда сохраняется

Готовый файл сначала попадает в песочницу приложения (имя наследуется от исходника, меняется только расширение), затем появляется окно «Save to Files» — выбираете папку в iOS Files. MP3/AAC/M4A/WAV/FLAC/OGG в «Фото» не уходят (iOS принимает в «Фото» только видеоконтейнеры mp4/mov/m4v). Исходное видео не трогается — можно обработать ещё раз.

### Качество звука

Битрейт зависит от формата: MP3, AAC, M4A — по умолчанию 192 кбит/с, OGG — 160 кбит/с, WAV/FLAC сохраняют исходный поток без потерь (битрейт не ограничен). Ручной настройки битрейта нет — баланс задан самим форматом.

### Локальная обработка

Извлечение идёт полностью на iPhone. Видео никуда не загружается, аудио никуда не отправляется. Можно работать в метро без сети.
